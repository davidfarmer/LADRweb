    Section 5.3 Upper-Triangular Matrices

    In Chapter 3 we defined the matrix of a linear map from a finite-dimensional vector space to another finite-dimensional vector space. That matrix depends on a choice of basis of each of the two vector spaces. Now that we are studying operators, which map a vector space to itself, the emphasis is on using only one basis.
    🔗

    Definition 5.31. matrix of an operator, \(\M(T)\).

    Suppose \(T \in \Lc(V)\text{.}\) The matrix of \(T\) with respect to a basis \(v_1, \dots, v_n\) of \(V\) is the \(n\)-by-\(n\) matrix
    \begin{equation*} \M(T) = \begin{pmatrix}A_{1,1} \amp \cdots \amp A_{1,n} \\ \vdots \amp \amp \vdots \\ A_{n,1} \amp \cdots \amp A_{n,n} \end{pmatrix} \end{equation*}
    whose entries \(A_{j,k}\) are defined by
    \begin{equation*} Tv_k = A_{1,k} v_1 + \dots + A_{n,k} v_n. \end{equation*}
    🔗
    The notation \(\M\bigl( T, (v_1, \dots, v_n) \bigr)\) is used if the basis is not clear from the context.
    🔗
    🔗
    Operators have square matrices (meaning that the number of rows equals the number of columns), rather than the more general rectangular matrices that we considered earlier for linear maps.
    🔗

    Aside
    The \(k^\nth\) column of the matrix \(\M(T)\) is formed from the coefficients used to write \(Tv_k\) as a linear combination of the basis \(v_1, \dots, v_n\text{.}\)
    🔗
    If \(T\) is an operator on \(\F{n}\) and no basis is specified, assume that the basis in question is the standard one (where the \(k^\nth\) basis vector is \(1\) in the \(k^\nth\) slot and \(0\) in all other slots). You can then think of the \(k^\nth\) column of \(\M(T)\) as \(T\) applied to the \(k^\nth\) basis vector, where we identify \(n\)-by-\(1\) column vectors with elements of \(\FF n\text{.}\)
    🔗

    Example 5.32. matrix of an operator with respect to standard basis.

    Define \(T \in \Lc( \F3 )\) by \(T(x, y, z) = (2x + y, 5y + 3z, 8z)\text{.}\) Then the matrix of \(T\) with respect to the standard basis of \(\F3\) is
    \begin{equation*} \M(T) = \begin{pmatrix}2 \amp 1 \amp 0 \\ 0 \amp 5 \amp 3 \\ 0 \amp 0 \amp 8 \end{pmatrix} , \end{equation*}
    as you should verify.
    🔗
    🔗
    A central goal of linear algebra is to show that given an operator \(T\) on a finite-dimensional vector space \(V{}\text{,}\) there exists a basis of \(V\) with respect to which \(T\) has a reasonably simple matrix. To make this vague formulation a bit more precise, we might try to choose a basis of \(V\) such that \(\M(T)\) has many \(0\)’s.
    🔗
    If \(V\) is a finite-dimensional complex vector space, then we already know enough to show that there is a basis of \(V\) with respect to which the matrix of \(T\) has \(0\)’s everywhere in the first column, except possibly the first entry. In other words, there is a basis of \(V\) with respect to which the matrix of \(T\) looks like
    \begin{equation*} \begin{pmatrix}\lambda \amp \amp \amp \amp \\ 0 \amp \amp * \amp \amp \\ \vdots \amp \amp \amp \amp \\ 0 \amp \amp \amp \amp \end{pmatrix} ; \end{equation*}
    here \(*\) denotes the entries in all columns other than the first column. To prove this, let \(\lambda\) be an eigenvalue of \(T\) (one exists by Theorem 5.18) and let \(v\) be a corresponding eigenvector. Extend \(v\) to a basis of \(V{}\text{.}\) Then the matrix of \(T\) with respect to this basis has the form above. Soon we will see that we can choose a basis of \(V\) with respect to which the matrix of \(T\) has even more \(0\)’s.
    🔗

    Definition 5.33. diagonal of a matrix.

    The diagonal of a square matrix consists of the entries on the line from the upper left corner to the bottom right corner.
    🔗
    🔗
    For example, the diagonal of the matrix
    \begin{equation*} \M(T) = \begin{pmatrix}\color{red}2 \amp 1 \amp 0 \\ 0 \amp \color{red}5 \amp 3 \\ 0 \amp 0 \amp \color{red}8 \end{pmatrix} \end{equation*}
    from Example 5.32 consists of the entries \(2, 5, 8\text{,}\) which are shown in red in the matrix above.
    🔗

    Definition 5.34. upper-triangular matrix.

    A square matrix is called upper triangular if all entries below the diagonal are \(0\text{.}\)
    🔗
    🔗
    🔗
    For example, the \(3\)-by-\(3\) matrix above is upper triangular.
    🔗
    Typically we represent an upper-triangular matrix in the form
    \begin{equation*} \begin{pmatrix}\lambda_1 \amp \amp * \\ \amp \ddots \amp \\ 0 \amp \amp \lambda_n \end{pmatrix} ; \end{equation*}
    the \(0\) in the matrix above indicates that all entries below the diagonal in this \(n\)-by-\(n\) matrix equal \(0\text{.}\) Upper-triangular matrices can be considered reasonably simple—if \(n\) is large, then at least almost half the entries in an \(n\)-by-\(n\) upper-triangular matrix are \(0\text{.}\)
    🔗

    Aside
    We often use \(*\) to denote matrix entries that we do not know or that are irrelevant to the questions being discussed.
    🔗
    The next result provides a useful connection between upper-triangular matrices and invariant subspaces.
    🔗

    Theorem 5.35. conditions for upper-triangular matrix.

    Suppose \(T \in \Lc(V)\) and \(v_1, \dots, v_n\) is a basis of \(V{}\text{.}\) Then the following are equivalent.
    1. The matrix of \(T\) with respect to \(v_1, \dots, v_n\) is upper triangular.
      🔗
      🔗
    2. \(\Span(v_1, \dots, v_k)\) is invariant under \(T\) for each \(k = 1, \dots, n\text{.}\)
      🔗
      🔗
    3. \(Tv_k \in \Span(v_1, \dots, v_k)\) for each \(k = 1, \dots, n\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    First suppose (a) holds. To prove that (b) holds, suppose \(k \in \{ 1, \ldots, n \}\text{.}\) If \(j \in \{ 1, \ldots, n \}\text{,}\) then
    \begin{equation*} Tv_j \in \Span (v_1, \ldots, v_j) \end{equation*}
    because the matrix of \(T\) with respect to \(v_1, \dots, v_n\) is upper triangular. Because \(\Span(v_1, \ldots, v_j) \subset \Span(v_1, \ldots, v_k)\) if \(j \le k\text{,}\) we see that
    \begin{equation*} Tv_j \in \Span(v_1, \ldots, v_k) \end{equation*}
    for each \(j \in \{ 1, \ldots, k \}\text{.}\) Thus \(\Span(v_1, \dots, v_k)\) is invariant under \(T\text{,}\) completing the proof that (a) implies (b).
    🔗
    Now suppose (b) holds, so \(\Span(v_1, \dots, v_k)\) is invariant under \(T\) for each \(k = 1, \dots, n\text{.}\) In particular, \(Tv_k \in \Span(v_1, \dots, v_k)\) for each \(k = 1, \dots, n\text{.}\) Thus (b) implies (c).
    🔗
    Now suppose (c) holds, so \(Tv_k \in \Span(v_1, \dots, v_k)\) for each \(k = 1, \dots, n\text{.}\) This means that when writing each \(Tv_k\) as a linear combination of the basis vectors \(v_1, \ldots, v_n\text{,}\) we need to use only the vectors \(v_1, \ldots, v_k\text{.}\) Hence all entries under the diagonal of \(\M(T)\) are \(0\text{.}\) Thus \(\M(T)\) is an upper-triangular matrix, completing the proof that (c) implies (a).
    🔗
    We have shown that (a) \(\implies\) (b) \(\implies\) (c) \(\implies\) (a), which shows that (a), (b), and (c) are equivalent.
    🔗
    🔗
    The next result tells us that if \(T \in \Lc(V)\) and with respect to some basis of \(V\) we have
    \begin{equation*} \M(T) = \begin{pmatrix}\lambda_1 \amp \amp * \\ \amp \ddots \amp \\ 0 \amp \amp \lambda_n \end{pmatrix} , \end{equation*}
    then \(T\) satisfies a simple equation depending on \(\lambda_1, \ldots, \lambda_n\text{.}\)
    🔗

    Theorem 5.36. equation satisfied by operator with upper-triangular matrix.

    Suppose \(T \in \Lc(V)\) and \(V\) has a basis with respect to which \(T\) has an upper-triangular matrix with diagonal entries \(\lambda_1, \ldots, \lambda_n\text{.}\) Then
    \begin{equation*} (T-\lambda_1 I) \cdots (T - \lambda_n I) = 0. \end{equation*}
    🔗
    🔗

    Proof.
    Let \(v_1, \ldots, v_n\) denote a basis of \(V\) with respect to which \(T\) has an upper-triangular matrix with diagonal entries \(\lambda_1, \ldots, \lambda_n\text{.}\) Then \(Tv_1 = \lambda_1 v_1\text{,}\) which means that \((T-\lambda_1 I)v_1 = 0\text{,}\) which implies that \((T-\lambda_1 I) \cdots (T - \lambda_m I) v_1 = 0\) for \(m=1, \ldots, n\) (using the commutativity of each \(T - \lambda_j I\) with each \(T - \lambda_k I\)).
    🔗
    Note that \((T - \lambda_2 I)v_2 \in \Span(v_1)\text{.}\) Thus \((T - \lambda_1 I)(T - \lambda_2 I)v_2 = 0\) (by the previous paragraph), which implies that \((T-\lambda_1 I) \cdots (T - \lambda_m I) v_2 = 0\) for \(m=2, \ldots, n\) (using the commutativity of each \(T - \lambda_j I\) with each \(T - \lambda_k I\)).
    🔗
    Note that \((T - \lambda_3 I)v_3 \in \Span(v_1, v_2)\text{.}\) Thus by the previous paragraph, \((T - \lambda_1 I)(T - \lambda_2 I)(T - \lambda_3 I) v_3 = 0\text{,}\) which implies that \((T-\lambda_1 I) \cdots (T - \lambda_m I) v_3 = 0\) for \(m=3, \ldots, n\) (using the commutativity of each \(T - \lambda_j I\) with each \(T - \lambda_k I\)).
    🔗
    Continuing this pattern, we see that \((T-\lambda_1 I) \cdots (T - \lambda_n I)v_k = 0\) for each \(k = 1, \ldots, n\text{.}\) Thus \((T-\lambda_1 I) \cdots (T - \lambda_n I)\) is the \(0\) operator because it is \(0\) on each vector in a basis of \(V{}\text{.}\)
    🔗
    🔗
    Unfortunately no method exists for exactly computing the eigenvalues of an operator from its matrix. However, if we are fortunate enough to find a basis with respect to which the matrix of the operator is upper triangular, then the problem of computing the eigenvalues becomes trivial, as the next result shows.
    🔗

    Theorem 5.37. determination of eigenvalues from upper-triangular matrix.

    Suppose \(T \in \Lc(V)\) has an upper-triangular matrix with respect to some basis of \(V{}\text{.}\) Then the eigenvalues of \(T\) are precisely the entries on the diagonal of that upper-triangular matrix.
    🔗
    🔗

    Proof.
    Suppose \(v_1, \dots, v_n\) is a basis of \(V\) with respect to which \(T\) has an upper-triangular matrix
    \begin{equation*} \M(T) = \begin{pmatrix}\lambda_1 \amp \amp * \\ \amp \ddots \amp \\ 0 \amp \amp \lambda_n \end{pmatrix} . \end{equation*}
    🔗
    Because \(Tv_1 = \lambda_1 v_1\text{,}\) we see that \(\lambda_1\) is an eigenvalue of \(T{}\text{.}\)
    🔗
    Suppose \(k \in \{ 2, \ldots, n \}\text{.}\) Then \((T - \lambda_k I)v_k \in \Span(v_1, \dots, v_{k-1})\text{.}\) Thus \(T - \lambda_k I\) maps \(\Span(v_1, \dots, v_k)\) into \(\Span(v_1, \dots, v_{k-1})\text{.}\) Because
    \begin{equation*} \dim \Span(v_1, \dots, v_k) = k \andd \dim \Span(v_1, \dots, v_{k-1}) = k-1, \end{equation*}
    this implies that \(T- \lambda_k I\) restricted to \(\Span(v_1, \dots, v_k)\) is not injective (by Theorem 3.22). Thus there exists \(v \in \Span(v_1, \dots, v_k)\) such that \(v \ne 0\) and \((T - \lambda_k I)v = 0\text{.}\) Thus \(\lambda_k\) is an eigenvalue of \(T{}\text{.}\) Hence we have shown that every entry on the diagonal of \(\M(T)\) is an eigenvalue of \(T{}\text{.}\)
    🔗
    To prove \(T\) has no other eigenvalues, let \(q\) be the polynomial defined by \(q(z) = (z-\lambda_1)\cdots(z-\lambda_n)\text{.}\) Then \(q(T) = 0\) (by Theorem 5.36). Hence \(q\) is a polynomial multiple of the minimal polynomial of \(T\) (by Theorem 5.26). Thus every zero of the minimal polynomial of \(T\) is a zero of \(q\text{.}\) Because the zeros of the minimal polynomial of \(T\) are the eigenvalues of \(T\) (by Theorem 5.24), this implies that every eigenvalue of \(T\) is a zero of \(q\text{.}\) Hence the eigenvalues of \(T\) are all contained in the list \(\lambda_1, \ldots, \lambda_n\text{.}\)
    🔗
    🔗

    Example 5.38. eigenvalues via an upper-triangular matrix.

    Define \(T \in \Lc( \F3 )\) by \(T(x, y, z) = (2x + y, 5y + 3z, 8z)\text{.}\) The matrix of \(T\) with respect to the standard basis is
    \begin{equation*} \M(T) = \begin{pmatrix}2 \amp 1 \amp 0 \\ 0 \amp 5 \amp 3 \\ 0 \amp 0 \amp 8 \end{pmatrix} . \end{equation*}
    🔗
    Now 5.37 implies that the eigenvalues of \(T\) are \(2\text{,}\) \(5\text{,}\) and \(8\text{.}\)
    🔗
    🔗
    The next example illustrates 5.40: an operator has an upper-triangular matrix with respect to some basis if and only if the minimal polynomial of the operator is the product of polynomials of degree \(1\text{.}\)
    🔗

    Example 5.39. whether \(T\) has an upper-triangular matrix can depend on \(\symbf{F}\).

    Define \(T \in \Lc( \F4 )\) by
    \begin{equation*} T(z_1, z_2, z_3, z_4) = (-z_2, z_1, 2 z_1 + 3z_3, z_3+3z_4). \end{equation*}
    🔗
    Thus with respect to the standard basis of \(\F4\text{,}\) the matrix of \(T\) is
    \begin{equation*} \begin{pmatrix}0 \amp -1 \amp 0 \amp 0 \\ 1 \amp 0 \amp 0 \amp 0 \\ 2 \amp 0 \amp 3 \amp 0\\ 0 \amp 0 \amp 1 \amp 3 \end{pmatrix} . \end{equation*}
    🔗
    You can ask a computer to verify that the minimal polynomial of \(T\) is the polynomial \(p\) defined by
    \begin{equation*} p(z) = 9 - 6z + 10 z^2 -6z^3 + z^4{}. \end{equation*}
    🔗
    First consider the case \(\F{} = \R{}\text{.}\) Then the polynomial \(p\) factors as
    \begin{equation*} p(z) = ( z^2 + 1 ) (z-3)(z-3), \end{equation*}
    with no further factorization of \(z^2 + 1\) as the product of two polynomials of degree \(1\) with real coefficients. Thus 5.40 states that there does not exist a basis of \(\R4\) with respect to which \(T\) has an upper-triangular matrix.
    🔗
    Now consider the case \(\F{} = \C{}\text{.}\) Then the polynomial \(p\) factors as
    \begin{equation*} p(z) = (z-i)(z+i)(z-3)(z-3), \end{equation*}
    where all factors above have the form \(z - \lambda_k\text{.}\) Thus 5.40 states that there is a basis of \(\C4\) with respect to which \(T\) has an upper-triangular matrix. Indeed, you can verify that with respect to the basis \((4-3i, -3-4i,-3+i,1), (4+3i,-3+4i,-3-i,1)\text{,}\) \((0, 0, 0, 1), (0,0,1, 0)\) of \(\C4\text{,}\) the operator \(T\) has the upper-triangular matrix
    \begin{equation*} \begin{pmatrix}i \amp 0 \amp 0 \amp 0 \\ 0 \amp -i \amp 0 \amp 0 \\ 0 \amp 0 \amp 3 \amp 1\\ 0 \amp 0 \amp 0 \amp 3 \end{pmatrix} . \end{equation*}
    🔗
    🔗

    Theorem 5.40. necessary and sufficient condition to have an upper-triangular matrix.

    Suppose \(V\) is finite-dimensional and \(T \in \Lc(V)\text{.}\) Then \(T\) has an upper-triangular matrix with respect to some basis of \(V\) if and only if the minimal polynomial of \(T\) equals \((z-\lambda_1) \cdots (z-\lambda_m)\) for some \(\lambda_1, \ldots, \lambda_m \in \F{}{}\text{.}\)
    🔗
    🔗
    🔗

    Proof.
    First suppose \(T\) has an upper-triangular matrix with respect to some basis of \(V{}\text{.}\) Let \(\alpha_1, \ldots, \alpha_n\) denote the diagonal entries of that matrix. Define a polynomial \(q \in \P(\F{})\) by
    \begin{equation*} q(z) = (z-\alpha_1) \cdots (z-\alpha_n). \end{equation*}
    🔗
    Then \(q(T) = 0\text{,}\) by Theorem 5.36. Hence \(q\) is a polynomial multiple of the minimal polynomial of \(T\text{,}\) by Theorem 5.26. Thus the minimal polynomial of \(T\) equals \((z-\lambda_1) \cdots (z-\lambda_m)\) for some \(\lambda_1, \ldots, \lambda_m \in \F{}\) with \(\{ \lambda_1, \ldots, \lambda_m \} \subset \{ \alpha_1, \ldots, \alpha_n \}\text{.}\)
    🔗
    To prove the implication in the other direction, now suppose the minimal polynomial of \(T\) equals \((z-\lambda_1) \cdots (z-\lambda_m)\) for some \(\lambda_1, \ldots, \lambda_m \in \F{}{}\text{.}\) We will use induction on \(m\text{.}\) To get started, if \(m = 1\) then \(z-\lambda_1\) is the minimal polynomial of \(T\text{,}\) which implies that \(T = \lambda_1 I\text{,}\) which implies that the matrix of \(T\) (with respect to any basis of \(V\)) is upper triangular.
    🔗
    Now suppose \(m > 1\) and the desired result holds for all smaller positive integers. Let
    \begin{equation*} U = \ran (T - \lambda_m I). \end{equation*}
    🔗
    Then \(U\) is invariant under \(T\) [this is a special case of Theorem 5.17 with \(p(z) = z - \lambda_m\)] . Thus \(T|_U\) is an operator on \(U\text{.}\)
    🔗
    If \(u \in U\text{,}\) then \(u = (T - \lambda_m I) v\) for some \(v \in V\) and
    \begin{equation*} (T - \lambda_1 I) \cdots (T - \lambda_{m-1} I) u = (T - \lambda_1 I) \cdots (T - \lambda_m I) v = 0. \end{equation*}
    🔗
    Hence \((z - \lambda_1) \cdots (z-\lambda_{m-1})\) is a polynomial multiple of the minimal polynomial of \(T|_U\text{,}\) by Theorem 5.26. Thus the minimal polynomial of \(T|_U\) is the product of at most \(m-1\) terms of the form \(z-\lambda_k\text{.}\)
    🔗
    By our induction hypothesis, there is a basis \(u_1, \dots, u_M\) of \(U\) with respect to which \(T|_U\) has an upper-triangular matrix. Thus for each \(k \in \{ 1, \ldots, M \}\text{,}\) we have (using 5.35)
    \begin{equation} Tu_k = (T|_U)(u_k) \in \Span(u_1, \dots, u_k).\tag{5.5} \end{equation}
    🔗
    Extend \(u_1, \dots, u_M\) to a basis \(u_1, \dots, u_M, v_1, \dots, v_N\) of \(V{}\text{.}\) If \(k \in \{ 1, \ldots, N \}\text{,}\) then
    \begin{equation*} Tv_k = (T - \lambda_m I)v_k + \lambda_m v_k. \end{equation*}
    🔗
    The definition of \(U\) shows that \((T - \lambda_m I)v_k \in U = \Span(u_1, \dots, u_M)\text{.}\) Thus the equation above shows that
    \begin{equation} Tv_k \in \Span(u_1, \dots, u_M, v_1, \dots, v_k).\tag{5.6} \end{equation}
    🔗
    From (5.5) and (5.6), we conclude (using 5.35) that \(T\) has an upper-triangular matrix with respect to the basis \(u_1, \dots, u_M, v_1, \dots, v_N\) of \(V{}\text{,}\) as desired.
    🔗
    🔗
    The set of numbers \(\{ \lambda_1, \ldots, \lambda_m \}\) from the previous result equals the set of eigenvalues of \(T\) (because the set of zeros of the minimal polynomial of \(T\) equals the set of eigenvalues of \(T\text{,}\) by Theorem 5.24), although the list \(\lambda_1, \ldots, \lambda_m\) in the previous result may contain repetitions.
    🔗
    In Chapter 8 we will improve even the wonderful result below; see 8.31 and Theorem 8.40.
    🔗

    Theorem 5.41. if \(\symbf{F} = \symbf{C}\text{,}\) then every operator on \(V\) has an upper-triangular matrix.

    Suppose \(V\) is a finite-dimensional complex vector space and \(T \in \Lc(V)\text{.}\) Then \(T\) has an upper-triangular matrix with respect to some basis of \(V{}\text{.}\)
    🔗
    🔗

    Proof.
    The desired result follows immediately from Theorem 5.40 and the second version of the fundamental theorem of algebra (see 4.10).
    🔗
    🔗
    For an extension of the result above to two operators \(S\) and \(T\) such that
    \begin{equation*} ST = TS, \end{equation*}
    🔗
    see 5.66. Also, for an extension to more than two operators, see Exercise 5.5.9(b) in Section 5.5.
    🔗
    Caution: If an operator \(T\in\Lc(V)\) has an upper-triangular matrix with respect to some basis \(v_1, \ldots, v_n\) of \(V{}\text{,}\) then the eigenvalues of \(T\) are exactly the entries on the diagonal of \(\M(T)\text{,}\) as shown by Theorem 5.37, and furthermore \(v_1\) is an eigenvector of \(T{}\text{.}\) However, \(v_2, \ldots, v_n\) need not be eigenvectors of \(T{}\text{.}\) Indeed, a basis vector \(v_k\) is an eigenvector of \(T\) if and only if all entries in the \(k^\nth\) column of the matrix of \(T\) are \(0\text{,}\) except possibly the \(k^\nth\) entry.
    🔗

    Aside
    The row echelon form of the matrix of an operator does not give us a list of the eigenvalues of the operator. In contrast, an upper-triangular matrix with respect to some basis gives us a list of all the eigenvalues of the operator. However, there is no method for computing exactly such an upper-triangular matrix, even though 5.41 guarantees its existence if \(\F{} = \C{}\text{.}\)
    🔗
    You may recall from a previous course that every matrix of numbers can be changed to a matrix in what is called row echelon form. If one begins with a square matrix, the matrix in row echelon form will be an upper-triangular matrix. Do not confuse this upper-triangular matrix with the upper-triangular matrix of an operator with respect to some basis whose existence is proclaimed by Theorem 5.41 (if \(\F{} = \C{}\))—there is no connection between these upper-triangular matrices.
    🔗
