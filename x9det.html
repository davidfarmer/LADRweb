    Section 9.3 Determinants

    Subsection 9.3.1 Defining the Determinant

    The next definition will lead us to a clean, beautiful, basis-free definition of the determinant of an operator.
    🔗

    Definition 9.40. \(\alpha_T\).

    Suppose that \(m\) is a positive integer and \(T \in \Lc(V)\text{.}\) For \(\alpha \in V_{\text{ alt } }^{(m)}{}\text{,}\) define \(\alpha_T \in V^{(m)}_{\text{ alt } }\) by
    \begin{equation*} \alpha_T(v_1, \ldots, v_m) = \alpha (Tv_1, \ldots, T v_m) \end{equation*}
    for each list \(v_1, \ldots, v_m\) of vectors in \(V{}\text{.}\)
    🔗
    🔗
    Suppose \(T \in \Lc(V)\text{.}\) If \(\alpha \in V^{(m)}_{\text{ alt } }\) and \(v_1, \ldots, v_m\) is a list of vectors in \(V\) with \(v_j = v_k\) for some \(j \ne k\text{,}\) then \(Tv_j = Tv_k\text{,}\) which implies that \(\alpha_T(v_1, \ldots, v_m) = \alpha (Tv_1, \ldots, T v_m) = 0\text{.}\) Thus the function \(\alpha \mapsto \alpha_T\) is a linear map of \(V^{(m)}_{\text{ alt } }\) to itself.
    🔗
    We know that \(\dim V^{(\dim V)}_{\text{ alt } } = 1\) (see 9.37). Every linear map from a one-dimensional vector space to itself is multiplication by some unique scalar. For the linear map \(\alpha \mapsto \alpha_T\text{,}\) we now define \(\det T\) to be that scalar.
    🔗

    Definition 9.41. determinant of an operator, \(\det T\).

    Suppose \(T \in \Lc(V)\text{.}\) The determinant of \(T{}\text{,}\) denoted by \(\det T{}\text{,}\) is defined to be the unique number in \(\F{}\) such that
    \begin{equation*} \alpha_T = (\det T) \alpha \end{equation*}
    for all \(\alpha \in V_{\text{ alt } }^{(\dim V)}{}\text{.}\)
    🔗
    🔗
    🔗

    Example 9.42. determinants of operators.

    Let \(n = \dim V{}\text{.}\)
    1. If \(I\) is the identity operator on \(V{}\text{,}\) then \(\alpha_I = \alpha\) for all \(\alpha \in V_{\text{ alt } }^{(n)}{}\text{.}\) Thus \(\det I = 1\text{.}\)
      🔗
      🔗
    2. More generally, if \(\lambda \in \F{}{}\text{,}\) then \(\alpha_{\lambda I} = \lambda^n \alpha\) for all \(\alpha \in V_{\text{ alt } }^{(n)}{}\text{.}\) Thus \(\det (\lambda I )= \lambda^n{}\text{.}\)
      🔗
      🔗
    3. Still more generally, if \(T \in \Lc(V)\) and \(\lambda \in \F{}{}\text{,}\) then \(\alpha_{\lambda T} = \lambda^n \alpha_T = \lambda^n (\det T) \alpha\) for all \(\alpha \in V_{\text{ alt } }^{(n)}{}\text{.}\) Thus \(\det (\lambda T) = \lambda^n \det T{}\text{.}\)
      🔗
      🔗
    4. Suppose \(T \in \Lc(V)\) and there is a basis \(e_1, \ldots, e_n\) of \(V\) consisting of eigenvectors of \(T{}\text{,}\) with corresponding eigenvalues \(\lambda_1, \ldots, \lambda_n\text{.}\) If \(\alpha \in V_{\text{ alt } }^{(n)}{}\text{,}\) then
      \begin{equation*} \alpha_T(e_1, \ldots, e_n) = \alpha (\lambda_1 e_1, \ldots, \lambda_n e_n) = (\lambda_1 \cdots \lambda_n) \alpha (e_1, \ldots, e_n). \end{equation*}
      If \(\alpha \ne 0\text{,}\) then 9.39 implies \(\alpha (e_1, \ldots, e_n) \ne 0\text{.}\) Thus the equation above implies
      \begin{equation*} \det T = \lambda_1 \cdots \lambda_n. \end{equation*}
      🔗
      🔗
    🔗
    🔗
    Our next task is to define and give a formula for the determinant of a square matrix. To do this, we associate with each square matrix an operator and then define the determinant of the matrix to be the determinant of the associated operator.
    🔗

    Definition 9.43. determinant of a matrix, \(\det A\).

    Suppose that \(n\) is a positive integer and \(A\) is an \(n\)-by-\(n\) square matrix with entries in \(\F{}{}\text{.}\) Let \(T \in \Lc( \F n )\) be the operator whose matrix with respect to the standard basis of \(\F n\) equals \(A\text{.}\) The determinant of \(A\text{,}\) denoted by \(\det A\text{,}\) is defined by \(\det A = \det T{}\text{.}\)
    🔗
    🔗
    🔗

    Example 9.44. determinants of matrices.

    1. If \(I\) is the \(n\)-by-\(n\) identity matrix, then the corresponding operator on \(\F n\) is the identity operator \(I\) on \(\FF n\text{.}\) Thus the first bullet point of Example 9.42 implies that the determinant of the identity matrix is \(1\text{.}\)
      🔗
      🔗
    2. Suppose \(A\) is a diagonal matrix with \(\lambda_1, \ldots, \lambda_n\) on the diagonal. Then the corresponding operator on \(\F n\) has the standard basis of \(\F n\) as eigenvectors, with eigenvalues \(\lambda_1, \ldots, \lambda_n\text{.}\) Thus the last bullet point of Example 9.42 implies that \(\det A = \lambda_1 \cdots \lambda_n\text{.}\)
      🔗
      🔗
    🔗
    🔗
    For the next result, think of each list \(v_1, \ldots, v_n\) of \(n\) vectors in \(\F n\) as a list of \(n\)-by-\(1\) column vectors. The notation \(\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) then denotes the \(n\)-by-\(n\) square matrix whose \(k^\nth\) column is \(v_k\) for each \(k = 1, \ldots, n\text{.}\)
    🔗

    Theorem 9.45. determinant is an alternating multilinear form.

    Suppose that \(n\) is a positive integer. The map that takes a list \(v_1, \ldots, v_n\) of vectors in \(\F n\) to \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) is an alternating \(n\)-linear form on \(\FF n\text{.}\)
    🔗
    🔗

    Proof.
    Let \(e_1, \ldots, e_n\) be the standard basis of \(\FF n\) and suppose \(v_1, \ldots, v_n\) is a list of vectors in \(\FF n\text{.}\) Let \(T \in \Lc( \F n )\) be the operator such that \(Te_k = v_k\) for \(k = 1, \ldots, n\text{.}\) Thus \(T\) is the operator whose matrix with respect to \(e_1, \ldots, e_n\) is \(\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\text{.}\) Hence \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} = \det T{}\text{,}\) by definition of the determinant of a matrix.
    🔗
    Let \(\alpha\) be an alternating \(n\)-linear form on \(\F n\) such that \(\alpha (e_1, \ldots, e_n) = 1\text{.}\) Then
    \begin{align*} \det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} \amp = \det T\\ \amp = (\det T) \alpha (e_1, \ldots, e_n)\\ \amp =\alpha (Te_1, \ldots, Te_n)\\ \amp = \alpha (v_1, \ldots, v_n)\text{,} \end{align*}
    where the third line follows from the definition of the determinant of an operator. The equation above shows that the map that takes a list of vectors \(v_1, \ldots, v_n\) in \(\F n\) to \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) is the alternating \(n\)-linear form \(\alpha\) on \(\FF n\text{.}\)
    🔗
    🔗
    The previous result has several important consequences. For example, it immediately implies that a matrix with two identical columns has determinant \(0\text{.}\) We will come back to other consequences later, but for now we want to give a formula for the determinant of a square matrix. Recall that if \(A\) is a matrix, then \(A_{j,k}\) denotes the entry in row \(j\text{,}\) column \(k\) of \(A\text{.}\)
    🔗

    Theorem 9.46. formula for determinant of a matrix.

    Suppose that \(n\) is a positive integer and \(A\) is an \(n\)-by-\(n\) square matrix. Then
    \begin{equation*} \det A = \sum_{(j_1, \ldots, j_n) \in \perm n} ( \sign(j_1, \ldots, j_n) ) A_{j_1,1} \cdots A_{j_n,n}. \end{equation*}
    🔗
    🔗

    Proof.
    Apply 9.36 with \(V = \F n\) and \(e_1, \ldots, e_n\) the standard basis of \(\F n\) and \(\alpha\) the alternating \(n\)-linear form on \(\F n\) that takes \(v_1, \ldots, v_n\) to \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) [see 9.45]. If each \(v_k\) is the \(k^\nth\) column of \(A\text{,}\) then each \(b_{j,k}\) in Theorem 9.36 equals \(A_{j,k}\text{.}\) Finally,
    \begin{equation*} \alpha (e_1, \ldots, e_n) = \det \begin{pmatrix}e_1 \amp \cdots \amp e_n \end{pmatrix} = \det I = 1. \end{equation*}
    🔗
    Thus the formula in Theorem 9.36 becomes the formula stated in this result.
    🔗
    🔗

    Example 9.47. explicit formula for determinant.

    1. If \(A\) is a \(2\)-by-\(2\) matrix, then the formula in Theorem 9.46 becomes
      \begin{equation*} \det A = A_{1,1} A_{2,2} - A_{2,1} A_{1,2}. \end{equation*}
      🔗
      🔗
    2. If \(A\) is a \(3\)-by-\(3\) matrix, then the formula in Theorem 9.46 becomes
      \begin{align*} \det A = \amp A_{1,1} A_{2,2} A_{3,3} - A_{2,1} A_{1,2} A_{3,3} - A_{3,1} A_{2,2} A_{1,3}\\ \amp {}- A_{1,1} A_{3,2} A_{2,3} + A_{3,1} A_{1,2} A_{2,3} + A_{2,1} A_{3,2} A_{1,3}\text{.} \end{align*}
      🔗
      🔗
    🔗
    🔗
    The sum in the formula in Theorem 9.46 contains \(n!\) terms. Because \(n!\) grows rapidly as \(n\) increases, the formula in Theorem 9.46 is not a viable method to evaluate determinants even for moderately sized \(n\text{.}\) For example, \(10!\) is over three million, and \(100!\) is approximately \(10^{158}\text{,}\) leading to a sum that the fastest computer cannot evaluate. We will soon see some results that lead to faster evaluations of determinants than direct use of the sum in Theorem 9.46.
    🔗

    Theorem 9.48. determinant of upper-triangular matrix.

    Suppose that \(A\) is an upper-triangular matrix with \(\lambda_1, \ldots, \lambda_n\) on the diagonal. Then \(\det A = \lambda_1 \cdots \lambda_n\text{.}\)
    🔗
    🔗

    Proof.
    If \((j_1, \ldots, j_n) \in \perm n\) with \((j_1, \ldots, j_n) \ne (1, \ldots, n)\text{,}\) then \(j_k > k\) for some \(k \in \{ 1, \ldots, n \}\text{,}\) which implies that \(A_{j_k, k} = 0\text{.}\) Thus the only permutation that can make a nonzero contribution to the sum in Theorem 9.46 is the permutation \((1, \ldots, n)\text{.}\) Because \(A_{k, k} = \lambda_k\) for each \(k = 1, \ldots, n\text{,}\) this implies that \(\det A = \lambda_1 \cdots \lambda_n\text{.}\)
    🔗
    🔗
    🔗

    Subsection 9.3.2 Properties of Determinants

    Our definition of the determinant leads to the following magical proof that the determinant is multiplicative.
    🔗

    Theorem 9.49. determinant is multiplicative.

    1. Suppose \(S, T \in \Lc(V)\text{.}\) Then \(\det (ST) = (\det S)(\det T)\text{.}\)
      🔗
      🔗
    2. Suppose \(A\) and \(B\) are square matrices of the same size. Then
      \begin{equation*} \det (AB) = (\det A)(\det B) \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Let \(n = \dim V{}\text{.}\) Suppose \(\alpha \in V^{(n)}_{\text{ alt } }\) and \(v_1, \ldots, v_n \in V{}\text{.}\) Then
      \begin{align*} \alpha_{ST} (v_1, \ldots, v_n) \amp = \alpha ( STv_1, \ldots, STv_n)\\ \amp = (\det S) \alpha (Tv_1, \ldots, Tv_n)\\ \amp = (\det S)(\det T) \alpha (v_1, \ldots, v_n)\text{,} \end{align*}
      where the first equation follows from the definition of \(\alpha_{ST}\text{,}\) the second equation follows from the definition of \(\det S\text{,}\) and the third equation follows from the definition of \(\det T{}\text{.}\) The equation above implies that \(\det (ST) = (\det S)(\det T)\text{.}\)
      🔗
      🔗
    2. Let \(S, T \in \Lc( \F n )\) be such that \(\M(S) = A\) and \(\M(T) = B\text{,}\) where all matrices of operators in this proof are with respect to the standard basis of \(\FF n\text{.}\) Then \(\M(ST) = \M(S) \M(T) = AB\) (see 3.43). Thus
      \begin{equation*} \det(AB) = \det(ST) = (\det S)(\det T) = (\det A)(\det B), \end{equation*}
      where the second equality comes from the result in (a).
      🔗
      🔗
    🔗
    🔗
    The determinant of an operator determines whether the operator is invertible.
    🔗

    Theorem 9.50. invertible \(\iff\) nonzero determinant.

    An operator \(T \in \Lc(V)\) is invertible if and only if \(\det T \ne 0\text{.}\) Furthermore, if \(T\) is invertible, then \(\det ( T^{-1} ) = \frac{1}{\det T}\text{.}\)
    🔗
    🔗

    Proof.
    First suppose \(T\) is invertible. Thus \(T T^{-1} = I\text{.}\) Now 9.49 implies that
    \begin{equation*} 1 = \det I = \det ( TT^{-1} ) = (\det T) ( \det ( T^{-1} ) ). \end{equation*}
    🔗
    Hence \(\det T \ne 0\) and \(\det ( T^{-1} )\) is the multiplicative inverse of \(\det T{}\text{.}\)
    🔗
    To prove the other direction, now suppose \(\det T \ne 0\text{.}\) Suppose \(v \in V\) and \(v \ne 0\text{.}\) Let \(v, e_2, \ldots, e_n\) be a basis of \(V\) and let \(\alpha \in V^{(n)}_{\text{ alt } }\) be such that \(\alpha \ne 0\text{.}\) Then \(\alpha (v, e_2, \ldots, e_n) \ne 0\) (by Theorem 9.39). Now
    \begin{equation*} \alpha (Tv, Te_2, \ldots, Te_n) = (\det T) \alpha (v, e_2, \ldots, e_n) \ne 0. \end{equation*}
    🔗
    Thus \(Tv \ne 0\text{.}\) Hence \(T\) is invertible.
    🔗
    🔗
    An \(n\)-by-\(n\) matrix \(A\) is invertible (see 3.80 for the definition of an invertible matrix) if and only if the operator on \(\F n\) associated with \(A\) \big(via the standard basis of \(\F n\)\big) is invertible. Thus the previous result shows that a square matrix \(A\) is invertible if and only if \(\det A \ne 0\text{.}\)
    🔗

    Theorem 9.51. eigenvalues and determinants.

    Suppose \(T \in \Lc(V)\) and \(\lambda \in \F{}{}\text{.}\) Then \(\lambda\) is an eigenvalue of \(T\) if and only if \(\det(\lambda I - T) = 0\text{.}\)
    🔗
    🔗

    Proof.
    The number \(\lambda\) is an eigenvalue of \(T\) if and only if \(T - \lambda I\) is not invertible (see 5.7), which happens if and only if \(\lambda I - T\) is not invertible, which happens if and only if \(\det(\lambda I - T) = 0\) (by Theorem 9.50).
    🔗
    🔗
    Suppose \(T \in \Lc(V)\) and \(\fun S W V\) is an invertible linear map. To prove that \(\det( S^{-1} T S ) = \det T\text{,}\) we could try to use 9.49 and Theorem 9.50, writing
    \begin{align*} \det( S^{-1} T S )\amp = ( \det S^{-1} ) (\det T) (\det S)\\ \amp = \det T{}\text{.} \end{align*}
    🔗
    That proof works if \(W = V{}\text{,}\) but if \(W \ne V\) then it makes no sense because the determinant is defined only for linear maps from a vector space to itself, and \(S\) maps \(W\) to \(V{}\text{,}\) making \(\det S\) undefined. The proof given below works around this issue and is valid when \(W \ne V{}\text{.}\)
    🔗

    Theorem 9.52. determinant is a similarity invariant.

    Suppose \(T \in \Lc(V)\) and \(\fun S W V\) is an invertible linear map. Then
    \begin{equation*} \det( S^{-1} T S ) = \det T{}. \end{equation*}
    🔗
    🔗

    Proof.
    Let \(n = \dim W = \dim V{}\text{.}\) Suppose \(\tau \in W_{\text{ alt } }^{(n)}{}\text{.}\) Define \(\alpha \in V^{(n)}_{\text{ alt } }\) by
    \begin{equation*} \alpha (v_1, \ldots, v_n) = \tau( S^{-1}v_1, \ldots, S^{-1}v_n ) \end{equation*}
    for \(v_1, \ldots, v_n \in V{}\text{.}\) Suppose \(w_1, \ldots, w_n \in W{}\text{.}\) Then
    \begin{align*} \tau_{S^{-1} T S}( w_1, \ldots, w_n) \amp = \tau( S^{-1}TS w_1, \ldots, S^{-1} T S w_n )\\ \amp = \alpha ( TSw_1, \ldots, TSw_n)\\ \amp = \alpha_T( Sw_1, \ldots, Sw_n)\\ \amp = (\det T) \alpha (Sw_1, \ldots, Sw_n)\\ \amp = (\det T) \tau(w_1, \ldots, w_n)\text{.} \end{align*}
    🔗
    The equation above and the definition of the determinant of the operator \(S^{-1} T S\) imply that \(\det( S^{-1} T S ) = \det T{}\text{.}\)

    For the special case in which \(V = \F n\) and \(e_1, \ldots, e_n\) is the standard basis of \(\FF n\text{,}\) the next result is true by the definition of the determinant of a matrix. The left side of the equation in the next result does not depend on a choice of basis, which means that the right side is independent of the choice of basis.

    Theorem 9.53. determinant of operator equals determinant of its matrix.

    Suppose \(T \in \Lc(V)\) and \(e_1, \ldots, e_n\) is a basis of \(V{}\text{.}\) Then
    \begin{equation*} \det T = \det \M( T, (e_1, \ldots, e_n) ). \end{equation*}
    🔗
    🔗

    Proof.
    Let \(f_1, \ldots, f_n\) be the standard basis of \(\FF{n}\text{.}\) Let \(\fun S {\F n} V\) be the linear map such that \(Sf_k = e_k\) for each \(k = 1, \ldots, n\text{.}\) Thus \(\M( S, (f_1, \ldots, f_n), (e_1, \ldots, e_n) )\) and \(\M( S^{-1} , (e_1, \ldots, e_n), (f_1, \ldots, f_n) )\) both equal the \(n\)-by-\(n\) identity matrix. Hence
    \begin{equation} \M( S^{-1} T S, (f_1, \ldots, f_n) ) = \M( T, (e_1, \ldots, e_n) ),\tag{9.54} \end{equation}
    as follows from two applications of Theorem 3.43. Thus
    \begin{align*} \det T \amp = \det( S^{-1} T S )\\ \amp = \det \M( S^{-1} T S, (f_1, \ldots, f_n) )\\ \amp = \det \M( T, (e_1, \ldots, e_n) )\text{,} \end{align*}
    where the first line comes from Theorem 9.52, the second line comes from the definition of the determinant of a matrix, and the third line follows from (9.54).

    Theorem 9.55. if \(\F{} = \C{}\text{,}\) then determinant equals product of eigenvalues.

    Proof.

Thus 9.53 and Theorem 9.48 imply that \(\det T\) equals the product of the eigenvalues of \(T{}\text{,}\) with each eigenvalue included as many times as its multiplicity.

    Theorem 9.56. determinant of transpose, dual, or adjoint.

    1. Suppose \(A\) is a square matrix. Then \(\det \tran{A} = \det A\text{.}\)
      🔗
      🔗
    2. Suppose \(T \in \Lc(V)\text{.}\) Then \(\det T' = \det T{}\text{.}\)
      🔗

    3. Suppose \(V\) is an inner product space and \(T \in \Lc(V)\text{.}\) Then
      \begin{equation*} \det ( T^* ) = \overline{\det T}{}. \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Let \(n\) be a positive integer. Define \(\fun \alpha { ( \F n )^n} {\F{}}\) by
      \begin{equation*} \alpha ( v_1, \ldots, v_n ) = \det ( \tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} } ) \end{equation*}
      for all \(v_1, \ldots, v_n \in \FF n\text{.}\) The formula in Theorem 9.46 for the determinant of a matrix shows that \(\alpha\) is an \(n\)-linear form on \(\FF n\text{.}\) Suppose \(v_1, \ldots, v_n \in \F n\) and \(v_j = v_k\) for some \(j \ne k\text{.}\) If \(B\) is an \(n\)-by-\(n\) matrix, then \(\tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} }B\) cannot equal the identity matrix because row \(j\) and row \(k\) of \(\tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} } B\) are equal. Thus (a) holds.

      🔗
    2. The equation \(\det T' = \det T{}\) follows from (a) and Theorem 9.53 and Theorem 3.132.
      🔗
      🔗
    3. Pick an orthonormal basis of \(V{}\text{.}\) The matrix of \(T^*\) with respect to that basis is the conjugate transpose of the matrix of \(T\) with respect to that basis (by Theorem 7.9). Thus 9.53, Theorem 9.46, and (a) imply that \(\det ( T^* ) = \overline{\det T}{}\text{.}\)

    Theorem 9.57. helpful results in evaluating determinants.

    1. If either two columns or two rows of a square matrix are equal, then the determinant of the matrix equals \(0\text{.}\)
      🔗
      🔗
    2. Suppose \(A\) is a square matrix and \(B\) is the matrix obtained from \(A\) by swapping either two columns or two rows. Then \(\det A = - \det B\text{.}\)
      🔗
      🔗
    3. If one column or one row of a square matrix is multiplied by a scalar, then the value of the determinant is multiplied by the same scalar.
      🔗
      🔗
    4. If a scalar multiple of one column of a square matrix is added to another column, then the value of the determinant is unchanged.
      🔗
      🔗
    5. If a scalar multiple of one row of a square matrix is added to another row, then the value of the determinant is unchanged.
      🔗
      🔗
    🔗
    🔗

    Proof.
    All the assertions in this result follow from the result that the maps \(v_1, \ldots, v_n \mapsto \det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) and \(v_1, \ldots, v_n \mapsto \det \tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} }\) are both alternating \(n\)-linear forms on \(\FF n\) [see 9.45 and Theorem 9.56(a)] .
    🔗
    For example, to prove (d) suppose \(v_1, \ldots, v_n \in \F n\) and \(c \in \F{}{}\text{.}\) Then
    \begin{align*} \det \amp \begin{pmatrix}v_1 + cv_2 \amp v_2 \amp \cdots \amp v_n \end{pmatrix}\\ \amp =\det \begin{pmatrix}v_1 \amp v_2 \amp \cdots \amp v_n \end{pmatrix} + c\det \begin{pmatrix}v_2 \amp v_2 \amp v_3 \amp \cdots \amp v_n \end{pmatrix}\\ \amp = \det \begin{pmatrix}v_1 \amp v_2 \amp \cdots \amp v_n \end{pmatrix} \text{,} \end{align*}
    where the first equation follows from the multilinearity property and the second equation follows from the alternating property. The equation above shows that adding a multiple of the second column to the first column does not change the value of the determinant. The same conclusion holds for any two columns. Thus (d) holds.
    🔗
    The proof of (e) follows from (d) and from Theorem 9.56(a). The proofs of (a), (b), and (c) use similar tools and are left to the reader.
    🔗
    🔗
    For matrices whose entries are concrete numbers, the result above leads to a much faster way to evaluate the determinant than direct application of the formula in Theorem 9.46. Specifically, apply the Gaussian elimination procedure of swapping rows [by Theorem 9.57(b), this changes the determinant by a factor of \(-1\)] , multiplying a row by a nonzero constant [by Theorem 9.57(c), this changes the determinant by the same constant] , and adding a multiple of one row to another row [by Theorem 9.57(e), this does not change the determinant] to produce an upper-triangular matrix, whose determinant is the product of the diagonal entries (by Theorem 9.48). If your software keeps track of the number of row swaps and of the constants used when multiplying a row by a constant, then the determinant of the original matrix can be computed.

One problem is that the procedure described in the paragraph above for evaluating a determinant does not work when the matrix includes a symbol (such as the \(\lambda\) in \(\lambda I - A\)). This problem arises because decisions need to be made in the Gaussian elimination procedure about whether certain quantities equal \(0\text{,}\) and those decisions become complicated in expressions involving a symbol \(\lambda\text{.}\)

Every eigenvalue of a unitary operator has absolute value \(1\) (by Theorem 7.54).     Theorem 9.58. every unitary operator has determinant with absolute value \(1\).

    Suppose \(V\) is an inner product space and \(S \in \Lc(V)\) is a unitary operator. Then \(\lvert \det S \rvert = 1\text{.}\)
    🔗
    🔗
    🔗

    Proof.
    Because \(S\) is unitary, \(I = S^* S\) (see 7.53). Thus
    \begin{equation*} 1 = \det(S^* S) = (\det S^*) (\det S) = \overline{( \det S)} (\det S) = \lvert \det S \rvert ^2{}, \end{equation*}
    where the second equality comes from Theorem 9.49(a) and the third equality comes from Theorem 9.56(c). The equation above implies that \(\lvert \det S \rvert = 1\text{.}\)

    Theorem 9.59. every positive operator has nonnegative determinant.

    Suppose \(V\) is an inner product space and \(T \in \Lc(V)\) is a positive operator. Then \(\det T \ge 0\text{.}\)
    🔗
    🔗
    🔗

    Proof.
    By the spectral theorem ( Theorem 7.29 or 7.31), \(V\) has an orthonormal basis consisting of eigenvectors of \(T{}\text{.}\) Thus by the last bullet point of Example 9.42, \(\det T\) equals a product of the eigenvalues of \(T{}\text{,}\) possibly with repetitions. Each eigenvalue of \(T\) is a nonnegative number (by Theorem 7.38). Thus we conclude that \(\det T \ge 0\text{.}\)
    🔗
    🔗
    Suppose \(V\) is an inner product space and \(T \in \Lc(V)\text{.}\) Recall that the list of nonnegative square roots of the eigenvalues of \(T^* T\) (each included as many times as its multiplicity) is called the list of singular values of \(T\) (see Section 7.5).

    Theorem 9.60. \(\lvert \det T \rvert =\) product of singular values of \(T\).

    Suppose \(V\) is an inner product space and \(T \in \Lc(V)\text{.}\) Then
    \begin{equation*} \lvert \det T \rvert = \sqrt{\det( T^*T )} = \text{ product of singular values of } T{}. \end{equation*}
    🔗
    🔗

    Proof.
    We have
    \begin{equation*} \lvert \det T \rvert ^2 = \overline{(\det T)} (\det T) = ( \det ( T^* ) )(\det T) = \det( T^* T ), \end{equation*}
    where the middle equality comes from Theorem 9.56(c) and the last equality comes from Theorem 9.49(a). Taking square roots of both sides of the equation above shows that \(\lvert \det T \rvert = \sqrt{\det( T^*T )}\text{.}\)
    🔗
    Let \(s_1, \ldots, s_n\) denote the list of singular values of \(T{}\text{.}\) Thus \({s_1}^{2}{}, \ldots, {s_n}^{2}\) is the list of eigenvalues of \(T^*T\) (with appropriate repetitions), corresponding to an orthonormal basis of \(V\) consisting of eigenvectors of \(T^*T{}\text{.}\) Hence the last bullet point of Example 9.42 implies that
    \begin{equation*} \det ( T^* T ) = {s_1}^{2} \cdots {s_n}^{2}{}. \end{equation*}
    🔗
    Thus \(\lvert \det T \rvert = s_1 \cdots s_n\text{,}\) as desired.

    Theorem 9.64. Cayley–Hamilton theorem.

    Suppose \(T \in \Lc(V)\) and \(q\) is the characteristic polynomial of \(T{}\text{.}\) Then \(q(T) =0\text{.}\)
    🔗
    🔗

    Proof.
    If \(\F{} = \C{}\text{,}\) then the equation \(q(T) = 0\) follows from Theorem 9.62 and Theorem 8.29.
    🔗
    Now suppose \(\F{} = \R{}\text{.}\) Fix a basis of \(V{}\text{,}\) and let \(A\) be the matrix of \(T\) with respect to this basis. Let \(S\) be the operator on \(\C {\dim V}\) such that the matrix of \(S\) \big(with respect to the standard basis of \(\C {\dim V}\)\big) is \(A\text{.}\) For all \(z \in \R{}\) we have
    \begin{equation*} q(z) = \det(zI - T) = \det(zI - A) = \det(zI - S). \end{equation*}
    🔗
    Thus \(q\) is the characteristic polynomial of \(S\text{.}\) The case \(\F{} = \C{}\) (first sentence of this proof) now implies that \(0 = q(S) = q(A) = q(T)\text{.}\)

    Theorem 9.65. characteristic polynomial, trace, and determinant.

    Suppose \(T \in \Lc(V)\text{.}\) Let \(n = \dim V{}\text{.}\) Then the characteristic polynomial of \(T\) can be written as
    \begin{equation*} z^n - (\tr T) z^{n-1} + \dots + (-1)^n (\det T). \end{equation*}
    🔗
    🔗

    Proof.
    The constant term of a polynomial function of \(z\) is the value of the polynomial when \(z = 0\text{.}\) Thus the constant term of the characteristic polynomial of \(T\) equals \(\det(-T)\text{,}\) which equals \((-1)^n \det T\) (by the third bullet point of Example 9.42).
    🔗
    Fix a basis of \(V{}\text{,}\) and let \(A\) be the matrix of \(T\) with respect to this basis. The matrix of \(zI - T\) with respect to this basis is \(zI - A\text{.}\) The term coming from the identity permutation \(\{ 1, \ldots, n \}\) in the formula 9.46 for \(\det(zI - A)\) is
    \begin{equation*} (z - A_{1,1}) \cdots (z - A_{n,n}). \end{equation*}
    🔗
    The coefficient of \(z^{n-1}\) in the expression above is \(-(A_{1,1} + \cdots + A_{n,n})\text{,}\) which equals \(-\tr T\text{.}\) The terms in the formula for \(\det(zI - A)\) coming from other elements of \(\perm n\) contain at most \(n-2\) factors of the form \(z - A_{k,k}\) and thus do not contribute to the coefficient of \(z^{n-1}\) in the characteristic polynomial of \(T{}\text{.}\)

    🔗
    In the result below, think of the columns of the \(n\)-by-\(n\) matrix \(A\) as elements of \(\FF{n}\text{.}\) The norms appearing below then arise from the standard inner product on \(\FF{n}\text{.}\) Recall that the notation \(R_{\cdot, k}\) in the proof below means the \(k^\nth\) column of the matrix \(R\) (as was defined in Notation 3.44).
    🔗

    Theorem 9.66. Hadamard’s inequality.

    Suppose \(A\) is an \(n\)-by-\(n\) matrix. Let \(v_1, \ldots, v_n\) denote the columns of \(A\text{.}\) Then
    \begin{equation*} \lvert \det A \rvert \le \prod_{k=1}^n \lVert v_k \rVert . \end{equation*}
    🔗
    🔗

    Proof.
    If \(A\) is not invertible, then \(\det A = 0\) and hence the desired inequality holds in this case.
    🔗
    Thus assume that \(A\) is invertible. The QR factorization Theorem 7.58 tells us that there exist a unitary matrix \(Q\) and an upper-triangular matrix \(R\) whose diagonal contains only positive numbers such that \(A = QR\text{.}\) We have
    \begin{align*} \lvert \det A \rvert \amp = \lvert \det Q \rvert \lvert \det R \rvert\\ \amp = \lvert \det R \rvert\\ \amp = \prod_{k=1}^n R_{k,k}\\ \amp \le \prod_{k=1}^n \lVert R_{\cdot, k} \rVert\\ \amp = \prod_{k=1}^n \lVert QR_{\cdot, k} \rVert\\ \amp = \prod_{k=1}^n \lVert v_k \rVert \text{,} \end{align*}
    where the first line comes from Theorem 9.49(b), the second line comes from Theorem 9.58, the third line comes from Theorem 9.48, and the fifth line holds because \(Q\) is an isometry.
    🔗
    🔗
    To give a geometric interpretation to Hadamard’s inequality, suppose \(\F{} = \R{}\text{.}\) Let \(T \in \Lc( \R n )\) be the operator such that \(Te_k = v_k\) for each \(k=1, \ldots, n\text{,}\) where \(e_1, \ldots, e_n\) is the standard basis of \(\RR n\text{.}\) Then \(T\) maps the box \(P(e_1, \ldots, e_n)\) onto the parallelepiped \(P(v_1, \ldots, v_n)\) [see 7.102 and Definition 7.105 for a review of this notation and terminology]. Because the box \(P(e_1, \ldots, e_n)\) has volume \(1\text{,}\) this implies (by Theorem 9.61) that the parallelepiped \(P(v_1, \ldots, v_n)\) has volume \(\lvert \det T \rvert\text{,}\) which equals \(\lvert \det A \rvert\text{.}\) Thus Hadamard’s inequality above can be interpreted to say that among all parallelepipeds whose edges have lengths \(\lVert v_1 \rVert , \ldots, \lVert v_n \rVert\text{,}\) the ones with largest volume have orthogonal edges \Big(and thus have volume \(\prod_{k=1}^n \lVert v_k \rVert\)\Big).

    🔗

    Theorem 9.67. determinant of Vandermonde matrix.

    Suppose \(n > 1\) and \(\beta_1, \ldots, \beta_n \in \F{}{}\text{.}\) Then
    \begin{equation*} \det \begin{pmatrix}1 \amp \beta_1 \amp {\beta_1}^{2} \amp \cdots \amp {\beta_1}^{n-1} \\ 1 \amp \beta_2 \amp {\beta_2}^{2} \amp \cdots \amp {\beta_2}^{n-1} \\ \\ \amp \amp \ddots \\ \\ 1 \amp \beta_n \amp {\beta_n}^{2} \amp \cdots \amp {\beta_n}^{n-1} \\ \end{pmatrix} = \prod_{1 \le j \lt k \le n} (\beta_k - \beta_j). \end{equation*}
    🔗
    🔗

    Proof.
    Let \(1, z, \ldots, z^{n-1}\) be the standard basis of \(\P{}_{n-1}(\F{})\) and let \(e_1, \ldots, e_n\) denote the standard basis of \(\FF n\text{.}\) Define a linear map \(\fun S { \P{}_{n-1}(\F{}) } { \F n }\) by
    \begin{equation*} Sp = ( p(\beta_1), \ldots, p(\beta_n) ). \end{equation*}
    🔗
    Let \(A\) denote the Vandermonde matrix shown in the statement of this result. Note that
    \begin{equation*} A = \M ( S, (1, z, \ldots, z^{n-1}), (e_1, \ldots, e_n) ). \end{equation*}
    🔗
    Let \(\fun T {\P{}_{n-1}(\F{})} {\P{}_{n-1}(\F{})}\) be the operator on \(\P{}_{n-1}(\F{})\) such that \(T1 = 1\) and
    \begin{equation*} Tz^k = (z - \beta_1) (z - \beta_2) \cdots (z - \beta_k) \end{equation*}
    for \(k= 1, \ldots, n-1\text{.}\) Let \(B = \M( T, (1, z, \ldots, z^{n-1}), (1, z, \ldots, z^{n-1}) )\text{.}\) Then \(B\) is an upper-triangular matrix all of whose diagonal entries equal \(1\text{.}\) Thus \(\det B = 1\) (by Theorem 9.48).
    🔗
    Let \(C = \M( ST, (1, z, \ldots, z^{n-1} ), (e_1, \ldots, e_n) )\text{.}\) Thus \(C = AB\) (by Theorem 3.81), which implies that
    \begin{equation*} \det A= (\det A)(\det B) =\det C. \end{equation*}
    🔗
    The definitions of \(C\text{,}\) \(S\text{,}\) and \(T\) show that \(C\) equals {
    \begin{equation*} \begin{pmatrix}1 \amp 0 \amp 0 \amp \cdots \amp 0 \\ 1 \amp \beta_2 - \beta_1 \amp 0\amp \cdots \amp 0 \\ 1 \amp \beta_3 - \beta_1 \amp (\beta_3 - \beta_1)(\beta_3 - \beta_2) \amp \cdots \amp 0 \\ \\ \amp \amp \amp \ddots \\ \\ 1 \amp \beta_n - \beta _1 \amp (\beta_n - \beta_1)(\beta_n - \beta_2) \amp \cdots \amp (\beta_n - \beta_1) (\beta_n - \beta_2) \cdots (\beta_n- \beta_{n-1} ) \end{pmatrix} . \end{equation*}
    🔗
    Now \(\displaystyle \det A = \det C = \prod_{1 \le j \lt k \le n} (\beta_k - \beta_j)\text{,}\) where we have used 9.56(a) and Theorem 9.48.

    20.

    Suppose \(A\) is an \(n\)-by-\(n\) matrix, and suppose \(c\) is such that \(\lvert A_{j,k} \rvert \le c\) for all \(j, k \in \{ 1, \ldots, n \}\text{.}\) Prove that

    21.

    Suppose \(n\) is a positive integer and \(\fun \delta {\C{n,n}} {\C{}}\) is a function such that
    \begin{equation*} \delta(AB) = \delta(A) \cdot \delta(B) \end{equation*}
    for all \(A, B \in \C{n,n}\) and \(\delta(A)\) equals the product of the diagonal entries of \(A\) for each diagonal matrix \(A \in \C{n,n}\text{.}\) Prove that
    \begin{equation*} \delta(A) = \det A \end{equation*}
    for all \(A \in \C{n,n}\text{.}\) Note: Recall that \(\C{n,n}\) denotes the set of \(n\)-by-\(n\) matrices with entries in  \(\C{}\text{.}\) This exercise shows that the determinant is the unique function defined on square matrices that is multiplicative and has the desired behavior on diagonal matrices. This result is analogous to Exercise 8.4.10 in Section 8.4, which shows that the trace is uniquely determined by its algebraic properties.
