    Section 1.2 Definition of Vector Space

    The motivation for the definition of a vector space comes from properties of addition and scalar multiplication in \(\F{n}\text{:}\) Addition is commutative, associative, and has an identity. Every element has an additive inverse. Scalar multiplication is associative. Scalar multiplication by \(1\) acts as expected. Addition and scalar multiplication are connected by distributive properties.
    🔗
    We will define a vector space to be a set \(V\) with an addition and a scalar multiplication on \(V\) that satisfy the properties in the paragraph above.
    🔗

    Definition 1.19. addition, scalar multiplication.

    1. An addition on a set \(V\) is a function that assigns an element \(u + v \in V\) to each pair of elements \(u, v \in V{}\text{.}\)
      🔗
      🔗
    2. A scalar multiplication on a set \(V\) is a function that assigns an element \(\lambda v \in V\) to each \(\lambda \in \F{}\) and each \(v \in V{}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Now we are ready to give the formal definition of a vector space.
    🔗

    Definition 1.20. vector space.

    A vector space is a set \(V\) along with an addition on \(V\) and a scalar multiplication on \(V\) such that the following properties hold.
    1. commutativity.
      \(u + v = v + u\) for all \(u, v \in V{}\text{.}\)
      🔗
      🔗
    2. associativity.
      \((u + v) + w = u + (v + w)\) and \((ab)v = a(bv)\) for all \(u, v, w \in V\) and for all \(a, b \in \F{}{}\text{.}\)
      🔗
      🔗
    3. additive identity.
      There exists an element \(0 \in V\) such that \(v + 0 = v\) for all \(v \in V{}\text{.}\)
      🔗
      🔗
    4. additive inverse.
      For every \(v \in V{}\text{,}\) there exists \(w \in V\) such that \(v + w = 0\text{.}\)
      🔗
      🔗
    5. multiplicative identity.
      \(1v = v\) for all \(v \in V{}\text{.}\)
      🔗
      🔗
    6. distributive properties.
      \(a(u + v) = au + av\) and \((a + b)v = av + bv\) for all \(a, b \in \F{}\) and all \(u, v \in V{}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    The following geometric language sometimes aids our intuition.
    🔗

    Definition 1.21. vector, point.

    Elements of a vector space are called vectors or points.
    🔗
    🔗
    The scalar multiplication in a vector space depends on \(\F{}{}\text{.}\) Thus when we need to be precise, we will say that \(V\) is a vector space over \(\F{}\) instead of saying simply that \(V\) is a vector space. For example, \(\R{n}\) is a vector space over \(\R{}\text{,}\) and \(\C{n}\) is a vector space over \(\C{}\text{.}\)
    🔗

    Definition 1.22. real vector space, complex vector space.

    1. A vector space over \(\R{}\) is called a real vector space.
      🔗
      🔗
    2. A vector space over \(\C{}\) is called a complex vector space.
      🔗
      🔗
    🔗
    🔗
    Usually the choice of \(\F{}\) is either clear from the context or irrelevant. Thus we often assume that \(\F{}\) is lurking in the background without specifically mentioning it.
    🔗

    Aside
    The simplest vector space is \(\{0\}\text{,}\) which contains only one point.
    🔗
    With the usual operations of addition and scalar multiplication, \(\F{n}\) is a vector space over \(\F{}{}\text{,}\) as you should verify. The example of \(\F{n}\) motivated our definition of vector space.
    🔗

    Example 1.23. \(\F{\infty}\).

    \(\F{\infty}\) is defined to be the set of all sequences of elements of \(\F{}\text{:}\)
    \begin{equation*} \F{\infty} = \{ (x_1, x_2, \dotsc) : x_k \in \F{} \ for\ k = 1, 2, \dotsc \}. \end{equation*}
    🔗
    Addition and scalar multiplication on \(\F{\infty}\) are defined as expected:
    \begin{gather*} (x_1, x_2, \dotsc) + (y_1, y_2, \dotsc) = (x_1 + y_1, x_2 + y_2, \dotsc),\\ \lambda(x_1, x_2, \dotsc) = (\lambda x_1, \lambda x_2, \dotsc)\text{.} \end{gather*}
    🔗
    With these definitions, \(\F{\infty}\) becomes a vector space over \(\F{}{}\text{,}\) as you should verify. The additive identity in this vector space is the sequence of all \(0\)’s.
    🔗
    🔗
    Our next example of a vector space involves a set of functions.
    🔗

    Notation 1.24. \(\F{S}\).

    1. If \(S\) is a set, then \(\F{S}\) denotes the set of functions from \(S\) to \(\F{}{}\text{.}\)
      🔗
      🔗
    2. For \(f, g \in \FF{S}\text{,}\) the sum \(f + g \in \F{S}\) is the function defined by
      \begin{equation*} (f + g)(x) = f(x) + g (x) \end{equation*}
      for all \(x \in S\text{.}\)
      🔗
      🔗
    3. For \(\lambda \in \F{}\) and \(f\in \FF{S}\text{,}\) the product \(\lambda f \in \F{S}\) is the function defined by
      \begin{equation*} (\lambda f)(x) = \lambda f(x) \end{equation*}
      for all \(x \in S\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗
    As an example of the notation above, if \(S\) is the interval \([0, 1]\) and \(\F{} = \R{}\text{,}\) then \(\R{[0, 1]}\) is the set of real-valued functions on the interval \([0, 1]\text{.}\)
    🔗
    You should verify all three bullet points in the next example.
    🔗

    Example 1.25. \(\F{S}\) is a vector space.

    1. If \(S\) is a nonempty set, then \(\F{S}\) (with the operations of addition and scalar multiplication as defined above) is a vector space over \(\F{}{}\text{.}\)
      🔗
      🔗
    2. The additive identity of \(\F{S}\) is the function \(0: S \to \F{}\) defined by
      \begin{equation*} 0(x) = 0 \end{equation*}
      for all \(x \in S\text{.}\)
      🔗
      🔗
    3. For \(f \in \FF{S}\text{,}\) the additive inverse of \(f\) is the function \(-f: S \to \F{}\) defined by
      \begin{equation*} (-f)(x) = -f(x) \end{equation*}
      for all \(x \in S\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Aside
    The elements of the vector space \(\R{[0,1]}\) are real-valued functions on \([0, 1]\text{,}\) not lists. In general, a vector space is an abstract entity whose elements might be lists, functions, or weird objects.
    🔗
    The vector space \(\F{n}\) is a special case of the vector space \(\F{S}\) because each \((x_1, \ldots, x_n) \in \F{n}\) can be thought of as a function \(x\) from the set \(\{1, 2, \dots, n\}\) to \(\F{}\) by writing \(x(k)\) instead of \(x_k\) for the \(k^\nth\) coordinate of \((x_1, \dots, x_n)\text{.}\) In other words, we can think of \(\F{n}\) as \(\FF{\{1, 2, \dots, n\}}\text{.}\) Similarly, we can think of \(\F{\infty}\) as \(\FF{\{1, 2, \dots \}}\text{.}\)
    🔗
    Soon we will see further examples of vector spaces, but first we need to develop some of the elementary properties of vector spaces.
    🔗
    The definition of a vector space requires it to have an additive identity. The next result states that this identity is unique.
    🔗

    Theorem 1.26. unique additive identity.

    A vector space has a unique additive identity.
    🔗
    🔗

    Proof.
    Suppose \(0\) and \(0'\) are both additive identities for some vector space \(V{}\text{.}\) Then
    \begin{equation*} 0' = 0' + 0 = 0 + 0' = 0, \end{equation*}
    where the first equality holds because \(0\) is an additive identity, the second equality comes from commutativity, and the third equality holds because \(0'\) is an additive identity. Thus \(0' = 0\text{,}\) proving that \(V\) has only one additive identity.
    🔗
    🔗
    Each element \(v\) in a vector space has an additive inverse, an element \(w\) in the vector space such that \(v + w = 0\text{.}\) The next result shows that each element in a vector space has only one additive inverse.
    🔗

    Theorem 1.27. unique additive inverse.

    Every element in a vector space has a unique additive inverse.
    🔗
    🔗

    Proof.
    Suppose \(V\) is a vector space. Let \(v \in V{}\text{.}\) Suppose \(w\) and \(w'\) are additive inverses of \(v\text{.}\) Then
    \begin{equation*} w = w + 0 = w + (v + w') = (w + v) + w' = 0 + w' = w'\!. \end{equation*}
    🔗
    Thus \(w = w'\!\text{,}\) as desired.
    🔗
    🔗
    Because additive inverses are unique, the following notation now makes sense.
    🔗

    Notation 1.28. \(-v\text{,}\) \(w - v\).

    Let \(v, w \in V{}\text{.}\) Then
    1. \(-v\) denotes the additive inverse of \(v\text{;}\)
      🔗
      🔗
    2. \(w - v\) is defined to be \(w + (-v)\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Almost all results in this book involve some vector space. To avoid having to restate frequently that \(V\) is a vector space, we now make the necessary declaration once and for all.
    🔗

    Notation 1.29. \(V\).

    For the rest of this book, \(V\) denotes a vector space over \(\F{}{}\text{.}\)
    🔗
    🔗
    🔗
    In the next result, \(0\) denotes a scalar (the number \(0 \in \F{}\)) on the left side of the equation and a vector (the additive identity of \(V\)) on the right side of the equation.
    🔗

    Theorem 1.30. the number \(0\) times a vector.

    \(0v = 0\) for every \(v \in V{}\text{.}\)
    🔗
    🔗

    Aside
    The result in Theorem 1.30 involves the additive identity of \(V\) and scalar multiplication. The only part of the definition of a vector space that connects vector addition and scalar multiplication is the distributive property. Thus the distributive property must be used in the proof of Theorem 1.30.
    🔗
    🔗

    Proof.
    For \(v \in V{}\text{,}\) we have
    \begin{equation*} 0v = (0 + 0)v = 0v + 0v. \end{equation*}
    🔗
    Adding the additive inverse of \(0v\) to both sides of the equation above gives \(0 = 0v\text{,}\) as desired.
    🔗
    🔗
    In the next result, \(0\) denotes the additive identity of \(V{}\text{.}\) Although their proofs are similar, Theorem 1.30 and Theorem 1.31 are not identical. More precisely, Theorem 1.30 states that the product of the scalar \(0\) and any vector equals the vector \(0\text{,}\) whereas 1.31 states that the product of any scalar and the vector \(0\) equals the vector \(0\text{.}\)
    🔗

    Theorem 1.31. a number times the vector \(0\).

    \(a0 = 0\) for every \(a \in \F{}{}\text{.}\)
    🔗
    🔗

    Proof.
    For \(a \in \F{}{}\text{,}\) we have
    \begin{equation*} a0 = a(0 + 0) = a0 + a0. \end{equation*}
    🔗
    Adding the additive inverse of \(a0\) to both sides of the equation above gives \(0 = a0\text{,}\) as desired.
    🔗
    🔗
    Now we show that if an element of \(V\) is multiplied by the scalar \(-1\text{,}\) then the result is the additive inverse of the element of \(V{}\text{.}\)
    🔗

    Theorem 1.32. the number \(-1\) times a vector.

    \((-1)v = -v\) for every \(v \in V{}\text{.}\)
    🔗
    🔗

    Proof.
    For \(v \in V{}\text{,}\) we have
    \begin{equation*} v + (-1)v = 1v + (-1)v = \bigl(1 + (-1)\bigr)v = 0v = 0. \end{equation*}
    🔗
    This equation says that \((-1)v\text{,}\) when added to \(v\text{,}\) gives \(0\text{.}\) Thus \((-1)v\) is the additive inverse of \(v\text{,}\) as desired.
    🔗
    🔗

    Exercises Exercises

    1.

    Prove that \(-(-v) = v\) for every \(v \in V{}\text{.}\)
    🔗
    🔗

    2.

    Suppose \(a \in \F{}{}\text{,}\) \(v \in V{}\text{,}\) and \(av = 0\text{.}\) Prove that \(a = 0\) or \(v = 0\text{.}\)
    🔗
    🔗

    3.

    Suppose \(v, w \in V{}\text{.}\) Explain why there exists a unique \(x \in V\) such that \(v + 3x = w\text{.}\)
    🔗
    🔗

    4.

    The empty set is not a vector space. The empty set fails to satisfy only one of the requirements listed in the definition of a vector space Definition 1.20. Which one?
    🔗
    🔗

    5.

    Show that in the definition of a vector space Definition 1.20, the additive inverse condition can be replaced with the condition that
    \begin{equation*} 0v = 0 \text{ for all } v \in V{}. \end{equation*}
    🔗
    Here the \(0\) on the left side is the number \(0\text{,}\) and the \(0\) on the right side is the additive identity of \(V{}\text{.}\) Note: The phrase a “condition can be replaced” in a definition means that the collection of objects satisfying the definition is unchanged if the original condition is replaced with the new condition.
    🔗
    🔗

    6.

    Let \(\infty\) and \(-\infty\) denote two distinct objects, neither of which is in \(\R{}\text{.}\) Define an addition and scalar multiplication on \(\R{} \cup \{\infty, -\infty\}\) as you could guess from the notation. Specifically, the sum and product of two real numbers is as usual, and for \(t \in \R{}\) define
    \begin{equation*} t \infty = \begin{cases}-\infty \amp \text{ if } t \lt 0,\\ 0 \amp \text{ if } t = 0,\\ \infty \amp \text{ if } t > 0, \end{cases} t (-\infty) = \begin{cases}\infty \amp \text{ if } t \lt 0,\\ 0 \amp \text{ if } t = 0,\\ -\infty \amp \text{ if } t > 0, \end{cases} \end{equation*}
    and
    \begin{align*} t + \infty \amp = \infty + t = \infty + \infty = \infty,\\ t + (-\infty) \amp = (-\infty) + t = (-\infty) + (-\infty) = -\infty,\\ \infty + (-\infty) \amp = (-\infty) + \infty = 0\text{.} \end{align*}
    🔗
    With these operations of addition and scalar multiplication, is \(\R{} \cup \{\infty,-\infty\}\) a vector space over \(\R{}\text{?}\) Explain.
    🔗
    🔗

    7.

    Suppose \(S\) is a nonempty set. Let \(V^S\) denote the set of functions from \(S\) to \(V{}\text{.}\) Define a natural addition and scalar multiplication on \(V^S\!\text{,}\) and show that \(V^S\) is a vector space with these definitions.
    🔗
    🔗

    8.

    Suppose \(V\) is a real vector space.
    1. The complexification of \(V{}\text{,}\) denoted by \(V{}_{\C{}}\text{,}\) equals \(V{} \times V{}\text{.}\) An element of \(V{}_{\C{}}\) is an ordered pair \((u, v)\text{,}\) where \(u, v \in V{}\text{,}\) but we write this as \(u + iv\text{.}\)
      🔗
      🔗
    2. Addition on \(V{}_{\C{}}\) is defined by
      \begin{equation*} (u_1 + i v_1) + (u_2 + i v_2) = (u_1 + u_2) + i (v_1 + v_2) \end{equation*}
      for all \(u_1, v_1, u_2, v_2 \in V{}\text{.}\)
      🔗
      🔗
    3. Complex scalar multiplication on \(V{}_{\C{}}\) is defined by
      \begin{equation*} (a + bi)(u + iv) = (au - bv) + i(av + bu) \end{equation*}
      for all \(a, b \in \R{}\) and all \(u, v \in V{}\text{.}\)
      🔗
      🔗
    🔗
    Prove that with the definitions of addition and scalar multiplication as above, \(V{}_{\C{}}\) is a complex vector space. Note: Think of \(V\) as a subset of \(V{}_{\C{}}\) by identifying \(u \in V\) with \(u + i0\text{.}\) The construction of \(V{}_{\C{}}\) from \(V\) can then be thought of as generalizing the construction of \(\C{n}\) from \(\RR{n}\text{.}\)
