    Section 9.2 Alternating Multilinear Forms

    Subsection 9.2.1 Multilinear Forms

    Definition 9.24. \(V^m\).

    For \(m\) a positive integer, define \(V^m\) by
    \begin{equation*} V^m = \underbrace{V{} \times \cdots \times V}_{m \textit{ times}}\!. \end{equation*}
    🔗
    🔗
    Now we can define \(m\)-linear forms as a generalization of the bilinear forms that we discussed in the previous section.
    🔗

    Definition 9.25. \(m\)-linear form, \(V^{(m)}\text{,}\) multilinear form.

    1. For \(m\) a positive integer, an \(m\)-linear form on \(V\) is a function \(\fun \beta {V^m{}} {\F{}}\) that is linear in each slot when the other slots are held fixed. This means that for each \(k \in \{ 1, \ldots, m \}\) and all \(u_1, \ldots, u_m \in V{}\text{,}\) the function
      \begin{equation*} v \mapsto \beta(u_1, \ldots, u_{k-1}, v, u_{k+1}, \ldots, u_m) \end{equation*}
      is a linear map from \(V\) to \(\F{}{}\text{.}\)
      🔗
      🔗
    2. The set of \(m\)-linear forms on \(V\) is denoted by \(V^{(m)}\!\text{.}\)
      🔗
      🔗
    3. A function \(\beta\) is called a multilinear form on \(V\) if it is an \(m\)-linear form on \(V\) for some positive integer \(m\text{.}\)
      🔗
      🔗
    🔗
    🔗
    In the definition above, the expression \(\beta(u_1, \ldots, u_{k-1}, v, u_{k+1}, \ldots, u_m)\) means \(\beta(v, u_2, \ldots, u_m)\) if \(k = 1\) and means \(\beta(u_1, \ldots, u_{m-1}, v)\) if \(k = m\text{.}\)
    🔗
    A \(1\)-linear form on \(V\) is a linear functional on \(V{}\text{.}\) A \(2\)-linear form on \(V\) is a bilinear form on \(V{}\text{.}\) You can verify that with the usual addition and scalar multiplication of functions, \(V^{(m)}\) is a vector space.
    🔗

    Example 9.26. \(m\)-linear forms.

    1. Suppose \(\alpha , \rho \in V^{(2)}\!\text{.}\) Define a function \(\fun \beta {V^4} {\F{}}\) by
      \begin{equation*} \beta(v_1, v_2, v_3, v_4) = \alpha (v_1, v_2) \rho(v_3, v_4). \end{equation*}
      Then \(\beta \in V^{(4)}\!\text{.}\)
      🔗
      🔗
    2. Define \(\fun \beta { ( \Lc(V) )^m } {\F{}}\) by
      \begin{equation*} \beta(T_1, \ldots, T_m) = \tr(T_1 \cdots T_m). \end{equation*}
      Then \(\beta\) is an \(m\)-linear form on \(\Lc(V)\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Alternating multilinear forms, which we now define, play an important role as we head toward defining determinants.
    🔗

    Definition 9.27. alternating forms, \(V^{(m)}_{alt}\).

    Suppose \(m\) is a positive integer.
    1. An \(m\)-linear form \(\alpha\) on \(V\) is called alternating if \(\alpha (v_1, \ldots, v_m) = 0\) whenever \(v_1, \ldots, v_m\) is a list of vectors in \(V\) with \(v_j = v_k\) for some two distinct values of \(j\) and \(k\) in \(\{ 1, \ldots, m \}\text{.}\)
      🔗
      🔗
    2. \(V^{(m)}_{\text{ alt } } = \{ \alpha \in V^{(m)}: \alpha \text{ is an alternating \(m\)-linear form on } V \}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    You should verify that \(V^{(m)}_{\text{ alt } }\) is a subspace of \(V^{(m)}\!\text{.}\) See Example 9.15 for examples of alternating \(2\)-linear forms. See Exercise 9.2.2.2 for an example of an alternating \(3\)-linear form.
    🔗
    The next result tells us that if a linearly dependent list is input to an alternating multilinear form, then the output equals \(0\text{.}\)
    🔗

    Theorem 9.28. alternating multilinear forms and linear dependence.

    Suppose \(m\) is a positive integer and \(\alpha\) is an alternating \(m\)-linear form on \(V{}\text{.}\) If \(v_1, \ldots, v_m\) is a linearly dependent list in \(V{}\text{,}\) then
    \begin{equation*} \alpha (v_1, \ldots, v_m) = 0. \end{equation*}
    🔗
    🔗

    Proof.
    Suppose \(v_1, \ldots, v_m\) is a linearly dependent list in \(V{}\text{.}\) By the linear dependence lemma Theorem 2.19, some \(v_k\) is a linear combination of \(v_1, \ldots, v_{k-1}\text{.}\) Thus there exist \(b_1, \ldots, b_{k-1}\) such that \(v_k = b_1 v_1 + \cdots + b_{k-1} v_{k-1}\text{.}\) Now
    \begin{align*} \alpha (v_1, \ldots, v_m) \amp = \alpha ( v_1, \ldots, v_{k-1}, \sum_{j=1}^{k-1} b_j v_j, v_{k+1}, \ldots, v_m )\\ \amp = \sum_{j=1}^{k-1} b_j \alpha ( v_1, \ldots, v_{k-1}, v_j, v_{k+1}, \ldots, v_m)\\ \amp = 0. \rlap{\text{ \qedsymbol } } \end{align*}
    🔗
    \addvspace{14bp}
    🔗
    The next result states that if \(m > \dim V{}\text{,}\) then there are no alternating \(m\)-linear forms on \(V\) other than the function on \(V^m\) that is identically \(0\text{.}\)
    🔗
    🔗

    Theorem 9.29. no nonzero alternating \(m\)-linear forms for \(m > \dim V\).

    Suppose \(m > \dim V{}\text{.}\) Then \(0\) is the only alternating \(m\)-linear form on \(V{}\text{.}\)
    🔗
    🔗

    Proof.
    Suppose that \(\alpha\) is an alternating \(m\)-linear form on \(V\) and \(v_1, \ldots, v_m \in V{}\text{.}\) Because \(m > \dim V{}\text{,}\) this list is not linearly independent (by Theorem 2.22). Thus 9.28 implies that \(\alpha (v_1, \ldots, v_m) = 0\text{.}\) Hence \(\alpha\) is the zero function from \(V^m\) to \(\F{}{}\text{.}\)
    🔗
    🔗
    🔗

    Subsection 9.2.2 Alternating Multilinear Forms and Permutations

    Theorem 9.30. swapping input vectors in an alternating multilinear form.

    Suppose \(m\) is a positive integer, \(\alpha\) is an alternating \(m\)-linear form on \(V{}\text{,}\) and \(v_1, \ldots, v_m\) is a list of vectors in \(V{}\text{.}\) Then swapping the vectors in any two slots of \(\alpha (v_1, \ldots, v_m)\) changes the value of \(\alpha\) by a factor of \(-1\text{.}\)
    🔗
    🔗

    Proof.
    Put \(v_1 + v_2\) in both the first two slots, getting
    \begin{equation*} 0 = \alpha (v_1 + v_2, v_1 + v_2, v_3, \ldots, v_m). \end{equation*}
    🔗
    Use the multilinear properties of \(\alpha\) to expand the right side of the equation above (as in the proof of Theorem 9.16) to get
    \begin{equation*} \alpha (v_2, v_1, v_3, \ldots, v_m) = -\alpha (v_1, v_2, v_3, \ldots, v_m). \end{equation*}
    🔗
    Similarly, swapping the vectors in any two slots of \(\alpha (v_1, \ldots, v_m)\) changes the value of \(\alpha\) by a factor of \(-1\text{.}\)
    🔗
    🔗
    To see what can happen with multiple swaps, suppose \(\alpha\) is an alternating \(3\)-linear form on \(V\) and \(v_1, v_2, v_3 \in V{}\text{.}\) To evaluate \(\alpha (v_3, v_1, v_2)\) in terms of \(\alpha (v_1, v_2, v_3)\text{,}\) start with \(\alpha (v_3, v_1, v_2)\) and swap the entries in the first and third slots, getting \(\alpha (v_3, v_1, v_2) = -\alpha (v_2, v_1, v_3)\text{.}\) Now in the last expression, swap the entries in the first and second slots, getting
    \begin{equation*} \alpha (v_3, v_1, v_2) = -\alpha (v_2, v_1, v_3) = \alpha (v_1, v_2, v_3). \end{equation*}
    🔗
    More generally, we see that if we do an odd number of swaps, then the value of \(\alpha\) changes by a factor of \(-1\text{,}\) and if we do an even number of swaps, then the value of \(\alpha\) does not change.
    🔗
    To deal with arbitrary multiple swaps, we need a bit of information about permutations.
    🔗

    Definition 9.31. permutation, \(\perm m\).

    Suppose \(m\) is a positive integer.
    1. A permutation of \((1, \ldots, m)\) is a list \((j_1, \ldots, j_m)\) that contains each of the numbers \(1, \ldots, m\) exactly once.
      🔗
      🔗
    2. The set of all permutations of \((1, \ldots, m)\) is denoted by \(\perm m\text{.}\)
      🔗
      🔗
    🔗
    🔗
    For example, \((2, 3, 4, 5, 1) \in \perm 5\text{.}\) You should think of an element of \(\perm m\) as a rearrangement of the first \(m\) positive integers.
    🔗
    The number of swaps used to change a permutation \((j_1, \ldots, j_m)\) to the standard order \((1, \ldots, m)\) can depend on the specific swaps selected. The following definition has the advantage of assigning a well-defined sign to every permutation.
    🔗

    Definition 9.32. sign of a permutation.

    The sign of a permutation \((j_1, \ldots, j_m)\) is defined by
    \begin{equation*} \sign(j_1, \ldots, j_m) = (-1)^N{}, \end{equation*}
    where \(N\) is the number of pairs of integers \((k,\ell)\) with \(1 \le k \lt \ell \le m\) such that \(k\) appears after \(\ell\) in the list \((j_1, \ldots, j_m)\text{.}\)
    🔗
    🔗
    Hence the sign of a permutation equals \(1\) if the natural order has been changed an even number of times and equals \(-1\) if the natural order has been changed an odd number of times.
    🔗

    Example 9.33. signs.

    1. The permutation \((1, \ldots, m)\) [no changes in the natural order] has sign \(1\text{.}\)
      🔗
      🔗
    2. The only pair of integers \((k, \ell)\) with \(k \lt \ell\) such that \(k\) appears after \(\ell\) in the list \((2, 1, 3, 4)\) is \((1, 2)\text{.}\) Thus the permutation \((2, 1, 3, 4)\) has sign \(-1\text{.}\)
      🔗
      🔗
    3. In the permutation \((2, 3, \ldots, m, 1)\text{,}\) the only pairs \((k, \ell)\) with \(k \lt \ell\) that appear with changed order are \((1, 2), (1, 3), \ldots, (1,m)\text{.}\) Because we have \(m-1\) such pairs, the sign of this permutation equals \((-1)^{m-1}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Theorem 9.34. swapping two entries in a permutation.

    Swapping two entries in a permutation multiplies the sign of the permutation by  \(-1\text{.}\)
    🔗
    🔗

    Proof.
    Suppose we have two permutations, where the second permutation is obtained from the first by swapping two entries. The two swapped entries were in their natural order in the first permutation if and only if they are not in their natural order in the second permutation. Thus we have a net change (so far) of \(1\) or \(-1\) (both odd numbers) in the number of pairs not in their natural order.
    🔗
    Consider each entry between the two swapped entries. If an intermediate entry was originally in the natural order with respect to both swapped entries, then it is now in the natural order with respect to neither swapped entry. Similarly, if an intermediate entry was originally in the natural order with respect to neither of the swapped entries, then it is now in the natural order with respect to both swapped entries. If an intermediate entry was originally in the natural order with respect to exactly one of the swapped entries, then that is still true. Thus the net change (for each pair containing an entry between the two swapped entries) in the number of pairs not in their natural order is \(2\text{,}\) \(-2\text{,}\) or \(0\) (all even numbers).
    🔗
    For all other pairs of entries, there is no change in whether or not they are in their natural order. Thus the total net change in the number of pairs not in their natural order is an odd number. Hence the sign of the second permutation equals \(-1\) times the sign of the first permutation.
    🔗
    🔗

    Theorem 9.35. permutations and alternating multilinear forms.

    Suppose \(m\) is a positive integer and \(\alpha \in V_{\text{ alt } }^{(m)}{}\text{.}\) Then
    \begin{equation*} \alpha (v_{j_1}, \ldots, v_{j_m}) = ( \sign(j_1, \ldots, j_m) ) \alpha (v_1, \ldots, v_m) \end{equation*}
    for every list \(v_1, \ldots, v_m\) of vectors in \(V\) and all \((j_1, \ldots, j_m) \in \perm m\text{.}\)
    🔗
    🔗

    Proof.
    Suppose \(v_1, \ldots, v_m \in V\) and \((j_1, \ldots, j_m) \in \perm m\text{.}\) We can get from \((j_1, \ldots, j_m)\) to \((1, \ldots, m)\) by a series of swaps of entries in different slots. Each such swap changes the value of \(\alpha\) by a factor of \(-1\) (by Theorem 9.30) and also changes the sign of the remaining permutation by a factor of \(-1\) (by Theorem 9.34). After an appropriate number of swaps, we reach the permutation \(1, \ldots, m\text{,}\) which has sign \(1\text{.}\) Thus the value of \(\alpha\) changed signs an even number of times if \(\sign(j_1, \ldots, j_m) = 1\) and an odd number of times if \(\sign(j_1, \ldots, j_m) = -1\text{,}\) which gives the desired result.
    🔗
    🔗
    Our use of permutations now leads in a natural way to the following beautiful formula for alternating \(n\)-linear forms on an \(n\)-dimensional vector space.
    🔗

    Theorem 9.36. formula for \((\dim V)\)-linear alternating forms on \(V\).

    Let \(n = \dim V{}\text{.}\) Suppose \(e_1, \ldots, e_n\) is a basis of \(V\) and \(v_1, \ldots, v_n \in V{}\text{.}\) For each \(k \in \{ 1, \ldots, n \}\text{,}\) let \(b_{1, k}, \ldots, b_{n, k} \in \F{}\) be such that
    \begin{equation*} v_k = \sum_{j=1}^n b_{j,k} e_j. \end{equation*}
    🔗
    Then
    \begin{equation*} \alpha (v_1, \ldots, v_n) = \alpha ( e_1, \ldots, e_n ) \sum_{(j_1, \ldots, j_n) \in \perm n} ( \sign(j_1, \ldots, j_n) ) b_{j_1,1} \cdots b_{j_n,n} \end{equation*}
    for every alternating \(n\)-linear form \(\alpha\) on \(V{}\text{.}\)
    🔗
    🔗

    Proof.
    Suppose \(\alpha\) is an alternating \(n\)-linear form \(\alpha\) on \(V{}\text{.}\) Then
    \begin{align*} \alpha (v_1, \ldots, v_n) \amp = \alpha ( \sum_{j_1=1}^n b_{j_1,1} e_{j_1}, \ldots, \sum_{j_n=1}^n b_{j_n,n} e_{j_n} )\\ \amp = \sum_{j_1=1}^n \cdots \sum_{j_n=1}^n b_{j_1,1} \cdots b_{j_n,n} \alpha ( e_{j_1}, \ldots, e_{j_n} )\\ \amp = \sum_{(j_1, \ldots, j_n) \in \perm n} b_{j_1,1} \cdots b_{j_n,n} \alpha ( e_{j_1}, \ldots, e_{j_n} )\\ \amp = \alpha ( e_1, \ldots, e_n ) \sum_{(j_1, \ldots, j_n) \in \perm n} ( \sign(j_1, \ldots, j_n) ) b_{j_1,1} \cdots b_{j_n,n}\text{,} \end{align*}
    where the third line holds because \(\alpha ( e_{j_1}, \ldots, e_{j_n} ) = 0\) if \(j_1, \ldots, j_n\) are not distinct integers, and the last line holds by Theorem 9.35.
    🔗
    🔗
    The following result will be the key to our definition of the determinant in the next section.
    🔗

    Theorem 9.37. \(\dim V^{(\dim V)}_{alt} = 1\).

    The vector space \(V^{(\dim V)}_{\text{ alt } }\) has dimension one.
    🔗
    🔗

    Proof.
    Let \(n = \dim V{}\text{.}\) Suppose \(\alpha\) and \(\alpha '\) are alternating \(n\)-linear forms on \(V\) with \(\alpha \ne 0\text{.}\) Let \(e_1, \ldots, e_n\) be such that \(\alpha (e_1, \ldots, e_n) \ne 0\text{.}\) There exists \(c \in \F{}\) such that
    \begin{equation*} \alpha '(e_1, \ldots, e_n) = c \alpha (e_1, \ldots, e_n). \end{equation*}
    🔗
    Furthermore, Theorem 9.28 implies that \(e_1, \ldots, e_n\) is linearly independent and thus is a basis of \(V{}\text{.}\)
    🔗
    Suppose \(v_1, \ldots, v_n \in V{}\text{.}\) Let \(b_{j,k}\) be as in Theorem 9.36 for \(j,k = 1, \ldots, n\text{.}\) Then
    \begin{align*} \alpha '(v_1, \ldots, v_n) \amp = \alpha '( e_1, \ldots, e_n ) \sum_{(j_1, \ldots, j_n) \in \perm n} ( \sign(j_1, \ldots, j_n) ) b_{j_1,1} \cdots b_{j_n,n}\\ \amp = c \alpha ( e_1, \ldots, e_n ) \sum_{(j_1, \ldots, j_n) \in \perm n} ( \sign(j_1, \ldots, j_n) ) b_{j_1,1} \cdots b_{j_n,n}\\ \amp = c \alpha (v_1, \ldots, v_n)\text{,} \end{align*}
    where the first and last lines above come from Theorem 9.36. The equation above implies that \(\alpha ' = c \alpha\text{.}\) Thus \(\alpha '\!, \alpha\) is not a linearly independent list, which implies that \(\dim V^{(n)}_{\text{ alt } } \le 1\text{.}\)
    🔗
    To complete the proof, we only need to show that there exists a nonzero alternating \(n\)-linear form \(\alpha\) on \(V\) \big(thus eliminating the possibility that \(\dim V^{(n)}_{\text{ alt } }\) equals \(0\)\big). To do this, let \(e_1, \ldots, e_n\) be any basis of \(V{}\text{,}\) and let \(\phi_1, \ldots, \phi_n \in V'\) be the linear functionals on \(V\) that allow us to express each element of \(V\) as a linear combination of \(e_1, \ldots, e_n\text{.}\) In other words,
    \begin{equation*} v = \sum_{j=1}^n \phi_j(v) e_j \end{equation*}
    for every \(v \in V{}\) (see 3.114). Now for \(v_1, \ldots, v_n \in V{}\text{,}\) define
    \begin{equation} \alpha (v_1, \ldots, v_n) = \sum_{(j_1, \ldots, j_n) \in \perm n} ( \sign(j_1, \ldots, j_n) ) \phi_{j_1}(v_1) \cdots \phi_{j_n}(v_n).\tag{9.38} \end{equation}
    🔗
    The verification that \(\alpha\) is an \(n\)-linear form on \(V\) is straightforward.
    🔗
    To see that \(\alpha\) is alternating, suppose \(v_1, \ldots, v_n \in V\) with \(v_1 = v_2\text{.}\) For each \((j_1, \ldots, j_n) \in \perm n\text{,}\) the permutation \((j_2, j_1, j_3, \ldots, j_n)\) has the opposite sign. Because \(v_1 = v_2\text{,}\) the contributions from these two permutations to the sum in (9.38) cancel each other. Hence \(\alpha (v_1, v_1, v_3, \ldots, v_n) = 0\text{.}\) Similarly, \(\alpha (v_1, \ldots, v_n) = 0\) if any two vectors in the list \(v_1, \ldots, v_n\) are equal. Thus \(\alpha\) is alternating.
    🔗
    Finally, consider (9.38) with each \(v_k = e_k\text{.}\) Because \(\phi_j(e_k)\) equals \(0\) if \(j \ne k\) and equals \(1\) if \(j = k\text{,}\) only the permutation \((1, \ldots, n)\) makes a nonzero contribution to the right side of (9.38) in this case, giving the equation \(\alpha (e_1, \ldots, e_n) =1\text{.}\) Thus we have produced a nonzero alternating \(n\)-linear form \(\alpha\) on \(V{}\text{,}\) as desired.
    🔗
    🔗

    Aside
    The formula (9.38) used in the last proof to construct a nonzero alternating \(n\)-linear form came from the formula in Theorem 9.36, and that formula arose naturally from the properties of an alternating multilinear form.
    🔗
    Earlier we showed that the value of an alternating multilinear form applied to a linearly dependent list is \(0\text{;}\) see 9.28. The next result provides a converse of Theorem 9.28 for \(n\)-linear multilinear forms when \(n = \dim V{}\text{.}\) In the following result, the statement that \(\alpha\) is nonzero means (as usual for a function) that \(\alpha\) is not the function on \(V^n\) that is identically \(0\text{.}\)
    🔗

    Theorem 9.39. alternating \((\dim V)\)-linear forms and linear independence.

    Let \(n = \dim V{}\text{.}\) Suppose \(\alpha\) is a nonzero alternating \(n\)-linear form on \(V\) and \(e_1, \ldots, e_n\) is a list of vectors in \(V{}\text{.}\) Then
    \begin{equation*} \alpha (e_1, \ldots, e_n) \ne 0 \end{equation*}
    if and only if \(e_1, \ldots, e_n\) is linearly independent.
    🔗
    🔗

    Proof.
    First suppose \(\alpha (e_1, \ldots, e_n) \ne 0\text{.}\) Then 9.28 implies that \(e_1, \ldots, e_n\) is linearly independent.
    🔗
    To prove the implication in the other direction, now suppose \(e_1, \ldots, e_n\) is linearly independent. Because \(n = \dim V{}\text{,}\) this implies that \(e_1, \ldots, e_n\) is a basis of \(V{}\) (see 2.38).
    🔗
    Because \(\alpha\) is not the zero \(n\)-linear form, there exist \(v_1, \ldots, v_n \in V\) such that \(\alpha (v_1, \ldots, v_n) \ne 0\text{.}\) Now 9.36 implies that \(\alpha ( e_1, \ldots, e_n ) \ne 0\text{.}\)
