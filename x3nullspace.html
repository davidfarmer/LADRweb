    Section 3.2 Null Spaces and Ranges

    Subsection 3.2.1 Null Space and Injectivity

    In this section we will learn about two subspaces that are intimately connected with each linear map. We begin with the set of vectors that get mapped to \(0\text{.}\)
    🔗

    Definition 3.11. null space, \(\ker T\).

    For \(T \in \Lc(V{},W)\text{,}\) the null space of \(T\text{,}\) denoted by \(\ker T\text{,}\) is the subset of \(V\) consisting of those vectors that \(T\) maps to \(0\text{:}\)
    \begin{equation*} \ker T = \{v \in V: Tv = 0 \}. \end{equation*}
    🔗
    🔗

    Example 3.12. null space.

    1. If \(T\) is the zero map from \(V\) to \(W{}\text{,}\) meaning that \(Tv = 0\) for every \(v \in V{}\text{,}\) then \(\ker T = V{}\text{.}\)
      🔗
      🔗
    2. Suppose \(\phi \in \Lc( \CC3, \C{} )\) is defined by \(\phi(z_1, z_2, z_3) = z_1 + 2z_2 + 3z_3\text{.}\) Then \(\ker \phi\) equals \(\{ (z_1, z_2, z_3) \in \C3: z_1 + 2z_2 + 3z_3 = 0 \}\text{,}\) which is a subspace of the domain of \(\phi\text{.}\) We will soon see that the null space of each linear map is a subspace of its domain.
      🔗
      🔗
    3. 🔗
      🔗
    4. Suppose that \(T\in \Lc\bigl(\P(\R{})\bigr)\) is the multiplication by \(x^2\) map defined by \((Tp)(x) = x^2 p(x)\text{.}\) The only polynomial \(p\) such that \(x^2 p(x) = 0\) for all \(x \in \R{}\) is the \(0\) polynomial. Thus \(\ker T = \{ 0 \}\text{.}\)
      🔗
      🔗
    5. Suppose \(T\in \Lc( \F{\infty} )\) is the backward shift defined by
      \begin{equation*} T(x_1, x_2, x_3, \dots) = (x_2, x_3, \dots). \end{equation*}
      Then \(T(x_1, x_2, x_3, \dots)\) equals \(0\) if and only if the numbers \(x_2, x_3, \dots\) are all \(0\text{.}\) Thus \(\ker T = \{ (a, 0, 0, \dots): a \in \F{} \}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    The next result shows that the null space of each linear map is a subspace of the domain. In particular, \(0\) is in the null space of every linear map.
    🔗

    Theorem 3.13. the null space is a subspace.

    Suppose \(T \in \Lc(V{},W)\text{.}\) Then \(\ker T\) is a subspace of \(V{}\text{.}\)
    🔗
    🔗

    Proof.
    Because \(T\) is a linear map, \(T(0) = 0\) (by Theorem 3.10). Thus \(0 \in \ker T{}\text{.}\)
    🔗
    Suppose \(u, v \in \ker T{}\text{.}\) Then
    \begin{equation*} T(u + v) = Tu + Tv = 0 + 0 = 0. \end{equation*}
    🔗
    Hence \(u + v \in \ker T{}\text{.}\) Thus \(\ker T\) is closed under addition.
    🔗
    Suppose \(u \in \ker T\) and \(\lambda \in \F{}{}\text{.}\) Then
    \begin{equation*} T(\lambda u) = \lambda Tu = \lambda 0 = 0. \end{equation*}
    🔗
    Hence \(\lambda u \in \ker T{}\text{.}\) Thus \(\ker T\) is closed under scalar multiplication.
    🔗
    We have shown that \(\ker T\) contains \(0\) and is closed under addition and scalar multiplication. Thus \(\ker T\) is a subspace of \(V\) (by Theorem 1.39).
    🔗
    🔗
    As we will soon see, for a linear map the next definition is closely connected to the null space.
    🔗

    Definition 3.14. injective.

    A function \(T\colon V \rightarrow W\) is called injective if \(Tu = Tv\) implies \(u = v\text{.}\)
    🔗
    🔗
    🔗

    Aside
    The term one-to-one means the same as injective.
    🔗
    We could rephrase the definition above to say that \(T\) is injective if \(u \ne v\) implies that \(Tu \ne Tv\text{.}\) Thus \(T\) is injective if and only if it maps distinct inputs to distinct outputs.
    🔗
    The next result says that we can check whether a linear map is injective by checking whether \(0\) is the only vector that gets mapped to \(0\text{.}\) As a simple application of this result, we see that of the linear maps whose null spaces we computed in Example 3.12, only multiplication by \(x^2\) is injective (except that the zero map is injective in the special case \(V = \{0\}\)).
    🔗

    Theorem 3.15. injectivity \(\iff\) null space equals \(\{0\}\).

    Let \(T \in \Lc(V{},W)\text{.}\) Then \(T\) is injective if and only if \(\ker T = \{0\}\text{.}\)
    🔗
    🔗

    Proof.
    First suppose \(T\) is injective. We want to prove that \(\ker T = \{0\}\text{.}\) We already know that \(\{0\} \subset \ker T\) (by Theorem 3.10). To prove the inclusion in the other direction, suppose \(v \in \ker T{}\text{.}\) Then
    \begin{equation*} T(v) = 0 = T(0). \end{equation*}
    🔗
    Because \(T\) is injective, the equation above implies that \(v = 0\text{.}\) Thus we can conclude that \(\ker T = \{0\}\text{,}\) as desired.
    🔗
    To prove the implication in the other direction, now suppose \(\ker T = \{0\}\text{.}\) We want to prove that \(T\) is injective. To do this, suppose \(u, v \in V\) and \(Tu = Tv\text{.}\) Then
    \begin{equation*} 0 = Tu - Tv = T(u - v). \end{equation*}
    🔗
    Thus \(u - v\) is in \(\ker T\text{,}\) which equals \(\{0\}\text{.}\) Hence \(u - v = 0\text{,}\) which implies that \(u = v\text{.}\) Hence \(T\) is injective, as desired.
    🔗
    🔗
    🔗

    Subsection 3.2.2 Range and Surjectivity

    Now we give a name to the set of outputs of a linear map.
    🔗

    Definition 3.16. range.

    For \(T \in \Lc(V{}, W)\text{,}\) the range of \(T\) is the subset of \(W\) consisting of those vectors that are equal to \(Tv\) for some \(v \in V\text{:}\)
    \begin{equation*} \ran T = \{Tv: v \in V \}. \end{equation*}
    🔗
    🔗

    Example 3.17. range.

    1. If \(T\) is the zero map from \(V\) to \(W{}\text{,}\) meaning that \(Tv=0\) for every \(v \in V{}\text{,}\) then \(\ran T = \{0\}\text{.}\)
      🔗
      🔗
    2. Suppose \(T \in \Lc( \RR2, \R3 )\) is defined by \(T(x, y) = (2x, 5y, x + y)\text{.}\) Then
      \begin{equation*} \ran T = \{ (2x, 5y, x + y ): x, y \in \R{} \}. \end{equation*}
      Note that \(\ran T\) is a subspace of \(\R3\text{.}\) We will soon see that the range of each element of \(\Lc(V{},W)\) is a subspace of \(W{}\text{.}\)
      🔗
      🔗
    3. Suppose \(D\in \Lc\bigl(\P(\R{})\bigr)\) is the differentiation map defined by \(Dp = p'\!\text{.}\) Because for every polynomial \(q \in \P(\R{})\) there exists a polynomial \(p \in \P(\R{})\) such that \(p' = q\text{,}\) the range of \(D\) is \(\P(\R{})\text{.}\)
      🔗
      🔗
    🔗
    🔗
    The next result shows that the range of each linear map is a subspace of the vector space into which it is being mapped.
    🔗

    Theorem 3.18. the range is a subspace.

    If \(T \in \Lc(V{},W)\text{,}\) then \(\ran T\) is a subspace of \(W{}\text{.}\)
    🔗
    🔗

    Proof.
    Suppose \(T \in \Lc(V{},W)\text{.}\) Then \(T(0) = 0\) (by Theorem 3.10), which implies that \(0 \in \ran T{}\text{.}\)
    🔗
    If \(w_1, w_2 \in \ran T\text{,}\) then there exist \(v_1, v_2 \in V\) such that \(Tv_1 = w_1\) and \(Tv_2 = w_2\text{.}\) Thus
    \begin{equation*} T(v_1 + v_2) = Tv_1 + Tv_2 = w_1 + w_2. \end{equation*}
    🔗
    Hence \(w_1 + w_2 \in \ran T{}\text{.}\) Thus \(\ran T\) is closed under addition.
    🔗
    If \(w \in \ran T\) and \(\lambda \in \F{}{}\text{,}\) then there exists \(v \in V\) such that \(Tv = w\text{.}\) Thus
    \begin{equation*} T(\lambda v) = \lambda Tv = \lambda w. \end{equation*}
    🔗
    Hence \(\lambda w \in \ran T{}\text{.}\) Thus \(\ran T\) is closed under scalar multiplication.
    🔗
    We have shown that \(\ran T\) contains \(0\) and is closed under addition and scalar multiplication. Thus \(\ran T\) is a subspace of \(W\) (by Theorem 1.39).
    🔗
    🔗

    Definition 3.19. surjective.

    A function \(T\colon V \rightarrow W\) is called surjective if its range equals \(W{}\text{.}\)
    🔗
    🔗
    🔗
    To illustrate the definition above, note that of the ranges we computed in Example 3.17, only the differentiation map is surjective (except that the zero map is surjective in the special case \(W = \{0\}\)).
    🔗

    Aside
    Some people use the term onto, which means the same as surjective.
    🔗
    Whether a linear map is surjective depends on what we are thinking of as the vector space into which it maps.
    🔗

    Example 3.20. surjectivity depends on the target space.

    The differentiation map \(D \in \Lc\bigl(\P{}_5(\R{})\bigr)\) defined by \(Dp = p'\) is not surjective, because the polynomial \(x^5\) is not in the range of \(D\text{.}\) However, the differentiation map \(S \in \Lc\bigl(\P{}_5(\R{}), \P{}_4(\R{})\bigr)\) defined by \(Sp = p'\) is surjective, because its range equals \(\P{}_4(\R{})\text{,}\) which is the vector space into which \(S\) maps.
    🔗
    🔗
    🔗

    Subsection 3.2.3 Fundamental Theorem of Linear Maps

    The next result is so important that it gets a dramatic name.
    🔗

    Theorem 3.21. fundamental theorem of linear maps.

    Suppose \(V\) is finite-dimensional and \(T \in \Lc(V{},W)\text{.}\) Then \(\ran T\) is finite-dimensional and
    \begin{equation*} \dim V = \dim \ker T + \dim \ran T{}. \end{equation*}
    🔗
    🔗

    Proof.
    Let \(u_1, \dots, u_m\) be a basis of \(\ker T\text{;}\) thus \(\dim \ker T = m\text{.}\) The linearly independent list \(u_1, \dots, u_m\) can be extended to a basis
    \begin{equation*} u_1, \dots, u_m, v_1, \dots, v_n \end{equation*}
    of \(V\) (by Theorem 2.31). Thus \(\dim V = m + n\text{.}\) To complete the proof, we need to show that \(\ran T\) is finite-dimensional and \(\dim \ran T = n\text{.}\) We will do this by proving that \(Tv_1, \dots, Tv_n\) is a basis of \(\ran T{}\text{.}\)
    🔗
    Let \(v \in V{}\text{.}\) Because \(u_1, \dots, u_m, v_1, \dots, v_n\) spans \(V{}\text{,}\) we can write
    \begin{equation*} v = a_1 u_1 + \dots + a_m u_m + b_1 v_1 + \dots + b_n v_n, \end{equation*}
    where the \(a\)’s and \(b\)’s are in \(\F{}{}\text{.}\) Applying \(T\) to both sides of this equation, we get
    \begin{equation*} Tv = b_1 Tv_1 + \dots + b_n Tv_n, \end{equation*}
    where the terms of the form \(Tu_k\) disappeared because each \(u_k\) is in \(\ker T{}\text{.}\) The last equation implies that the list \(Tv_1, \dots, Tv_n\) spans \(\ran T{}\text{.}\) In particular, \(\ran T\) is finite-dimensional.
    🔗
    To show \(Tv_1, \dots, Tv_n\) is linearly independent, suppose \(c_1, \dots, c_n \in \F{}\) and
    \begin{equation*} c_1 Tv_1 + \dots + c_n Tv_n = 0. \end{equation*}
    🔗
    Then
    \begin{equation*} T(c_1 v_1 + \dots + c_n v_n) = 0. \end{equation*}
    🔗
    Hence
    \begin{equation*} c_1 v_1 + \dots + c_n v_n \in \ker T{}. \end{equation*}
    🔗
    Because \(u_1, \dots, u_m\) spans \(\ker T\text{,}\) we can write
    \begin{equation*} c_1 v_1 + \dots + c_n v_n = d_1 u_1 + \dots + d_m u_m, \end{equation*}
    where the \(d\)’s are in \(\F{}{}\text{.}\) This equation implies that all the \(c\)’s (and \(d\)’s) are \(0\) (because \(u_1, \dots, u_m, v_1, \dots, v_n\) is linearly independent). Thus \(Tv_1, \dots, Tv_n\) is linearly independent and hence is a basis of \(\ran T\text{,}\) as desired.
    🔗
    🔗
    Now we can show that no linear map from a finite-dimensional vector space to a “smaller” vector space can be injective, where “smaller” is measured by dimension.
    🔗

    Theorem 3.22. linear map to a lower-dimensional space is not injective.

    Suppose \(V\) and \(W\) are finite-dimensional vector spaces such that \(\dim V > \dim W{}\text{.}\) Then no linear map from \(V\) to \(W\) is injective.
    🔗
    🔗

    Proof.
    Let \(T \in \Lc(V{},W)\text{.}\) Then
    \begin{align*} \dim \ker T \amp = \dim V - \dim \ran T\\ \amp \ge \dim V - \dim W\\ \amp > 0\text{,} \end{align*}
    where the first line above comes from the fundamental theorem of linear maps Theorem 3.21 and the second line follows from Theorem 2.36. The inequality above states that \(\dim \ker T > 0\text{.}\) This means that \(\ker T\) contains vectors other than \(0\text{.}\) Thus \(T\) is not injective (by Theorem 3.15).
    🔗
    🔗

    Example 3.23. linear map from \(\F4\) to \(\F3\) is not injective.

    Define a linear map \(\fun T {\F4} {\F3}\) by
    \begin{equation*} T(z_1, z_2, z_3, z_4) = ( \sqrt{7} z_1 + \pi z_2 + z_4, 97 z_1 + 3 z_2 + 2z_3, z_2 + 6z_3 + 7z_4 ). \end{equation*}
    🔗
    Because \(\dim \F4 > \dim \FF3\text{,}\) we can use 3.22 to assert that \(T\) is not injective, without doing any calculations.
    🔗
    🔗
    The next result shows that no linear map from a finite-dimensional vector space to a “bigger” vector space can be surjective, where “bigger” is measured by dimension.
    🔗

    Theorem 3.24. linear map to a higher-dimensional space is not surjective.

    Suppose \(V\) and \(W\) are finite-dimensional vector spaces such that \(\dim V \lt \dim W{}\text{.}\) Then no linear map from \(V\) to \(W\) is surjective.
    🔗
    🔗

    Proof.
    Let \(T \in \Lc(V{},W)\text{.}\) Then
    \begin{align*} \dim \ran T \amp = \dim V - \dim \ker T\\ \amp \le \dim V\\ \amp \lt \dim W{}\text{,} \end{align*}
    where the equality above comes from the fundamental theorem of linear maps Theorem 3.21. The inequality above states that \(\dim \ran T \lt \dim W{}\text{.}\) This means that \(\ran T\) cannot equal \(W{}\text{.}\) Thus \(T\) is not surjective.
    🔗
    🔗
    As we will soon see, Theorem 3.22 and Theorem 3.24 have important consequences in the theory of linear equations. The idea is to express questions about systems of linear equations in terms of linear maps. Let’s begin by rephrasing in terms of linear maps the question of whether a homogeneous system of linear equations has a nonzero solution.
    🔗

    Aside
    Homogeneous, in this context, means that the constant term on the right side of each equation below is \(0\text{.}\)
    🔗
    Fix positive integers \(m\) and \(n\text{,}\) and let \(A_{j,k} \in \F{}\) for \(j = 1, \dots, m\) and \(k = 1, \dots , n\text{.}\) Consider the homogeneous system of linear equations
    \begin{align*} \sum_{k=1}^n A_{1,k} x_k \amp = 0\\ \amp \vdots\\ \sum_{k=1}^n A_{m,k} x_k \amp = 0\text{.} \end{align*}
    🔗
    Clearly \(x_1 = \dots = x_n = 0\) is a solution of the system of equations above; the question here is whether any other solutions exist.
    🔗
    Define \(T\colon \F{n} \rightarrow \F{m}\) by
    \begin{equation} T(x_1, \dots, x_n) = ( \sum_{k=1}^n A_{1,k} x_k, \dots, \sum_{k=1}^n A_{m,k} x_k ).\tag{3.1} \end{equation}
    🔗
    The equation \(T(x_1, \dots, x_n) = 0\) (the \(0\) here is the additive identity in \(\FF{m}\text{,}\) namely, the list of length \(m\) of all \(0\)’s) is the same as the homogeneous system of linear equations above.
    🔗
    Thus we want to know if \(\ker T\) is strictly bigger than \(\{0\}\text{,}\) which is equivalent to \(T\) not being injective (by Theorem 3.15). The next result gives an important condition for ensuring that \(T\) is not injective.
    🔗

    Theorem 3.25. homogeneous system of linear equations.

    A homogeneous system of linear equations with more variables than equations has nonzero solutions.
    🔗
    🔗

    Proof.
    Use the notation and result from the discussion above. Thus \(T\) is a linear map from \(\F{n}\) to \(\FF{m}\text{,}\) and we have a homogeneous system of \(m\) linear equations with \(n\) variables \(x_1, \dots, x_n\text{.}\) From 3.22 we see that \(T\) is not injective if \(n > m\text{.}\)
    🔗
    🔗
    Example of the result above: a homogeneous system of four linear equations with five variables has nonzero solutions.
    🔗
    Now we consider the question of whether a system of linear equations has no solutions for some choice of the constant terms. To rephrase this question in terms of a linear map, fix positive integers \(m\) and \(n\text{,}\) and let \(A_{j,k} \in \F{}\) for all \(j = 1, \dots, m\) and all \(k = 1, \dots , n\text{.}\) For \(c_1, \dots, c_m \in \F{}{}\text{,}\) consider the system of linear equations
    \begin{align} \sum_{k=1}^n A_{1,k} x_k \amp = c_1\notag\\ \amp \vdots\tag{3.2}\\ \sum_{k=1}^n A_{m,k} x_k \amp = c_m\text{.}\notag \end{align}
    🔗
    With this notation, the question here is whether there is some choice of the constant terms \(c_1, \dots, c_m \in \F{}\) such that no solution exists to the system above.
    🔗

    Aside
    The results 3.25 and Theorem 3.26, which compare the number of variables and the number of equations, can also be proved using Gaussian elimination. The abstract approach taken here seems to provide cleaner proofs.
    🔗
    🔗
    Define \(T\colon \F{n} \rightarrow \F{m}\) as in (3.1). The equation \(T(x_1, \dots, x_n) \!= \!(c_1, \dots, c_m)\) is the same as the system of equations (3.2). Thus we want to know if \(\ran T \ne \FF{m}\text{.}\) Hence we can rephrase our question about not having a solution for some choice of \(c_1, \dots, c_m \in \F{}\) as follows: What condition ensures that \(T\) is not surjective? The next result gives one such condition.
    🔗

    Theorem 3.26. system of linear equations with more equations than variables.

    A system of linear equations with more equations than variables has no solution for some choice of the constant terms.
    🔗
    🔗

    Proof.
    Use the notation from the discussion above. Thus \(T\) is a linear map from \(\F{n}\) to \(\FF{m}\text{,}\) and we have a system of \(m\) equations with \(n\) variables \(x_1, \dots, x_n\text{;}\) see (3.2). If \(n \lt m\text{,}\) then 3.24 implies that \(T\) is not surjective. As discussed above, this shows that if we have more equations than variables in a system of linear equations, then there is no solution for some choice of the constant terms.
    🔗
    🔗
    Example of the result above: a system of five linear equations with four variables has no solution for some choice of the constant terms.
