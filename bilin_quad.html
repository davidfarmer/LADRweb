    Section 9.1 Bilinear Forms and Quadratic Forms

    Subsection 9.1.1 Bilinear Forms

    A bilinear form on \(V\) is a function from \(V{} \times V\) to \(\F{}\) that is linear in each slot separately, meaning that if we hold either slot fixed then we have a linear function in the other slot. Here is the formal definition.
    🔗

    Definition 9.1. bilinear form.

    A bilinear form on \(V\) is a function \(\fun \beta {V{} \times V} \F{}\) such that
    \begin{equation*} v \mapsto \beta(v, u) \andd v \mapsto \beta(u,v) \end{equation*}
    are both linear functionals on \(V\) for every \(u \in V{}\text{.}\)
    🔗
    🔗

    Aside
    Recall that the term linear functional, used in the definition above, means a linear function that maps into the scalar field \(\F{}{}\text{.}\) Thus the term bilinear functional would be more consistent terminology than bilinear form, which unfortunately has become standard.
    🔗
    For example, if \(V\) is a real inner product space, then the function that takes an ordered pair \((u, v) \in V{} \times V\) to \(\langle u, v \rangle\) is a bilinear form on \(V{}\text{.}\) If \(V\) is a nonzero complex inner product space, then this function is not a bilinear form because the inner product is not linear in the second slot (complex scalars come out of the second slot as their complex conjugates).
    🔗
    If \(\F{} = \R{}\text{,}\) then a bilinear form differs from an inner product in that an inner product requires symmetry [meaning that \(\beta(v,w) = \beta(w,v)\) for all \(v, w \in V\)] and positive definiteness [meaning that \(\beta(v, v) > 0\) for all \(v \in V \sm \{ 0 \}\)] , but these properties are not required for a bilinear form.
    🔗

    Example 9.2. bilinear forms.

    1. The function \(\fun \beta {\F3 \times \F3} {\F{}}\) defined by
      \begin{equation*} \beta( (x_1, x_2, x_3), (y_1, y_2, y_3) ) = x_1 y_2 - 5 x_2 y_3 + 2 x_3 y_1 \end{equation*}
      is a bilinear form on \(\F3\text{.}\)
      🔗
      🔗
    2. Suppose \(A\) is an \(n\)-by-\(n\) matrix with \(A_{j,k} \in \F{}\) in row \(j\text{,}\) column \(k\text{.}\) Define a bilinear form \(\beta_A\) on \(\F n\) by
      \begin{equation*} \beta_A( (x_1, \ldots, x_n), (y_1, \ldots, y_n) ) = \sum_{k=1}^n \sum_{j=1}^n A_{j,k} x_j y_k. \end{equation*}
      The first bullet point is a special case of this bullet point with \(n = 3\) and
      \begin{equation*} A = \begin{pmatrix}0 \amp 1 \amp 0\\ 0 \amp 0 \amp -5 \\ 2 \amp 0 \amp 0 \end{pmatrix} . \end{equation*}
      🔗
      🔗
    3. Suppose \(V\) is a real inner product space and \(T \in \Lc(V)\text{.}\) Then the function \(\fun \beta {V{} \times V} {\R{}}\) defined by
      \begin{equation*} \beta(u, v) = \langle u, Tv \rangle \end{equation*}
      is a bilinear form on \(V{}\text{.}\)
      🔗
      🔗
    4. If \(n\) is a positive integer, then the function \(\fun \beta { \P{}_n(\R{}) \times \P{}_n(\R{}) } {\R{}}\) defined by
      \begin{equation*} \beta(p,q) = p(2) \cdot q'(3) \end{equation*}
      is a bilinear form on \(\P{}_n(\R{})\text{.}\)
      🔗
      🔗
    5. Suppose \(\phi, \tau \in V'\!\text{.}\) Then the function \(\fun \beta {V{} \times V} {\F{}}\) defined by
      \begin{equation*} \beta(u, v) = \phi(u) \cdot \tau(v) \end{equation*}
      is a bilinear form on \(V{}\text{.}\)
      🔗
      🔗
    6. More generally, suppose that \(\phi_1, \ldots, \phi_n, \tau_1, \ldots, \tau_n \in V'\!\text{.}\) Then the function \(\fun \beta {V{} \times V} {\F{}}\) defined by
      \begin{equation*} \beta(u, v) = \phi_1(u) \cdot \tau_1(v) + \cdots + \phi_n(u) \cdot \tau_n(v) \end{equation*}
      is a bilinear form on \(V{}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    A bilinear form on \(V\) is a function from \(V{} \times V\) to \(\F{}{}\text{.}\) Because \(V{} \times V\) is a vector space, this raises the question of whether a bilinear form can also be a linear map from \(V{} \times V\) to \(\F{}{}\text{.}\) Note that none of the bilinear forms in Example 9.2 are linear maps except in some special cases in which the bilinear form is the zero map. Exercise 9.1.3.3 shows that a bilinear form \(\beta\) on \(V\) is a linear map on \(V{} \times V\) only if \(\beta = 0\text{.}\)
    🔗

    Definition 9.3. \(V^{(2)}\).

    The set of bilinear forms on \(V\) is denoted by \(V^{(2)}\!\text{.}\)
    🔗
    🔗
    With the usual operations of addition and scalar multiplication of functions, \(V^{(2)}\) is a vector space.
    🔗
    For \(T\) an operator on an \(n\)-dimensional vector space \(V\) and a basis \(e_1, \ldots, e_n\) of \(V{}\text{,}\) we used an \(n\)-by-\(n\) matrix to provide information about \(T{}\text{.}\) We now do the same thing for bilinear forms on \(V{}\text{.}\)
    🔗

    Definition 9.4. matrix of a bilinear form, \(\M(\beta)\).

    Suppose \(\beta\) is a bilinear form on \(V\) and \(e_1, \ldots, e_n\) is a basis of \(V{}\text{.}\) The matrix of \(\beta\) with respect to this basis is the n n matrix \(\M(\beta)\) whose entry \(\M(\beta)_{j,k}\) in row \(j\text{,}\) column \(k\) is given by
    \begin{equation*} \M(\beta)_{j,k} = \beta(e_j, e_k)\text{.} \end{equation*}
    🔗
    If the basis \(e_1, \ldots, e_n\) is not clear from the context, then the notation \(\M( \beta, (e_1, \ldots, e_n) )\) is used.
    🔗
    🔗
    Recall that \(\F{n,n}\) denotes the vector space of \(n\)-by-\(n\) matrices with entries in \(\F{}\) and that \(\dim \F{n,n} = n^2\) (see 3.37 and Theorem 3.38).
    🔗

    Theorem 9.5. \(\dim V^{(2)} = (\dim V)^2\).

    Suppose \(e_1, \ldots, e_n\) is a basis of \(V{}\text{.}\) Then the map \(\beta \mapsto \M(\beta)\) is an isomorphism of \(V^{(2)}\) onto \(\FF{n,n}\text{.}\) Furthermore, \(\dim V^{(2)} = (\dim V)^2{}\text{.}\)
    🔗
    🔗

    Proof.
    The map \(\beta \mapsto \M(\beta)\) is clearly a linear map of \(V^{(2)}\) into \(\FF{n,n}\text{.}\) For \(A \in \FF{n,n}\text{,}\) define a bilinear form \(\beta_A\) on \(V\) by
    \begin{equation*} \beta_A( x_1 e_1+ \cdots + x_n e_n, y_1 e_1 + \cdots + y_n e_n ) = \sum_{k=1}^n \sum_{j=1}^n A_{j,k} x_j y_k \end{equation*}
    for \(x_1, \ldots, x_n, y_1, \ldots, y_n \in \F{}\) \big(if \(V = \F{n}\) and \(e_1, \ldots, e_n\) is the standard basis of \(\FF{n}\text{,}\) this \(\beta_A\) is the same as the bilinear form \(\beta_A\) in the second bullet point of Example 9.2\big).
    🔗
    The linear map \(\beta \mapsto \M(\beta)\) from \(V^{(2)}\) to \(\F{n,n}\) and the linear map \(A \mapsto \beta_A\) from \(\F{n,n}\) to \(V^{(2)}\) are inverses of each other because \(\beta_{\M(\beta)} = \beta\) for all \(\beta \in V^{(2)}\) and \(\M(\beta_A) = A\) for all \(A \in \FF{n,n}\text{,}\) as you should verify.
    🔗
    Thus both maps are isomorphisms and the two spaces that they connect have the same dimension. Hence \(\dim V^{(2)} = \dim \F{n,n} = n^2 = (\dim V)^2{}\text{.}\)
    🔗
    🔗
    Recall that \(\tran{C}\) denotes the transpose of a matrix \(C\text{.}\) The matrix \(\tran{C}\) is obtained by interchanging the rows and the columns of \(C\text{.}\)
    🔗

    Theorem 9.6. composition of a bilinear form and an operator.

    Suppose \(\beta\) is a bilinear form on \(V\) and \(T \in \Lc(V)\text{.}\) Define bilinear forms \(\alpha\) and \(\rho\) on \(V\) by
    \begin{equation*} \alpha (u,v) = \beta(u, Tv) \andd \rho(u,v) = \beta(Tu, v). \end{equation*}
    🔗
    Let \(e_1, \ldots, e_n\) be a basis of \(V{}\text{.}\) Then
    \begin{equation*} \M(\alpha ) = \M(\beta) \M(T) \andd \M(\rho) = \tran{\M(T)} \M(\beta). \end{equation*}
    🔗
    🔗

    Proof.
    If \(j, k \in \{ 1, \ldots, n \}\text{,}\) then
    \begin{align*} \M(\alpha )_{j,k} \amp = \alpha (e_j, e_k)\\ \amp = \beta(e_j, Te_k)\\ \amp = \beta( e_j, \sum_{m=1}^n \M(T)_{m,k} e_m )\\ \amp = \sum_{m=1}^n \beta(e_j, e_m) \M(T)_{m,k}\\ \amp = ( \M(\beta) \M(T) )_{j, k}\text{.} \end{align*}
    🔗
    Thus \(\M(\alpha ) = \M(\beta) \M(T)\text{.}\) The proof that \(\M(\rho) = \tran{\M(T)} \M(\beta)\) is similar.
    🔗
    🔗
    The result below shows how the matrix of a bilinear form changes if we change the basis. The formula in the result below should be compared to the change-of-basis formula for the matrix of an operator (see 3.78). The two formulas are similar, except that the transpose \(\tran{C}\) appears in the formula below and the inverse \(C^{-1}\) appears in the change-of-basis formula for the matrix of an operator.
    🔗

    Theorem 9.7. change-of-basis formula.

    Suppose \(\beta \in V^{(2)}\!\text{.}\) Suppose \(e_1, \ldots, e_n\) and \(f_1, \ldots, f_n\) are bases of \(V{}\text{.}\) Let
    \begin{equation*} A= \M\bigl(\beta, (e_1, \ldots, e_n)\bigr) \andd B = \M\bigl(\beta, (f_1, \ldots, f_n)\bigr) \end{equation*}
    and \(C = \M\bigl(I, (e_1, \ldots, e_n), (f_1, \ldots, f_n)\bigr)\text{.}\) Then
    \begin{equation*} A = \tran{C} B C\text{.} \end{equation*}
    🔗
    🔗

    Proof.
    The linear map lemma Theorem 3.4 tells us that there exists an operator \(T \in \Lc(V)\) such that \(Tf_k = e_k\) for each \(k = 1, \ldots, n\text{.}\) The definition of the matrix of an operator with respect to a basis implies that
    \begin{equation*} \M( T, (f_1, \ldots, f_n) ) = C. \end{equation*}
    🔗
    Define bilinear forms \(\alpha , \rho\) on \(V\) by
    \begin{equation*} \alpha (u, v) = \beta(u, Tv) \andd \rho(u,v) = \alpha (Tu, v) = \beta(Tu, Tv). \end{equation*}
    🔗
    Then \(\beta(e_j, e_k) = \beta(Tf_j, Tf_k) = \rho(f_j, f_k)\) for all \(j, k \in \{ 1, \ldots, n \}\text{.}\) Thus
    \begin{align*} A \amp = \M( \rho, (f_1, \ldots, f_n) )\\ \amp = \tran{C} \M( \alpha , (f_1, \ldots, f_n) )\\ \amp = \tran{C} B C\text{,} \end{align*}
    where the second and third lines each follow from Theorem 9.6.
    🔗
    🔗

    Example 9.8. the matrix of a bilinear form on \(\P_2(\R)\).

    Define a bilinear form \(\beta\) on \(\P{}_2(\R{})\) by \(\beta(p,q) = p(2) \cdot q'(3)\text{.}\) Let
    \begin{equation*} A = \M( \beta, (1, x-2, (x-3)^2 ) ) \andd B = \M( \beta, (1, x, x^2) ) \end{equation*}
    and \(C = \M( I, (1, x-2, (x-3)^2 ), (1, x, x^2) )\text{.}\) Then
    \begin{equation*} A = \begin{pmatrix}0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \end{pmatrix} {}\andd{} B = \begin{pmatrix}0 \amp 1 \amp 6 \\ 0 \amp 2 \amp 12 \\ 0 \amp 4 \amp 24 \end{pmatrix} {}\andd{} C = \begin{pmatrix}1 \amp -2 \amp 9 \\ 0 \amp 1 \amp -6 \\ 0 \amp 0 \amp 1 \end{pmatrix} . \end{equation*}
    🔗
    Now the change-of-basis formula 9.7 asserts that \(A = \tran{C} B C\text{,}\) which you can verify with matrix multiplication using the matrices above.
    🔗
    🔗
    🔗

    Subsection 9.1.2 Symmetric Bilinear Forms

    Definition 9.9. symmetric bilinear form, \(V^{(2)}_{sym}\).

    A bilinear form \(\rho \in V^{(2)}\) is called symmetric if
    \begin{equation*} \rho(u,w) = \rho(w, u) \end{equation*}
    for all \(u,w \in V{}\text{.}\) The set of symmetric bilinear forms on \(V\) is denoted by \(V^{(2)}_{\text{ sym } }\text{.}\)
    🔗
    🔗

    Example 9.10. symmetric bilinear forms.

    1. If \(V\) is a real inner product space and \(\rho \in V^{(2)}\) is defined by
      \begin{equation*} \rho(u, w) = \langle u, w \rangle , \end{equation*}
      then \(\rho\) is a symmetric bilinear form on \(V{}\text{.}\)
      🔗
      🔗
    2. Suppose \(V\) is a real inner product space and \(T \in \Lc(V)\text{.}\) Define \(\rho \in V^{(2)}\) by
      \begin{equation*} \rho(u, w) = \langle u, Tw \rangle . \end{equation*}
      Then \(\rho\) is a symmetric bilinear form on \(V\) if and only if \(T\) is a self-adjoint operator (the previous bullet point is the special case \(T = I\)).
      🔗
      🔗
    3. Suppose \(\fun \rho {\Lc(V) \times \Lc(V)} {\F{}}\) is defined by
      \begin{equation*} \rho(S,T) = \tr(ST). \end{equation*}
      Then \(\rho\) is a symmetric bilinear form on \(\Lc(V)\) because trace is a linear functional on \(\Lc(V)\) and \(\tr(ST) = \tr(TS)\) for all \(S, T \in \Lc(V)\text{;}\) see 8.50.
      🔗
      🔗
    🔗
    🔗

    Definition 9.11. symmetric matrix.

    A square matrix \(A\) is called symmetric if it equals its transpose.
    🔗
    🔗
    An operator on \(V\) may have a symmetric matrix with respect to some but not all bases of \(V{}\text{.}\) In contrast, the next result shows that a bilinear form on \(V\) has a symmetric matrix with respect to either all bases of \(V\) or with respect to no bases of \(V{}\text{.}\)
    🔗

    Theorem 9.12. symmetric bilinear forms are diagonalizable.

    Suppose \(\rho \in V^{(2)}\!\text{.}\) Then the following are equivalent.
    1. \(\rho\) is a symmetric bilinear form on \(V{}\text{.}\)
      🔗
      🔗
    2. \(\M( \rho, (e_1, \ldots, e_n) )\) is a symmetric matrix for every basis \(e_1, \ldots, e_n\) of \(V{}\text{.}\)
      🔗
      🔗
    3. \(\M( \rho, (e_1, \ldots, e_n) )\) is a symmetric matrix for some basis \(e_1, \ldots, e_n\) of \(V{}\text{.}\)
      🔗
      🔗
    4. \(\M( \rho, (e_1, \ldots, e_n) )\) is a diagonal matrix for some basis \(e_1, \ldots, e_n\) of \(V{}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    First suppose (a) holds, so \(\rho\) is a symmetric bilinear form. Suppose \(e_1, \ldots, e_n\) is a basis of \(V{}\) and \(j,k \in \{ 1, \ldots, n \}\text{.}\) Then \(\rho(e_j, e_k) = \rho(e_k, e_j)\) because \(\rho\) is symmetric. Thus \(\M( \rho, (e_1, \ldots, e_n) )\) is a symmetric matrix, showing that (a) implies (b).
    🔗
    Clearly (b) implies (c).
    🔗
    Now suppose (c) holds and \(e_1, \ldots, e_n\) is a basis of \(V\) such that \(\M( \rho, (e_1, \ldots, e_n) )\) is a symmetric matrix. Suppose \(u, w \in V{}\text{.}\) There exist \(a_1, \ldots, a_n, b_1, \ldots, b_n \in \F{}\) such that \(u = a_1 e_1 + \cdots + a_n e_n\) and \(w = b_1 e_1 + \cdots + b_n e_n\text{.}\) Now
    \begin{align*} \rho(u, w) \amp = \rho( \sum_{j=1}^n a_j e_j, \sum_{k=1}^n b_k e_k )\\ \amp = \sum_{j=1}^n \sum_{k=1}^n a_j b_k \rho(e_j, e_k)\\ \amp = \sum_{j=1}^n \sum_{k=1}^n a_j b_k \rho(e_k, e_j)\\ \amp = \rho( \sum_{k=1}^n b_k e_k, \sum_{j=1}^n a_j e_j )\\ \amp = \rho(w,u)\text{,} \end{align*}
    where the third line holds because \(\M(\rho)\) is a symmetric matrix. The equation above shows that \(\rho\) is a symmetric bilinear form, proving that (c) implies (a).
    🔗
    At this point, we have proved that (a), (b), (c) are equivalent. Because every diagonal matrix is symmetric, (d) implies (c). To complete the proof, we will show that (a) implies (d) by induction on \(n = \dim V{}\text{.}\)
    🔗
    If \(n = 1\text{,}\) then (a) implies (d) because every \(1\)-by-\(1\) matrix is diagonal. Now suppose \(n > 1\) and the implication (a) \(\implies\) (d) holds for one less dimension. Suppose (a) holds, so \(\rho\) is a symmetric bilinear form. If \(\rho = 0\text{,}\) then the matrix of \(\rho\) with respect to every basis of \(V\) is the zero matrix, which is a diagonal matrix. Hence we can assume that \(\rho \ne 0\text{,}\) which means there exist \(u, w \in V\) such that \(\rho(u, w) \ne 0\text{.}\) Now
    \begin{equation*} 2 \rho(u, w) = \rho(u + w, u+w) - \rho(u, u) - \rho(w,w). \end{equation*}
    🔗
    Because the left side of the equation above is nonzero, the three terms on the right cannot all equal \(0\text{.}\) Hence there exists \(v \in V\) such that \(\rho(v,v) \ne 0\text{.}\)
    🔗
    Let \(U = \{ u \in V : \rho(u,v) = 0 \}\text{.}\) Thus \(U\) is the null space of the linear functional \(u \mapsto \rho(u, v)\) on \(V{}\text{.}\) This linear functional is not the zero linear functional because \(v \notin U\text{.}\) Thus \(\dim U = n-1\text{.}\) By our induction hypothesis, there is a basis \(e_1, \ldots, e_{n-1}\) of \(U\) such that the symmetric bilinear form \(\rho|_{U \times U}\) has a diagonal matrix with respect to this basis.
    🔗
    Because \(v \notin U\text{,}\) the list \(e_1, \ldots, e_{n-1}, v\) is a basis of \(V{}\text{.}\) Suppose \(k \in \{ 1, \ldots, n-1 \}\text{.}\) Then \(\rho(e_k, v) = 0\) by the construction of \(U\text{.}\) Because \(\rho\) is symmetric, we also have \(\rho(v, e_k) = 0\text{.}\) Thus the matrix of \(\rho\) with respect to \(e_1, \ldots, e_{n-1}, v\) is a diagonal matrix, completing the proof that (a) implies (d).
    🔗
    🔗
    The previous result states that every symmetric bilinear form has a diagonal matrix with respect to some basis. If our vector space happens to be a real inner product space, then the next result shows that every symmetric bilinear form has a diagonal matrix with respect to some orthonormal basis. Note that the inner product here is unrelated to the bilinear form.
    🔗

    Theorem 9.13. diagonalization of a symmetric bilinear form by an orthonormal basis.

    Suppose \(V\) is a real inner product space and \(\rho\) is a symmetric bilinear form on \(V{}\text{.}\) Then \(\rho\) has a diagonal matrix with respect to some orthonormal basis of \(V{}\text{.}\)
    🔗
    🔗

    Proof.
    Let \(f_1, \ldots, f_n\) be an orthonormal basis of \(V{}\text{.}\) Let \(B = \M( \rho, (f_1, \ldots, f_n) )\text{.}\) Then \(B\) is a symmetric matrix (by Theorem 9.12). Let \(T \in \Lc(V)\) be the operator such that \(\M( T, (f_1, \ldots, f_n) ) = B\text{.}\) Thus \(T\) is self-adjoint.
    🔗
    The real spectral theorem Theorem 7.24 states that \(T\) has a diagonal matrix with respect to some orthonormal basis \(e_1, \ldots, e_n\) of \(V{}\text{.}\) Let \(C = \M\bigl(I, (e_1, \ldots, e_n), (f_1, \ldots, f_n)\bigr)\text{.}\) Thus \(C^{-1} B C\) is the matrix of \(T\) with respect to the basis \(e_1, \ldots, e_n\) (by Theorem 3.78). Hence \(C^{-1} B C\) is a diagonal matrix. Now
    \begin{equation*} \\M( \rho, (e_1, \ldots, e_n) ) = \tran{C} B C = C^{-1} B C, \end{equation*}
    where the first equality holds by Theorem 9.7 and the second equality holds because \(C\) is a unitary matrix with real entries \big(which implies that \(C^{-1} = \tran{C}\text{;}\) see 7.46\big).
    🔗
    🔗
    Now we turn our attention to alternating bilinear forms. Alternating multilinear forms will play a major role in our approach to determinants later in this chapter.
    🔗

    Definition 9.14. alternating bilinear form, \(V^{(2)}_{alt}\).

    A bilinear form \(\alpha \in V^{(2)}\) is called alternating if
    \begin{equation*} \alpha (v,v) = 0 \end{equation*}
    for all \(v \in V{}\text{.}\) The set of alternating bilinear forms on \(V\) is denoted by \(V^{(2)}_{\text{ alt } }\text{.}\)
    🔗
    🔗

    Example 9.15. alternating bilinear forms.

    1. Suppose \(n \ge 3\) and \(\fun \alpha {\F n \times \F n} {\F{}}\) is defined by
      \begin{equation*} \alpha ( (x_1, \ldots, x_n), (y_1, \ldots, y_n) ) = x_1 y_2 - x_2 y_1 + x_1 y_3 - x_3 y_1. \end{equation*}
      Then \(\alpha\) is an alternating bilinear form on \(\FF n\text{.}\)
      🔗
      🔗
    2. Suppose \(\phi, \tau \in V'\!\text{.}\) Then the bilinear form \(\alpha\) on \(V\) defined by
      \begin{equation*} \alpha (u, w) = \phi(u) \tau(w) - \phi(w) \tau(u) \end{equation*}
      is alternating.
      🔗
      🔗
    🔗
    🔗
    The next result shows that a bilinear form is alternating if and only if switching the order of the two inputs multiplies the output by \(-1\text{.}\)
    🔗

    Theorem 9.16. characterization of alternating bilinear forms.

    A bilinear form \(\alpha\) on \(V\) is alternating if and only if
    \begin{equation*} \alpha (u,w) = -\alpha (w,u) \end{equation*}
    for all \(u, w \in V{}\text{.}\)
    🔗
    🔗

    Proof.
    First suppose that \(\alpha\) is alternating. If \(u, w \in V{}\text{,}\) then
    \begin{align*} 0 \amp = \alpha (u+w, u+w)\\ \amp = \alpha (u,u) + \alpha (u,w) + \alpha (w,u) + \alpha (w,w)\\ \amp = \alpha (u,w) + \alpha (w,u)\text{.} \end{align*}
    🔗
    Thus \(\alpha (u,w) = -\alpha (w,u)\text{,}\) as desired.
    🔗
    To prove the implication in the other direction, suppose \(\alpha (u,w) = -\alpha (w,u)\) for all \(u, w \in V{}\text{.}\) Then \(\alpha (v,v) = -\alpha (v, v)\) for all \(v \in V{}\text{,}\) which implies that \(\alpha (v,v) = 0\) for all \(v \in V{}\text{.}\) Thus \(\alpha\) is alternating.
    🔗
    🔗
    Now we show that the vector space of bilinear forms on \(V\) is the direct sum of the symmetric bilinear forms on \(V\) and the alternating bilinear forms on \(V{}\text{.}\)
    🔗

    Theorem 9.17. \(V^{(2)} = V^{(2)}_{sym} \oplus V^{(2)}_{alt}\).

    The sets \(V^{(2)}_{\text{ sym } }\) and \(V^{(2)}_{\text{ alt } }\) are subspaces of \(V^{(2)}\text{.}\) Furthermore,
    \begin{equation*} V^{(2)} = V^{(2)}_{\text{ sym } } \oplus V^{(2)}_{\text{ alt } }. \end{equation*}
    🔗
    🔗

    Proof.
    The definition of symmetric bilinear form implies that the sum of any two symmetric bilinear forms on \(V\) is a symmetric bilinear form on \(V{}\text{,}\) and every scalar multiple of any symmetric bilinear form on \(V\) is a symmetric bilinear form on \(V{}\text{.}\) Also, the zero bilinear form is in \(V^{(2)}_{\text{ sym } }\text{.}\) Thus \(V^{(2)}_{\text{ sym } }\) is a subspace of \(V^{(2)}\!\text{.}\) Similarly, the verification that \(V^{(2)}_{\text{ alt } }\) is a subspace of \(V^{(2)}\) is straightforward.
    🔗
    Next, we want to show that \(V^{(2)} = V^{(2)}_{\text{ sym } } + V^{(2)}_{\text{ alt } }\text{.}\) To do this, suppose \(\beta \in V^{(2)}\!\text{.}\) Define \(\rho, \alpha \in V^{(2)}\) by
    \begin{equation*} \rho(u,w) = \frac{ \beta(u,w) + \beta(w,u) }{2} \andd \alpha (u,w) = \frac{ \beta(u,w) - \beta(w,u) }{2}. \end{equation*}
    🔗
    Then \(\rho \in V^{(2)}_{\text{ sym } }\) and \(\alpha \in V^{(2)}_{\text{ alt } }\text{,}\) and \(\beta = \rho + \alpha\text{.}\) Thus \(V^{(2)} = V^{(2)}_{\text{ sym } } + V^{(2)}_{\text{ alt } }\text{.}\)
    🔗
    Finally, to show that the intersection of the two subspaces under consideration equals \(\{ 0 \}\text{,}\) suppose \(\beta \in V^{(2)}_{\text{ sym } } \cap V^{(2)}_{\text{ alt } }\text{.}\) If \(u, w \in V{}\text{,}\) then 9.16 implies that
    \begin{equation*} \beta(u,w) = -\beta(w, u) = -\beta(u,w) \end{equation*}
    and hence \(\beta(u, w) = 0\text{.}\) Thus \(\beta = 0\text{.}\) Hence \(V^{(2)} = V^{(2)}_{\text{ sym } } \oplus V^{(2)}_{\text{ alt } }\) (by Theorem 1.50).
    🔗
    🔗
    🔗

    Subsection 9.1.3 Quadratic Forms

    Definition 9.18. quadratic form associated with a bilinear form, \(q_\beta\).

    For \(\beta\) a bilinear form on \(V{}\text{,}\) define a function \(\fun {q_\beta} V {\F{}}\) by \(q_\beta(v) = \beta(v, v)\text{.}\) A function \(\fun q V {\F{}}\) is called a quadratic form on \(V\) if there exists a bilinear form \(\beta\) on \(V\) such that \(q = q_\beta\text{.}\)
    🔗
    🔗
    Note that if \(\beta\) is a bilinear form, then \(q_\beta = 0\) if and only if \(\beta\) is alternating.
    🔗

    Example 9.19. quadratic form.

    Suppose \(\beta\) is the bilinear form on \(\R3\) defined by
    \begin{equation*} \beta( (x_1, x_2,x_3), (y_1, y_2, y_3) ) = x_1 y_1 - 4x_1 y_2 + 8x_1 y_3 - 3x_3 y_3. \end{equation*}
    🔗
    Then \(q_\beta\) is the quadratic form on \(\R3\) given by the formula
    \begin{equation*} q_\beta(x_1, x_2, x_3) = {x_1}^{2} - 4 x_1 x_2 +8 x_1 x_3 - 3{x_3}^{2}{}. \end{equation*}
    🔗
    🔗
    The quadratic form in the example above is typical of quadratic forms on \(\FF n\text{,}\) as shown in the next result.
    🔗

    Theorem 9.20. quadratic forms on \(\F n\).

    Suppose \(n\) is a positive integer and \(q\) is a function from \(\F n\) to \(\F{}{}\text{.}\) Then \(q\) is a quadratic form on \(\F n\) if and only if there exist numbers \(A_{j,k} \in \F{}\) for \(j, k \in \{ 1, \ldots, n \}\) such that
    \begin{equation*} q(x_1, \ldots, x_n) = \sum_{k=1}^n \sum_{j=1}^n A_{j,k} x_j x_k \end{equation*}
    for all \((x_1, \ldots, x_n) \in \FF n\text{.}\)
    🔗
    🔗

    Proof.
    First suppose \(q\) is a quadratic form on \(\FF n\text{.}\) Thus there exists a bilinear form \(\beta\) on \(\F n\) such that \(q = q_\beta\text{.}\) Let \(A\) be the matrix of \(\beta\) with respect to the standard basis of \(\FF n\text{.}\) Then for all \((x_1, \ldots, x_n) \in \FF n\text{,}\) we have the desired equation
    \begin{equation*} q(x_1, \ldots, x_n) = \beta( (x_1, \ldots, x_n), (x_1, \ldots, x_n) ) = \sum_{k=1}^n \sum_{j=1}^n A_{j,k} x_j x_k. \end{equation*}
    🔗
    Conversely, suppose there exist numbers \(A_{j,k} \in \F{}\) for \(j, k \in \{ 1, \ldots, n \}\) such that
    \begin{equation*} q(x_1, \ldots, x_n) = \sum_{k=1}^n \sum_{j=1}^n A_{j,k} x_j x_k \end{equation*}
    for all \((x_1, \ldots, x_n) \in \FF n\text{.}\) Define a bilinear form \(\beta\) on \(\F n\) by
    \begin{equation*} \beta( (x_1, \ldots, x_n), (y_1, \ldots, y_n) ) = \sum_{k=1}^n \sum_{j=1}^n A_{j,k} x_j y_k. \end{equation*}
    🔗
    Then \(q = q_\beta\text{,}\) as desired.
    🔗
    🔗
    Although quadratic forms are defined in terms of an arbitrary bilinear form, the equivalence of (a) and (b) in the result below shows that a symmetric bilinear form can always be used.
    🔗

    Theorem 9.21. characterizations of quadratic forms.

    Suppose \(\fun q V {\F{}}\) is a function. The following are equivalent.
    1. \(q\) is a quadratic form.
      🔗
      🔗
    2. There exists a unique symmetric bilinear form \(\rho\) on \(V\) such that \(q = q_\rho\text{.}\)
      🔗
      🔗
    3. \(q(\lambda v) = \lambda^2 q(v)\) for all \(\lambda \in \F{}\) and all \(v \in V{}\text{,}\) and the function
      \begin{equation*} (u, w) \mapsto q(u+w) - q(u) - q(w) \end{equation*}
      is a symmetric bilinear form on \(V{}\text{.}\)
      🔗
      🔗
    4. \(q(2 v) = 4 q(v)\) for all \(v \in V{}\text{,}\) and the function
      \begin{equation*} (u, w) \mapsto q(u+w) - q(u) - q(w) \end{equation*}
      is a symmetric bilinear form on \(V{}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    First suppose (a) holds, so \(q\) is a quadratic form. Hence there exists a bilinear form \(\beta\) such that \(q = q_\beta\text{.}\) By 9.17, there exist a symmetric bilinear form \(\rho\) on \(V\) and an alternating bilinear form \(\alpha\) on \(V\) such that \(\beta = \rho + \alpha\text{.}\) Now
    \begin{equation*} q = q_\beta = q_\rho + q_\alpha = q_\rho. \end{equation*}
    🔗
    If \(\rho' \in V^{(2)}_{\text{ sym } }\) also satisfies \(q_{\rho'} = q\text{,}\) then \(q_{\rho' - \rho} = 0\text{;}\) thus \(\rho' - \rho \in V^{(2)}_{\text{ sym } } \cap V^{(2)}_{\text{ alt } }\text{,}\) which implies that \(\rho' = \rho\) (by Theorem 9.17). This completes the proof that (a) implies (b).
    🔗
    Now suppose (b) holds, so there exists a symmetric bilinear form \(\rho\) on \(V\) such that \(q = q_\rho\text{.}\) If \(\lambda \in \F{}\) and \(v \in V\) then
    \begin{equation*} q(\lambda v) = \rho(\lambda v, \lambda v) = \lambda \rho(v, \lambda v) = \lambda^2 \rho(v, v) = \lambda^2 q(v), \end{equation*}
    showing that the first part of (c) holds.
    🔗
    If \(u, w \in V{}\text{,}\) then
    \begin{equation*} q(u+w) - q(u) - q(w) = \rho(u+w, u+ w) - \rho(u, u) - \rho(w, w) = 2 \rho(u, w). \end{equation*}
    🔗
    Thus the function \((u, w) \mapsto q(u+w) - q(u) - q(w)\) equals \(2\rho\text{,}\) which is a symmetric bilinear form on \(V{}\text{,}\) completing the proof that (b) implies (c).
    🔗
    Clearly (c) implies (d).
    🔗
    Now suppose (d) holds. Let \(\rho\) be the symmetric bilinear form on \(V\) defined by
    \begin{equation*} \rho(u, w) = \frac{ q(u+w) - q(u) - q(w) }{2}. \end{equation*}
    🔗
    If \(v \in V{}\text{,}\) then
    \begin{equation*} \rho(v,v) = \frac{ q(2v) - q(v) - q(v) }{2} = \frac{4q(v) - 2q(v)}{2} = q(v). \end{equation*}
    🔗
    Thus \(q = q_\rho\text{,}\) completing the proof that (d) implies (a).
    🔗
    🔗

    Example 9.22. symmetric bilinear form associated with a quadratic form.

    Suppose \(q\) is the quadratic form on \(\R3\) given by the formula
    \begin{equation*} q(x_1, x_2, x_3) = {x_1}^{2} - 4 x_1 x_2 +8 x_1 x_3 - 3{x_3}^{2}{}. \end{equation*}
    🔗
    A bilinear form \(\beta\) on \(\R3\) such that \(q = q_\beta\) is given by Example 9.19, but this bilinear form is not symmetric, as promised by Theorem 9.21(b). However, the bilinear form \(\rho\) on \(\R3\) defined by
    \begin{equation*} \rho( (x_1, x_2,x_3), (y_1, y_2, y_3) ) = x_1 y_1 - 2 x_1 y_2 - 2 x_2 y_1 + 4x_1 y_3 + 4x_3 y_1- 3x_3 y_3 \end{equation*}
    is symmetric and satisfies \(q = q_\rho\text{.}\)
    🔗
    🔗
    The next result states that for each quadratic form we can choose a basis such that the quadratic form looks like a weighted sum of squares of the coordinates, meaning that there are no cross terms of the form \(x_j x_k\) with \(j \ne k\text{.}\)
    🔗

    Theorem 9.23. diagonalization of quadratic form.

    Suppose \(q\) is a quadratic form on \(V{}\text{.}\)
    1. There exist a basis \(e_1, \ldots, e_n\) of \(V\) and \(\lambda_1, \ldots, \lambda_n \in \F{}\) such that
      \begin{equation*} q( x_1 e_1 + \cdots + x_n e_n ) = \lambda_1 {x_1}^{2} + \cdots + \lambda_n {x_n}^{2} \end{equation*}
      for all \(x_1, \ldots, x_n \in \F{}{}\text{.}\)
      🔗
      🔗
    2. If \(\F{} = \R{}\) and \(V\) is an inner product space, then the basis in (a) can be chosen to be an orthonormal basis of \(V{}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. There exists a symmetric bilinear form \(\rho\) on \(V\) such that \(q = q_\rho\) (by Theorem 9.21). Now there exists a basis \(e_1, \ldots, e_n\) of \(V\) such that \(\M( \rho, (e_1, \ldots, e_n) )\) is a diagonal matrix (by Theorem 9.12). Let \(\lambda_1, \ldots, \lambda_n\) denote the entries on the diagonal of this matrix. Thus
      \begin{equation*} \rho(e_j, e_k) = \begin{cases}\lambda_j \amp \text{ if } j = k,\\ 0 \amp \text{ if } j \ne k \end{cases} \end{equation*}
      for all \(j, k \in \{ 1, \ldots, n \}\text{.}\) If \(x_1, \ldots, x_n \in \F{}{}\text{,}\) then
      \begin{align*} q( x_1 e_1 + \cdots + x_n e_n ) \amp = \rho( x_1 e_1 + \cdots + x_n e_n, x_1 e_1 + \cdots + x_n e_n )\\ \amp = \sum_{k=1}^n \sum_{j=1}^n x_j x_k \rho(e_j, e_k)\\ \amp = \lambda_1 {x_1}^{2} + \cdots + \lambda_n {x_n}^{2}{}\text{,} \end{align*}
      as desired.
      🔗
      🔗
    2. Suppose \(\F{} = \R{}\) and \(V\) is an inner product space. Then 9.13 tells us that the basis in (a) can be chosen to be an orthonormal basis of \(V{}\text{.}\)
      🔗
      🔗
