    Section 3.1 Vector Space of Linear Maps

    Subsection 3.1.1 Definition and Examples of Linear Maps

    Now we are ready for one of the key definitions in linear algebra.
    🔗

    Definition 3.1. linear map.

    A linear map from \(V\) to \(W\) is a function \(T\colon V \rightarrow W\) with the following properties.
    1. additivity.
      \(T(u + v) = Tu + Tv\) for all \(u, v \in V{}\text{.}\)
      🔗
      🔗
    2. homogeneity.
      \(T(\lambda v) = \lambda(Tv)\) for all \(\lambda \in \F{}\) and all \(v \in V{}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Aside
    Some mathematicians use the phrase linear transformation, which means the same as linear map.
    🔗
    Note that for linear maps we often use the notation \(Tv\) as well as the usual function notation \(T(v)\text{.}\)
    🔗

    Notation 3.2. \(\Lc(V,W)\text{,}\) \(\Lc(V)\).

    1. The set of linear maps from \(V\) to \(W\) is denoted by \(\Lc(V{},W)\text{.}\)
      🔗
      🔗
    2. The set of linear maps from \(V\) to \(V\) is denoted by \(\Lc(V)\text{.}\) In other words, \(\Lc(V) = \Lc(V{},V)\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Let’s look at some examples of linear maps. Make sure you verify that each of the functions defined in the next example is indeed a linear map:
    🔗

    Example 3.3. linear maps.

    1. zero.
      In addition to its other uses, we let the symbol \(0\) denote the linear map that takes every element of some vector space to the additive identity of another (or possibly the same) vector space. To be specific, \(0 \in \Lc(V{},W)\) is defined by
      \begin{equation*} 0v = 0. \end{equation*}
      The \(0\) on the left side of the equation above is a function from \(V\) to \(W{}\text{,}\) whereas the \(0\) on the right side is the additive identity in \(W{}\text{.}\) As usual, the context should allow you to distinguish between the many uses of the symbol \(0\text{.}\)
      🔗
      🔗
    2. identity operator.
      The identity operator, denoted by \(I\text{,}\) is the linear map on some vector space that takes each element to itself. To be specific, \(I \in \Lc(V)\) is defined by
      \begin{equation*} Iv = v. \end{equation*}
      🔗
      🔗
    3. differentiation.
      Define \(D\in \Lc\bigl(\P(\R{})\bigr)\) by
      \begin{equation*} Dp = p'\!. \end{equation*}
      The assertion that this function is a linear map is another way of stating a basic result about differentiation: \((f + g)' = f' + g'\) and \((\lambda f)' = \lambda f'\) whenever \(f, g\) are differentiable and \(\lambda\) is a constant.
      🔗
      🔗
    4. integration.
      Define \(T\in \Lc\bigl(\P(\R{}),\R{}\bigr)\) by
      \begin{equation*} Tp = \int_0^1 p. \end{equation*}
      The assertion that this function is linear is another way of stating a basic result about integration: the integral of the sum of two functions equals the sum of the integrals, and the integral of a constant times a function equals the constant times the integral of the function.
      🔗
      🔗
    5. multiplication by \(x^2\).
      Define a linear map \(T\in \Lc\bigl(\P(\R{})\bigr)\) by
      \begin{equation*} (Tp)(x) = x^2 p(x) \end{equation*}
      for each \(x \in \R{}\text{.}\)
      🔗
      🔗
    6. backward shift.
      Recall that \(\F{\infty}\) denotes the vector space of all sequences of elements of \(\F{}{}\text{.}\) Define a linear map \(T\in \Lc( \F{\infty} )\) by
      \begin{equation*} T(x_1, x_2, x_3, \dots) = (x_2, x_3, \dots). \end{equation*}
      🔗
      🔗
    7. from \(\R3\) to \(\R2\).
      Define a linear map \(T\in \Lc( \RR{3},\R{2} )\) by
      \begin{equation*} T(x,y,z) = (2x - y + 3z, 7x + 5y -6z). \end{equation*}
      🔗
      🔗
    8. from \(\F{n}\) to \(\F{m}\).
      To generalize the previous example, let \(m\) and \(n\) be positive integers, let \(A_{j,k} \in \F{}\) for each \(j = 1, \dots, m\) and each \(k = 1, \dots , n\text{,}\) and define a linear map \(T\in \Lc( \FF{n},\F{m} )\) by
      \begin{equation*} T(x_1, \dots, x_n) = (A_{1,1}x_1 + \dots + A_{1,n} x_n, \dots, A_{m,1}x_1 + \dots + A_{m,n} x_n). \end{equation*}
      Actually every linear map from \(\F{n}\) to \(\F{m}\) is of this form.
      🔗
      🔗
    9. composition.
      Fix a polynomial \(q \in \P(\R{})\text{.}\) Define a linear map \(T \in \Lc( \P(\R{}) )\) by
      \begin{equation*} (Tp)(x) = p( q(x) ). \end{equation*}
      🔗
      🔗
    🔗
    🔗
    The existence part of the next result means that we can find a linear map that takes on whatever values we wish on the vectors in a basis. The uniqueness part of the next result means that a linear map is completely determined by its values on a basis.
    🔗

    Theorem 3.4. linear map lemma.

    Suppose \(v_1, \dots, v_n\) is a basis of \(V\) and \(w_1, \dots, w_n \in W{}\text{.}\) Then there exists a unique linear map \(T \colon V \to W\) such that
    \begin{equation*} Tv_k = w_k \end{equation*}
    for each \(k = 1, \dots, n\text{.}\)
    🔗
    🔗

    Proof.
    First we show the existence of a linear map \(T\) with the desired property. Define \(T \colon V \to W\) by
    \begin{equation*} T(c_1 v_1 + \dots + c_n v_n) = c_1 w_1 + \dots + c_n w_n, \end{equation*}
    where \(c_1, \dots, c_n\) are arbitrary elements of \(\F{}{}\text{.}\) The list \(v_1, \dots, v_n\) is a basis of \(V{}\text{.}\) Thus the equation above does indeed define a function \(T\) from \(V\) to \(W\) (because each element of \(V\) can be uniquely written in the form \(c_1 v_1 + \dots + c_n v_n\)).
    🔗
    For each \(k\text{,}\) taking \(c_k = 1\) and the other \(c\)’s equal to \(0\) in the equation above shows that \(Tv_k = w_k\text{.}\)
    🔗
    If \(u, v \in V\) with \(u = a_1 v_1 + \dots + a_n v_n\) and \(v = c_1 v_1 + \dots + c_n v_n\text{,}\) then
    \begin{align*} T(u + v) \amp = T\bigl( (a_1 + c_1) v_1 + \dots + (a_n + c_n) v_n \bigr)\\ \amp = (a_1 + c_1) w_1 + \dots + (a_n + c_n) w_n\\ \amp = (a_1 w_1 + \dots + a_n w_n) + (c_1 w_1 + \dots + c_n w_n)\\ \amp = Tu + Tv\text{.} \end{align*}
    🔗
    Similarly, if \(\lambda \in \F{}\) and \(v = c_1 v_1 + \dots + c_n v_n\text{,}\) then
    \begin{align*} T(\lambda v) \amp = T( \lambda c_1 v_1 + \dots + \lambda c_n v_n)\\ \amp = \lambda c_1 w_1 + \dots + \lambda c_n w_n\\ \amp = \lambda (c_1 w_1 + \dots + c_n w_n)\\ \amp = \lambda Tv\text{.} \end{align*}
    🔗
    Thus \(T\) is a linear map from \(V\) to \(W{}\text{.}\)
    🔗
    To prove uniqueness, now suppose that \(T \in \Lc(V{},W)\) and that \(Tv_k = w_k\) for each \(k = 1, \dots, n\text{.}\) Let \(c_1, \dots, c_n \in \F{}{}\text{.}\) Then the homogeneity of \(T\) implies that \(T(c_k v_k) = c_k w_k\) for each \(k = 1, \dots, n\text{.}\) The additivity of \(T\) now implies that
    \begin{equation*} T(c_1 v_1 + \dots + c_n v_n) = c_1 w_1 + \dots + c_n w_n. \end{equation*}
    🔗
    Thus \(T\) is uniquely determined on \(\Span(v_1, \dots, v_n)\) by the equation above. Because \(v_1, \dots, v_n\) is a basis of \(V{}\text{,}\) this implies that \(T\) is uniquely determined on \(V{}\text{,}\) as desired.
    🔗
    🔗
    🔗

    Subsection 3.1.2 Algebraic Operations on \(\Lc(V, W)\)

    We begin by defining addition and scalar multiplication on \(\Lc(V{},W)\text{.}\)
    🔗

    Definition 3.5. addition and scalar multiplication on \(\Lc(V,W)\).

    Suppose \(S, T \in \Lc(V{},W)\) and \(\lambda \in \F{}{}\text{.}\) The sum \(S + T\) and the product \(\lambda T\) are the linear maps from \(V\) to \(W\) defined by
    \begin{equation*} (S+T)(v) = Sv + Tv \andd (\lambda T)(v) = \lambda (Tv) \end{equation*}
    for all \(v \in V{}\text{.}\)
    🔗
    🔗

    Aside
    Linear maps are pervasive throughout mathematics. However, they are not as ubiquitous as imagined by people who seem to think \(\cos\) is a linear map from \(\R{}\) to \(\R{}\) when they incorrectly write that \(\cos(x + y)\) equals \(\cos x + \cos y\) and that \(\cos 2x\) equals \(2\cos x\text{.}\)
    🔗
    You should verify that \(S+T\) and \(\lambda T\) as defined above are indeed linear maps. In other words, if \(S, T \in \Lc(V{},W)\) and \(\lambda \in \F{}{}\text{,}\) then \(S+T \in \Lc(V{}, W)\) and \(\lambda T \in \Lc(V{}, W)\text{.}\)
    🔗
    Because we took the trouble to define addition and scalar multiplication on \(\Lc(V{},W)\text{,}\) the next result should not be a surprise.
    🔗

    Theorem 3.6. \(\Lc(V,W)\) is a vector space.

    With the operations of addition and scalar multiplication as defined above, \(\Lc(V{},W)\) is a vector space.
    🔗
    🔗
    The routine proof of the result above is left to the reader. Note that the additive identity of \(\Lc(V{},W)\) is the zero linear map defined in Example 3.3.
    🔗
    Usually it makes no sense to multiply together two elements of a vector space, but for some pairs of linear maps a useful product exists, as in the next definition.
    🔗

    Definition 3.7. product of linear maps.

    If \(T \in \Lc(U,V)\) and \(S \in \Lc(V{},W)\text{,}\) then the product \(ST \in \Lc(U,W)\) is defined by
    \begin{equation*} (ST)(u) = S(Tu) \end{equation*}
    for all \(u \in U\text{.}\)
    🔗
    🔗
    Thus \(ST\) is just the usual composition \(S \circ T\) of two functions, but when both functions are linear, we usually write \(ST\) instead of \(S \circ T{}\text{.}\) The product notation \(ST\) helps make the distributive properties (see next result) seem natural.
    🔗
    Note that \(ST\) is defined only when \(T\) maps into the domain of \(S\text{.}\) You should verify that \(ST\) is indeed a linear map from \(U\) to \(W\) whenever \(T \in \Lc(U,V)\) and \(S \in \Lc(V{},W)\text{.}\)
    🔗

    Theorem 3.8. algebraic properties of products of linear maps.

    1. associativity.
      \((T{}_1T{}_2)T{}_3 = T{}_1(T{}_2T{}_3)\) whenever \(T{}_1\text{,}\) \(T{}_2\text{,}\) and \(T{}_3\) are linear maps such that the products make sense (meaning \(T{}_3\) maps into the domain of \(T{}_2\text{,}\) and \(T{}_2\) maps into the domain of \(T{}_1\)).
      🔗
      🔗
    2. identity.
      \(TI = IT = T\) whenever \(T \in \Lc(V{},W)\text{;}\) here the first \(I\) is the identity operator on \(V{}\text{,}\) and the second \(I\) is the identity operator on \(W\text{.}\)
      🔗
      🔗
    3. distributive properties.
      \((S_1 + S_2) T = S_1 T + S_2 T \andd S(T{}_1 + T{}_2) = ST{}_1 + ST{}_2\) whenever \(T{},T{}_1,T{}_2 \in \Lc(U,V)\) and \(S, S_1, S_2 \in \Lc(V{},W)\text{.}\)
      🔗
      🔗
    🔗
    🔗
    The routine proof of the result above is left to the reader.
    🔗
    Multiplication of linear maps is not commutative. In other words, it is not necessarily true that \(ST = TS\text{,}\) even if both sides of the equation make sense.
    🔗

    Example 3.9. two noncommuting linear maps from \(\P(\R)\) to \(\P(\R)\).

    Suppose \(D \in \Lc\bigl(\P(\R{})\bigr)\) is the differentiation map defined in Example 3.3 and \(T \in \Lc\bigl(\P(\R{})\bigr)\) is the multiplication by \(x^2\) map defined earlier in this section. Then
    \begin{equation*} \bigl((TD)p\bigr)(x) = x^2 p' \! (x) \butt \bigl((DT)p\bigr)(x) = x^2 p' \! (x) + 2 x p(x). \end{equation*}
    🔗
    Thus \(TD \ne DT{}\)—differentiating and then multiplying by \(x^2\) is not the same as multiplying by \(x^2\) and then differentiating.
    🔗
    🔗

    Theorem 3.10. linear maps take \(0\) to \(0\).

    Suppose \(T\) is a linear map from \(V\) to \(W{}\text{.}\) Then \(T(0) = 0\text{.}\)
    🔗
    🔗

    Proof.
    By additivity, we have
    \begin{equation*} T(0) = T(0 + 0) = T(0) + T(0). \end{equation*}
    🔗
    Add the additive inverse of \(T(0)\) to each side of the equation above to conclude that \(T(0) = 0\text{.}\)
    🔗
    🔗
    Suppose \(m, b \in \R{}\text{.}\) The function \(\fun f {\R{}} {\R{}}\) defined by
    \begin{equation*} f(x) = mx + b \end{equation*}
    is a linear map if and only if \(b = 0\) (use 3.10). Thus the linear functions of high school algebra are not the same as linear maps in the context of linear algebra.
    🔗

    Give an example of a function \(\phi\colon \R{2} \to \R{}\) such that
    \begin{equation*} \phi(av) = a \phi(v) \end{equation*}
    for all \(a \in \R{}\) and all \(v \in \R{2}\) but \(\phi\) is not linear. Note: This exercise and the next exercise show that neither homogeneity nor additivity alone is enough to imply that a function is a linear map.
    🔗
    🔗

    9.

    Give an example of a function \(\phi \colon \C{} \to \C{}\) such that
    \begin{equation*} \phi(w + z) = \phi(w) + \phi(z) \end{equation*}
    for all \(w, z \in \C{}\) but \(\phi\) is not linear. (Here \(\C{}\) is thought of as a complex vector space.) Note: There also exists a function \(\phi \colon \R{} \to \R{}\) such that \(\phi\) satisfies the additivity condition above but \(\phi\) is not linear. However, showing the existence of such a function involves considerably more advanced tools.
    🔗
    🔗

    10.

    Prove or give a counterexample: If \(q \in \P(\R{})\) and \(\fun T {\P(\R{})} {\P(\R{})}\) is defined by \(Tp = q \circ p\text{,}\) then \(T\) is a linear map. Note: The function \(T\) defined here differs from the function \(T\) defined in the last bullet point of Example 3.3 by the order of the functions in the compositions.
    🔗

    11.

    Suppose \(V\) is finite-dimensional and \(T \in \Lc(V)\text{.}\) Prove that \(T\) is a scalar multiple of the identity if and only if \(ST = TS\) for every \(S \in \Lc(V)\text{.}\)
    🔗

    12.

    Suppose \(U\) is a subspace of \(V\) with \(U \ne V{}\text{.}\) Suppose \(S \in \Lc(U, W)\) and \(S \ne 0\) (which means that \(Su \ne 0\) for some \(u \in U\)). Define \(T \colon V \to W\) by
    \begin{equation*} Tv = \begin{cases}Sv \amp \text{ if } v \in U,\\ 0 \amp \text{ if } v \in V \textit{ and \ }v \notin U. \end{cases} \end{equation*}
    🔗
    Prove that \(T\) is not a linear map on \(V{}\text{.}\)
    🔗
    🔗

    13.

    Suppose \(V\) is finite-dimensional. Prove that every linear map on a subspace of \(V\) can be extended to a linear map on \(V{}\text{.}\) In other words, show that if \(U\) is a subspace of \(V\) and \(S \in \Lc(U, W)\text{,}\) then there exists \(T \in \Lc(V{}, W)\) such that \(Tu = Su\) for all \(u \in U\text{.}\) Note: The result in this exercise is used in the proof of Theorem 3.125.
    🔗
    🔗

    14.

    Suppose \(V\) is finite-dimensional with \(\dim V > 0\text{,}\) and suppose \(W\) is infinite-dimensional. Prove that \(\Lc(V{},W)\) is infinite-dimensional.

    15.

    Suppose \(v_1, \dots, v_m\) is a linearly dependent list of vectors in \(V{}\text{.}\) Suppose also that \(W \ne \{0\}\text{.}\) Prove that there exist \(w_1, \dots, w_m \in W\) such that no \(T \in \Lc(V{}, W)\) satisfies \(Tv_k = w_k\) for each \(k = 1, \dots, m\text{.}\)

    Suppose \(V\) is finite-dimensional with \(\dim V > 1\text{.}\) Prove that there exist \(S, T \in \Lc(V)\) such that \(ST \ne TS\text{.}\)

    17.

    Suppose \(V\) is finite-dimensional. Show that the only two-sided ideals of \(\Lc(V)\) are \(\{ 0 \}\) and \(\Lc(V)\text{.}\) Note: A subspace \(\E\) of \(\Lc(V)\) is called a two-sided ideal of \(\Lc(V)\) if \(TE \in \E\) and \(ET \in \E\) for all \(E \in \E\) and all \(T \in \Lc(V)\text{.}\)
