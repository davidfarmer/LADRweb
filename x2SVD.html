    Section 7.5 Singular Value Decomposition

    Subsection 7.5.1 Singular Values

    We will need the following result in this section.
    🔗

    Theorem 7.52. properties of \(T^*T\).

    Suppose \(T \in \Lc(V{}, W)\text{.}\) Then
    1. \(T^* T\) is a positive operator on \(V\text{;}\)
      🔗
      🔗
    2. \(\ker T^*T = \ker T\text{;}\)
      🔗
      🔗
    3. \(\ran T^*T = \ran T^*\text{;}\)
      🔗
      🔗
    4. \(\dim \ran T = \dim \ran T^* = \dim \ran T^* T{}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. We have
      \begin{equation*} ( T^* T )^* = T^* ( T^* )^* = T^* T{}. \end{equation*}
      Thus \(T^* T\) is self-adjoint. If \(v \in V{}\text{,}\) then
      \begin{equation*} \langle ( T^*T )v , v \rangle = \langle T^*(Tv), v \rangle = \langle Tv, Tv \rangle = \|Tv\|^2 \ge 0. \end{equation*}
      Thus \(T^* T\) is a positive operator.
      🔗
      🔗
    2. First suppose \(v \in \ker T^*T{}\text{.}\) Then
      \begin{equation*} \lVert Tv \rVert ^2 = \langle Tv, Tv \rangle = \langle T^*Tv, v \rangle = \langle 0, v \rangle = 0. \end{equation*}
      Thus \(Tv = 0\text{,}\) proving that \(\ker T^*T \subset \ker T{}\text{.}\) The inclusion in the other direction is clear, because if \(v \in V\) and \(Tv = 0\text{,}\) then \(T^*Tv = 0\text{.}\) Thus \(\ker T^*T = \ker T\text{,}\) completing the proof of (b).
      🔗
      🔗
    3. We already know from (a) that \(T^*T\) is self-adjoint. Thus
      \begin{equation*} \ran T^* T = ( \ker T^* T )^\perp = (\ker T)^\perp = \ran T^*{}, \end{equation*}
      where the first and last equalities come from Theorem 7.6 and the second equality comes from (b).
      🔗
      🔗
    4. To verify the first equation in (d), note that
      \begin{equation*} \dim \ran T = \dim ( \ker T^* )^\perp = \dim W - \dim \ker T^* = \dim \ran T^*{}, \end{equation*}
      where the first equality comes from Theorem 7.6(d), the second equality comes from Theorem 6.47, and the last equality comes from the fundamental theorem of linear maps Theorem 3.21. The equality \(\dim \ran T^* = \dim \ran T^* T\) follows from (c).
      🔗
      🔗
    🔗
    🔗
    The eigenvalues of an operator tell us something about the behavior of the operator. Another collection of numbers, called the singular values, is also useful. Eigenspaces and the notation \(E\) (used in the examples) were defined in Definition 5.46.
    🔗

    Definition 7.53. singular values.

    Suppose \(T \in \Lc(V{}, W)\text{.}\) The singular values of \(T\) are the nonnegative square roots of the eigenvalues of \(T^* T{}\text{,}\) listed in decreasing order, each included as many times as the dimension of the corresponding eigenspace of \(T^*T{}\text{.}\)
    🔗
    🔗

    Example 7.54. singular values of an operator on \(\F4\).

    Define \(T \in \Lc( \F{4} )\) by \(T(z_1, z_2, z_3, z_4) = (0, 3 z_1, 2 z_2, -3z_4)\text{.}\) A calculation shows that
    \begin{equation*} T^*T(z_1, z_2, z_3, z_4) = (9 z_1, 4z_2, 0, 9z_4), \end{equation*}
    as you should verify. Thus the standard basis of \(\F4\) diagonalizes \(T^*T\text{,}\) and we see that the eigenvalues of \(T^* T\) are \(9\text{,}\) \(4\text{,}\) and \(0\text{.}\) Also, the dimensions of the eigenspaces corresponding to the eigenvalues are
    \begin{equation*} \dim E( 9, T^* T ) = 2 \andd \dim E( 4, T^* T ) = 1 \andd \dim E( 0, T^*T ) = 1. \end{equation*}
    🔗
    Taking nonnegative square roots of these eigenvalues of \(T^*T\) and using dimension information from above, we conclude that the singular values of \(T\) are \(3, 3, 2, 0\text{.}\)
    🔗
    The only eigenvalues of \(T\) are \(-3\) and \(0\text{.}\) Thus in this case, the collection of eigenvalues did not pick up the number \(2\) that appears in the definition (and hence the behavior) of \(T\text{,}\) but the list of singular values does include \(2\text{.}\)
    🔗
    🔗

    Example 7.55. singular values of a linear map from \(\F4\) to \(\F3\).

    Suppose \(T \in \Lc( \F4, \F3 )\) has matrix (with respect to the standard bases)
    \begin{equation*} \begin{pmatrix}0 \amp 0 \amp 0 \amp -5 \\ 0 \amp 0 \amp 0 \amp 0\\ 1 \amp 1 \amp 0 \amp 0 \end{pmatrix} . \end{equation*}
    🔗
    You can verify that the matrix of \(T^* T\) is
    \begin{equation*} \begin{pmatrix}1 \amp 1 \amp 0 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0\\ 0 \amp 0 \amp 0\amp 0\\ 0 \amp 0 \amp 0 \amp 25 \end{pmatrix} \end{equation*}
    and that the eigenvalues of the operator \(T^*T\) are \(25\text{,}\) \(2\text{,}\) \(0\text{,}\) with \(\dim E( 25, T^* T ) = 1\text{,}\) \(\dim E( 2, T^* T ) = 1\text{,}\) and \(\dim E( 0, T^*T ) = 2\text{.}\) Thus the singular values of \(T\) are \(5, \sqrt{2}, 0, 0\text{.}\)
    🔗
    🔗
    See Exercise 7.5.2.2 for a characterization of the positive singular values.
    🔗

    Theorem 7.56. role of positive singular values.

    Suppose that \(T \in \Lc(V{}, W)\text{.}\) Then
    1. \(T\) is injective \(\iff 0\) is not a singular value of \(T\text{;}\)
      🔗
      🔗
    2. the number of positive singular values of \(T\) equals \(\dim \ran T\text{;}\)
      🔗
      🔗
    3. \(T\) is surjective \(\iff\) number of positive singular values of \(T\) equals \(\dim W{}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    The linear map \(T\) is injective if and only if \(\ker T = \{ 0 \}\text{,}\) which happens if and only if \(\ker T^*T = \{ 0 \}\) [by Theorem 7.52(b)] , which happens if and only if \(0\) is not an eigenvalue of \(T^*T\text{,}\) which happens if and only if \(0\) is not a singular value of \(T\text{,}\) completing the proof of (a).
    🔗
    The spectral theorem applied to \(T^* T\) shows that \(\dim \ran T^*T\) equals the number of positive eigenvalues of \(T^*T\) (counting repetitions). Thus 7.52(d) implies that \(\dim \ran T\) equals the number of positive singular values of \(T\text{,}\) proving (b).
    🔗
    Use (b) and Theorem 2.38 to show that (c) holds.
    🔗
    🔗
    The table below compares eigenvalues with singular values.
    🔗
    list of eigenvalues list of singular values
    context: vector spaces context: inner product spaces
    defined only for linear maps from a vector space to itself defined for linear maps from an inner product space to a possibly different inner product space
    can be arbitrary real numbers (if \(\F{} = \R{}\)) or complex numbers (if \(\F{} = \C{}\)) are nonnegative numbers
    can be the empty list if \(\F{} = \R{}\) length of list equals dimension of domain

    no standard order, especially if \(\F{} = \C{}\) always listed in decreasing order
    The next result nicely characterizes isometries in terms of singular values.
    🔗

    Theorem 7.57. isometries characterized by having all singular values equal \(1\).

    Suppose that \(S \in \Lc(V{}, W)\text{.}\) Then
    🔗
    \(S\) is an isometry \(\iff\) all singular values of \(S\) equal \(1\text{.}\)
    🔗
    🔗
    🔗

    Proof.
    We have
    \begin{align*} \text{ \(S\) is an isometry } \amp \iff S^* S = I\\ \amp \iff \text{ all eigenvalues of \(S^* S\) equal \(1\) }\\ \amp \iff \text{ all singular values of \(S\) equal~\(1\), } \end{align*}
    where the first equivalence comes from Theorem 7.39 and the second equivalence comes from the spectral theorem ( Theorem 7.24 or 7.26) applied to the self-adjoint operator \(S^* S\text{.}\)
    🔗
    🔗
    🔗

    Subsection 7.5.2 SVD for Linear Maps and for Matrices

    Aside
    The singular value decomposition is useful in computational linear algebra because good techniques exist for approximating eigenvalues and eigenvectors of positive operators such as \(T^*T\text{,}\) whose eigenvalues and eigenvectors lead to the singular value decomposition.
    🔗
    The next result shows that every linear map from \(V\) to \(W\) has a remarkably clean description in terms of its singular values and orthonormal lists in \(V\) and \(W{}\text{.}\) In the next section we will see several important applications of the singular value decomposition (often called the SVD).
    🔗

    Theorem 7.58. singular value decomposition.

    Suppose \(T \in \Lc(V{}, W)\) and the positive singular values of \(T\) are \(s_1, \dots, s_m\text{.}\) Then there exist orthonormal lists \(e_1, \dots, e_m\) in \(V\) and \(f_1, \dots, f_m\) in \(W\) such that
    \begin{equation} Tv = s_1 \langle v, e_1 \rangle f_1 + \dots + s_m \langle v, e_m \rangle f_m\tag{7.13} \end{equation}
    for every \(v \in V{}\text{.}\)
    🔗
    🔗

    Proof.
    Let \(s_1, \ldots, s_n\) denote the singular values of \(T\) (thus \(n = \dim V\)). Because \(T^*T\) is a positive operator [see 7.52(a)] , the spectral theorem implies that there exists an orthonormal basis \(e_1, \ldots, e_n\) of \(V\) with
    \begin{equation} T^*T e_k = {s_k}^{2} e_k\tag{7.14} \end{equation}
    for each \(k = 1, \ldots, n\text{.}\)
    🔗
    For each \(k = 1, \ldots, m\text{,}\) let
    \begin{equation} f_k = \frac{Te_k}{s_k}.\tag{7.15} \end{equation}
    🔗
    If \(j, k \in \{ 1, \ldots, m \}\text{,}\) then
    \begin{equation*} \langle f_j, f_k \rangle = \frac{1}{s_j s_k} \langle Te_j, Te_k \rangle = \frac{1}{s_j s_k} \langle e_j, T^*T e_k \rangle = \frac{s_k}{s_j} \langle e_j, e_k \rangle = \begin{cases}0 \amp \text{ if } j \ne k ,\\ 1 \amp \text{ if } j = k. \end{cases} \end{equation*}
    🔗
    Thus \(f_1, \ldots, f_m\) is an orthonormal list in \(W{}\text{.}\)
    🔗
    If \(k \in \{ 1, \ldots, n \}\) and \(k > m\text{,}\) then \(s_k = 0\) and hence \(T^*T e_k = 0\) (by (7.14)), which implies that \(Te_k = 0\) [by Theorem 7.52(b)] .
    🔗
    Suppose \(v \in V{}\text{.}\) Then
    \begin{align*} Tv \amp = T( \langle v, e_1 \rangle e_1 + \cdots + \langle v, e_n \rangle e_n )\\ \amp = \langle v, e_1 \rangle Te_1 + \cdots + \langle v, e_m \rangle Te_m\\ \amp = s_1 \langle v, e_1 \rangle f_1 + \cdots + s_m \langle v, e_m \rangle f_m\text{,} \end{align*}
    where the last index in the first line switched from \(n\) to \(m\) in the second line because \(Te_k = 0\) if \(k > m\) (as noted in the paragraph above) and the third line follows from (7.15). The equation above is our desired result.
    🔗
    🔗
    Suppose \(T \in \Lc(V{}, W)\text{,}\) the positive singular values of \(T\) are \(s_1, \ldots, s_m\text{,}\) and \(e_1, \ldots, e_m\) and \(f_1, \ldots, f_m\) are as in the singular value decomposition 7.58. The orthonormal list \(e_1, \ldots, e_m\) can be extended to an orthonormal basis \(e_1, \ldots, e_{\dim V}\) of \(V\) and the orthonormal list \(f_1, \ldots, f_m\) can be extended to an orthonormal basis \(f_1, \ldots, f_{\dim W}\) of \(W{}\text{.}\) The formula (7.13) shows that
    \begin{equation*} Te_k = \begin{cases}s_k f_k \amp \text{ if } 1 \le k \le m,\\ 0 \amp \text{ if } m \lt k \le \dim V{}. \end{cases} \end{equation*}
    🔗
    Thus the matrix of \(T\) with respect to the orthonormal bases \((e_1, \ldots, e_{\dim V})\) and \((f_1, \ldots, f_{\dim W})\) has the simple form
    \begin{equation*} \M( T, (e_1, \ldots, e_{\dim V}), (f_1, \ldots, f_{\dim W}) )_{j,k} = \begin{cases}s_k \amp \text{ if } 1 \le j = k \le m, \\ 0 \amp \text{ otherwise } . \end{cases} \end{equation*}
    🔗
    If \(\dim V = \dim W\) (as happens, for example, if \(W = V\)), then the matrix described in the paragraph above is a diagonal matrix. If we extend the definition of diagonal matrix as follows to apply to matrices that are not necessarily square, then we have proved the wonderful result that every linear map from \(V\) to \(W\) has a diagonal matrix with respect to appropriate orthonormal bases.
    🔗

    Definition 7.59. diagonal matrix.

    An \(M\)-by-\(N\) matrix \(A\) is called a diagonal matrix if all entries of the matrix are \(0\) except possibly \(A_{k,k}\) for \(k = 1, \ldots, \min \{ M, N \}\text{.}\)
    🔗
    🔗
    The table below compares the spectral theorem ( Theorem 7.24 and Theorem 7.26) with the singular value decomposition Theorem 7.58.
    🔗
    spectral theorem singular value decomposition
    describes only self-adjoint operators (when \(\F{} = \R{}\)) or normal operators (when \(\F{} = \C{}\)) describes arbitrary linear maps from an inner product space to a possibly different inner product space
    produces a single orthonormal basis produces two orthonormal lists, one for domain space and one for range space, that are not necessarily the same even when range space equals domain space
    different proofs depending on whether \(\F{} = \R{}\) or \(\F{}=\C{}\) same proof works regardless of whether \(\F{} = \R{}\) or \(\F{}=\C{}\)
    The singular value decomposition gives us a new way to understand the adjoint and the inverse of a linear map. Specifically, the next result shows that given a singular value decomposition of a linear map \(T \in \Lc(V{},W)\text{,}\) we can obtain the adjoint of \(T\) simply by interchanging the roles of the \(e\)’s and the \(f\)’s (see (7.17)). Similarly, we can obtain the pseudoinverse \(T^\dagger\) (see 6.60) of \(T\) by interchanging the roles of the \(e\)’s and the \(f\) ’s and replacing each positive singular value \(s_k\) of \(T\) with \(1/s_k\) (see (7.18)).
    🔗
    Recall that the pseudoinverse \(T^\dagger\) in (7.18) below equals the inverse \(T^{-1}\) if \(T\) is invertible [see 6.61(a)] .
    🔗

    Theorem 7.60. singular value decomposition of adjoint and pseudoinverse.

    Suppose \(T \in \Lc(V{}, W)\) and the positive singular values of \(T\) are \(s_1, \dots, s_m\text{.}\) Suppose \(e_1, \dots, e_m\) and \(f_1, \dots, f_m\) are orthonormal lists in \(V\) and \(W\) such that
    \begin{equation} Tv = s_1 \langle v, e_1 \rangle f_1 + \dots + s_m \langle v, e_m \rangle f_m\tag{7.16} \end{equation}
    for every \(v \in V{}\text{.}\) Then
    \begin{equation} T^*w = s_1 \langle w, f_1 \rangle e_1 + \dots + s_m \langle w, f_m \rangle e_m\tag{7.17} \end{equation}
    and
    \begin{equation} T^\dagger w = \frac{\langle w, f_1 \rangle }{s_1} e_1 + \dots + \frac{\langle w, f_m \rangle }{s_m} e_m\tag{7.18} \end{equation}
    for every \(w \in W{}\text{.}\)
    🔗
    🔗

    Proof.
    If \(v \in V\) and \(w \in W\) then
    \begin{align*} \langle Tv,w \rangle \amp = \langle s_1 \langle v, e_1 \rangle f_1 + \dots + s_m \langle v, e_m \rangle f_m, w \rangle\\ \amp = s_1 \langle v, e_1 \rangle \langle f_1,w \rangle + \dots + s_m \langle v, e_m \rangle \langle f_m, w \rangle\\ \amp = \langle v, s_1 \langle w, f_1 \rangle e_1 + \dots + s_m \langle w, f_m \rangle e_m \rangle \text{.} \end{align*}
    🔗
    This implies that
    \begin{equation*} T^*w = s_1 \langle w, f_1 \rangle e_1 + \dots + s_m \langle w, f_m \rangle e_m, \end{equation*}
    🔗
    proving (7.17).
    🔗
    To prove (7.18), suppose \(w \in W{}\text{.}\) Let
    \begin{equation*} v = \frac{\langle w, f_1 \rangle }{s_1} e_1 + \dots + \frac{\langle w, f_m \rangle }{s_m} e_m. \end{equation*}
    🔗
    Apply \(T\) to both sides of the equation above, getting
    \begin{align*} Tv \amp = \frac{\langle w, f_1 \rangle }{s_1} Te_1 + \dots + \frac{\langle w, f_m \rangle }{s_m} Te_m\\ \amp = \langle w, f_1 \rangle f_1 + \dots + \langle w, f_m \rangle f_m\\ \amp = P_{\!\ran T} w\text{,} \end{align*}
    where the second line holds because (7.16) implies that \(Te_k = s_k f_k\) if \(k = 1, \ldots, m\text{,}\) and the last line above holds because (7.16) implies that \(f_1, \ldots, f_m\) spans \(\ran T\) and thus is an orthonormal basis of \(\ran T\) [and hence 6.52(i) applies] . The equation above, the observation that \(v \in (\ker T)^\perp\) [see Exercise 7.5.2.8(b)] , and the definition of \(T^\dagger w\) (see 6.60) show that \(v = T^\dagger w\text{,}\) proving (7.18).
    🔗
    🔗

    Example 7.61. finding a singular value decomposition.

    Define \(T \in \Lc( \F4, \F3 )\) by \(T(x_1, x_2, x_3, x_4) = (-5x_4, 0, x_1 + x_2)\text{.}\) We want to find a singular value decomposition of \(T{}\text{.}\) The matrix of \(T\) (with respect to the standard bases) is
    \begin{equation*} \begin{pmatrix}0 \amp 0 \amp 0 \amp -5 \\ 0 \amp 0 \amp 0 \amp 0\\ 1 \amp 1 \amp 0 \amp 0 \end{pmatrix} . \end{equation*}
    🔗
    Thus, as discussed in Example 7.55, the matrix of \(T^*T\) is
    \begin{equation*} \begin{pmatrix}1 \amp 1 \amp 0 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0\\ 0 \amp 0 \amp 0\amp 0\\ 0 \amp 0 \amp 0 \amp 25 \end{pmatrix} , \end{equation*}
    and the positive eigenvalues of \(T^*T\) are \(25\text{,}\) \(2\text{,}\) with \(\dim E( 25, T^* T ) = 1\) and \(\dim E( 2, T^* T ) = 1\text{.}\) Hence the positive singular values of \(T\) are \(5, \sqrt{2}\text{.}\)
    🔗
    Thus to find a singular value decomposition of \(T\text{,}\) we must find an orthonormal list \(e_1, e_2\) in \(\F4\) and an orthonormal list \(f_1, f_2\) in \(\F3\) such that
    \begin{equation*} Tv = 5 \langle v, e_1 \rangle f_1 + \sqrt{2} \langle v, e_2 \rangle f_2 \end{equation*}
    for all \(v \in \F4\text{.}\)
    🔗
    An orthonormal basis of \(E( 25, T^* T )\) is the vector \((0,0,0,1 )\text{;}\) an orthonormal basis of \(E( 2, T^*T )\) is the vector \(( \frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}},0,0 )\text{.}\) Thus, following the proof of Theorem 7.58, we take
    \begin{equation*} e_1 = (0,0,0,1) \andd e_2 = ( \frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}},0,0 ) \end{equation*}
    and
    \begin{equation*} f_1 = \frac{Te_1}{5} = (-1, 0, 0) \andd f_2 = \frac{Te_2}{\sqrt{2}} = (0, 0, 1). \end{equation*}
    🔗
    Then, as expected, we see that \(e_1, e_2\) is an orthonormal list in \(\F4\) and \(f_1, f_2\) is an orthonormal list in \(\F3\) and
    \begin{equation*} Tv = 5 \langle v, e_1 \rangle f_1 + \sqrt{2} \langle v, e_2 \rangle f_2 \end{equation*}
    for all \(v \in \F4\text{.}\) Thus we have found a singular value decomposition of \(T{}\text{.}\)
    🔗

    The next result translates the singular value decomposition from the context of linear maps to the context of matrices. Specifically, the following result gives a factorization of an arbitrary matrix as the product of three nice matrices. The proof gives an explicit construction of these three matrices in terms of the singular value decomposition.
    🔗
    In the next result, the phrase “orthonormal columns” should be interpreted to mean that the columns are orthonormal with respect to the standard Euclidean inner product.
    🔗

    Theorem 7.62. matrix version of SVD.

    Suppose \(A\) is a \(p\)-by-\(n\) matrix of rank \(m\ge1\text{.}\) Then there exist a \(p\)-by-\(m\) matrix \(B\) with orthonormal columns, an \(m\)-by-\(m\) diagonal matrix \(D\) with positive numbers on the diagonal, and an \(n\)-by-\(m\) matrix \(C\) with orthonormal columns such that
    \begin{equation*} A = B D C^*{}. \end{equation*}
    🔗
    🔗

    Proof.
    Let \(\fun T {\F{n}} {\F{p}}\) be the linear map whose matrix with respect to the standard bases equals \(A\text{.}\) Then \(\dim \ran T = m\) (by Theorem 3.73). Let
    \begin{equation} Tv = s_1 \langle v, e_1 \rangle f_1 + \cdots + s_m \langle v, e_m \rangle f_m\tag{7.19} \end{equation}
    be a singular value decomposition of \(T{}\text{.}\) Let
    \begin{align*} B \amp = \text{ the \(p\)-by-\(m\) matrix whose columns are } f_1, \ldots, f_m,\\ D \amp = \text{ the \(m\)-by-\(m\) diagonal matrix whose diagonal entries are } s_1, \ldots, s_m,\\ C \amp = \text{ the \(n\)-by-\(m\) matrix whose columns are } e_1, \ldots, e_m\text{.} \end{align*}
    🔗
    Let \(u_1, \ldots, u_m\) denote the standard basis of \(\FF{m}\text{.}\) If \(k \in \{ 1, \ldots, m \}\) then
    \begin{equation*} (AC - BD)u_k = Ae_k - B(s_k u_k) = s_k f_k - s_k f_k = 0. \end{equation*}
    🔗
    Thus \(AC = B D\text{.}\)
    🔗
    Multiply both sides of this last equation by \(C^*\) (the conjugate transpose of \(C\)) on the right to get
    \begin{equation*} ACC^* = B D C^*{}. \end{equation*}
    🔗
    Note that the rows of \(C^*\) are the complex conjugates of \(e_1, \ldots, e_m\text{.}\) Thus if \(k \in \{ 1, \ldots, m \}\text{,}\) then the definition of matrix multiplication shows that \(C^*e_k = u_k\text{;}\) hence \(CC^* e_k = e_k\text{.}\) Thus \(ACC^*v = Av\) for all \(v \in \Span(e_1, \dots, e_m)\text{.}\)
    🔗
    If \(v \in ( \Span(e_1, \ldots, e_m) )^\perp\text{,}\) then \(Av = 0\) (as follows from (7.19)) and \(C^*v = 0\) (as follows from the definition of matrix multiplication). Hence \(ACC^*v = Av\) for all \(v \in ( \Span(e_1, \dots, e_m) )^\perp\text{.}\)
    🔗
    Because \(ACC^*\) and \(A\) agree on \(\Span(e_1, \dots, e_m)\) and on \(( \Span(e_1, \dots, e_m) )^\perp\text{,}\) we conclude that \(ACC^* = A\text{.}\) Thus the displayed equation above becomes
    \begin{equation*} A = B D C^*{}, \end{equation*}
    as desired.
    🔗
    🔗
    Note that the matrix \(A\) in the result above has \(pn\) entries. In comparison, the matrices \(B\text{,}\) \(D\text{,}\) and \(C\) above have a total of
    \begin{equation*} m(p + m + n) \end{equation*}
    entries. Thus if \(p\) and \(n\) are large numbers and the rank \(m\) is considerably less than \(p\) and \(n\text{,}\) then the number of entries that must be stored on a computer to represent \(A\) is considerably less than \(pn\text{.}\)
