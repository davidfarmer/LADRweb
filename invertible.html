    Section 3.4 Invertibility and Isomorphisms

    Subsection 3.4.1 Invertible Linear Maps

    We begin this section by defining the notions of invertible and inverse in the context of linear maps.
    🔗

    Definition 3.59. invertible, inverse.

    1. A linear map \(T \in \Lc(V{},W)\) is called invertible if there exists a linear map \(S \in \Lc(W{},V)\) such that \(ST\) equals the identity operator on \(V\) and \(TS\) equals the identity operator on \(W{}\text{.}\)
      🔗
      🔗
    2. A linear map \(S \in \Lc(W{},V)\) satisfying \(ST = I\) and \(TS = I\) is called an inverse of \(T\) (note that the first \(I\) is the identity operator on \(V\) and the second \(I\) is the identity operator on \(W\)).
      🔗
      🔗
    🔗
    🔗
    The definition above mentions “an inverse”. However, the next result shows that we can change this terminology to “the inverse”.
    🔗

    Theorem 3.60. inverse is unique.

    An invertible linear map has a unique inverse.
    🔗
    🔗

    Proof.
    Suppose \(T \in \Lc(V{},W)\) is invertible and \(S_1\) and \(S_2\) are inverses of \(T{}\text{.}\) Then
    \begin{equation*} S_1 = S_1I = S_1(TS_2) = (S_1T)S_2 = IS_2 = S_2. \end{equation*}
    🔗
    Thus \(S_1 = S_2\text{.}\)
    🔗
    🔗
    Now that we know that the inverse is unique, we can give it a notation.
    🔗

    Notation 3.61. \(T^{-1}\).

    If \(T\) is invertible, then its inverse is denoted by \(T^{-1}{}\text{.}\) In other words, if \(T \in \Lc(V{},W)\) is invertible, then \(T^{-1}\) is the unique element of \(\Lc(W{},V)\) such that \(T^{-1}T = I\) and \(TT^{-1} = I\text{.}\)
    🔗
    🔗

    Example 3.62. inverse of a linear map from \(\R3\) to \(\R3\).

    Suppose \(T \in \Lc( \R3 )\) is defined by \(T(x, y, z) = (-y, x, 4z)\text{.}\) Thus \(T\) is a counterclockwise rotation by \(90^\circ\) in the \(xy\)-plane and a stretch by a factor of \(4\) in the direction of the \(z\)-axis.
    🔗
    Hence the inverse map \(T^{-1} \in \Lc( \R3 )\) is the clockwise rotation by \(90^\circ\) in the \(xy\)-plane and a stretch by a factor of \(\frac{1}{4}\) in the direction of the \(z\)-axis:
    \begin{equation*} T^{-1}(x, y, z) = ( y, -x, \tfrac{1}{4}z ). \end{equation*}
    🔗
    🔗
    The next result shows that a linear map is invertible if and only if it is one-to-one and onto.
    🔗

    Theorem 3.63. invertibility \(\iff\) injectivity and surjectivity.

    A linear map is invertible if and only if it is injective and surjective.
    🔗
    🔗

    Proof.
    Suppose \(T\in \Lc(V{},W)\text{.}\) We need to show that \(T\) is invertible if and only if it is injective and surjective.
    🔗
    First suppose \(T\) is invertible. To show that \(T\) is injective, suppose \(u, v \in V\) and \(Tu = Tv\text{.}\) Then
    \begin{equation*} u = T^{-1}(Tu) = T^{-1}(Tv) = v, \end{equation*}
    so \(u = v\text{.}\) Hence \(T\) is injective.
    🔗
    We are still assuming that \(T\) is invertible. Now we want to prove that \(T\) is surjective. To do this, let \(w \in W{}\text{.}\) Then \(w = T( T^{-1}w )\text{,}\) which shows that \(w\) is in the range of \(T{}\text{.}\) Thus \(\ran T = W{}\text{.}\) Hence \(T\) is surjective, completing this direction of the proof.
    🔗
    Now suppose \(T\) is injective and surjective. We want to prove that \(T\) is invertible. For each \(w \in W{}\text{,}\) define \(S(w)\) to be the unique element of \(V\) such that \(T( S(w) ) = w\) (the existence and uniqueness of such an element follow from the surjectivity and injectivity of \(T\)). The definition of \(S\) implies that \(T \circ S\) equals the identity operator on \(W{}\text{.}\)
    🔗
    To prove that \(S \circ T\) equals the identity operator on \(V{}\text{,}\) let \(v \in V{}\text{.}\) Then
    \begin{equation*} T\bigl((S \circ T)v \bigr) = (T \circ S)(Tv) = I(Tv) = Tv. \end{equation*}
    🔗
    This equation implies that \((S \circ T)v = v\) (because \(T\) is injective). Thus \(S \circ T\) equals the identity operator on \(V{}\text{.}\)
    🔗
    To complete the proof, we need to show that \(S\) is linear. To do this, suppose \(w_1\text{,}\) \(w_2 \in W{}\text{.}\) Then
    \begin{equation*} T( S(w_1) + S(w_2) ) = T( S(w_1) ) + T( S(w_2) ) = w_1 + w_2. \end{equation*}
    🔗
    Thus \(S(w_1) + S(w_2)\) is the unique element of \(V\) that \(T\) maps to \(w_1 + w_2\text{.}\) By the definition of \(S\text{,}\) this implies that \(S(w_1 + w_2) = S(w_1) + S(w_2)\text{.}\) Hence \(S\) satisfies the additive property required for linearity.
    🔗
    The proof of homogeneity is similar. Specifically, if \(w \in W\) and \(\lambda \in \F{}{}\text{,}\) then
    \begin{equation*} T( \lambda S(w) ) = \lambda T( S(w) ) = \lambda w. \end{equation*}
    🔗
    Thus \(\lambda S(w)\) is the unique element of \(V\) that \(T\) maps to \(\lambda w\text{.}\) By the definition of \(S\text{,}\) this implies that \(S(\lambda w) = \lambda S(w)\text{.}\) Hence \(S\) is linear, as desired.
    🔗
    🔗
    For a linear map from a vector space to itself, you might wonder whether injectivity alone, or surjectivity alone, is enough to imply invertibility. On infinite-dimensional vector spaces, neither condition alone implies invertibility, as illustrated by the next example, which uses two familiar linear maps from Example 3.3.
    🔗

    Example 3.64. neither injectivity nor surjectivity implies invertibility.

    1. The multiplication by \(x^2\) linear map from \(\P(\R{})\) to \(\P(\R{})\) (see 3.3) is injective but it is not invertible because it is not surjective (the polynomial \(1\) is not in the range).
      🔗
      🔗
    2. The backward shift linear map from \(\F{\infty}\) to \(\F{\infty}\) (see 3.3) is surjective but it is not invertible because it is not injective [the vector \((1, 0, 0, 0, \dotsc)\) is in the null space] .
      🔗
      🔗
    🔗
    🔗
    In view of the example above, the next result is remarkable—it states that for a linear map from a finite-dimensional vector space to a vector space of the same dimension, either injectivity or surjectivity alone implies the other condition. Note that the hypothesis below that \(\dim V = \dim W\) is automatically satisfied in the important special case where \(V\) is finite-dimensional and \(W = V{}\text{.}\)
    🔗

    Theorem 3.65. injectivity is equivalent to surjectivity (if \(\dim V = \dim W \lt \infty\)).

    Suppose that \(V\) and \(W\) are finite-dimensional vector spaces, \(\dim V = \dim W{}\text{,}\) and \(T \in \Lc(V{}, W)\text{.}\) Then
    \begin{equation*} T is invertible \iff T is injective \iff T is surjective. \end{equation*}
    🔗
    🔗

    Proof.
    The fundamental theorem of linear maps Theorem 3.21 states that
    \begin{equation} \dim V = \dim \ker T + \dim \ran T{}.\tag{3.66} \end{equation}
    🔗
    If \(T\) is injective (which by Theorem 3.15 is equivalent to the condition \(\dim \ker T = 0\)), then the equation above implies that
    \begin{equation*} \dim \ran T = \dim V - \dim \ker T = \dim V = \dim W{}, \end{equation*}
    which implies that \(T\) is surjective (by Theorem 2.40).
    🔗
    Conversely, if \(T\) is surjective, then (3.66) implies that
    \begin{equation*} \dim \ker T = \dim V - \dim \ran T = \dim V - \dim W = 0, \end{equation*}
    which implies that \(T\) is injective.
    🔗
    Thus we have shown that \(T\) is injective if and only if \(T\) is surjective. Thus if \(T\) is either injective or surjective, then \(T\) is both injective and surjective, which implies that \(T\) is invertible. Hence \(T\) is invertible if and only if \(T\) is injective if and only if \(T\) is surjective.
    🔗
    🔗
    The next example illustrates the power of the previous result. Although it is possible to prove the result in the example below without using linear algebra, the proof using linear algebra is cleaner and easier.
    🔗

    Example 3.67. there exists a polynomial \(p\) such that \(\bigl((x^2 + 5x + 7)p\bigr)'' = q\).

    The linear map
    \begin{equation*} p \mapsto \bigl((x^2 + 5x + 7)p\bigr)'' \end{equation*}
    from \(\P(\R{})\) to itself is injective, as you can show. Thus we are tempted to use 3.65 to show that this map is surjective. However, Example 3.64 shows that the magic of Theorem 3.65 does not apply to the infinite-dimensional vector space \(\P(\R{})\text{.}\) We will get around this problem by restricting attention to the finite-dimensional vector space \(\P{}_m(\R{})\text{.}\)
    🔗
    Suppose \(q \in \P(\R{})\text{.}\) There exists a nonnegative integer \(m\) such that \(q \in \P{}_m(\R{})\text{.}\) Define \(T \colon \P{}_m(\R{}) \to \P{}_m(\R{})\) by
    \begin{equation*} Tp = \bigl((x^2 + 5x + 7)p\bigr)''\!. \end{equation*}
    🔗
    Multiplying a nonzero polynomial by \((x^2 + 5x + 7)\) increases the degree by \(2\text{,}\) and then differentiating twice reduces the degree by \(2\text{.}\) Thus \(T\) is indeed a linear map from \(\P{}_m(\R{})\) to itself.
    🔗
    Every polynomial whose second derivative equals \(0\) is of the form \(ax + b\text{,}\) where \(a, b \in \R{}\text{.}\) Thus \(\ker T = \{0\}\text{.}\) Hence \(T\) is injective.
    🔗
    Thus \(T\) is surjective (by Theorem 3.65), which means that there exists a polynomial \(p \in \P{}_m(\R{})\) such that \(\bigl((x^2 + 5x + 7)p\bigr)'' = q\text{,}\) as claimed in the title of this example.
    🔗
    🔗
    Exercise 6.1.2.35 in Section 6.1 gives a similar but more spectacular example of using 3.65.
    🔗
    The hypothesis in the result below that \(\dim V = \dim W\) holds in the important special case in which \(V\) is finite-dimensional and \(W = V{}\text{.}\) Thus in that case, the equation \(ST = I\) implies that \(ST = TS\text{,}\) even though we do not have multiplicative commutativity of arbitrary linear maps from \(V\) to \(V{}\text{.}\)
    🔗

    Theorem 3.68. \(ST = I \iff TS = I\) (on vector spaces of the same dimension).

    Suppose \(V\) and \(W\) are finite-dimensional vector spaces of the same dimension, \(S \in \Lc(W{},V)\text{,}\) and \(T \in \Lc(V{}, W)\text{.}\) Then \(ST = I\) if and only if \(TS = I\text{.}\)
    🔗
    🔗

    Proof.
    First suppose \(ST = I\text{.}\) If \(v \in V\) and \(Tv = 0\text{,}\) then
    \begin{equation*} v = Iv= (ST)v = S(Tv) = S(0) = 0. \end{equation*}
    🔗
    Thus \(T\) is injective (by Theorem 3.15). Because \(V\) and \(W\) have the same dimension, this implies that \(T\) is invertible (by Theorem 3.65).
    🔗
    Now multiply both sides of the equation \(ST = I\) by \(T^{-1}\) on the right, getting
    \begin{equation*} S = T^{-1}{}. \end{equation*}
    🔗
    Thus \(TS = TT^{-1} = I\text{,}\) as desired.
    🔗
    To prove the implication in the other direction, simply reverse the roles of \(S\) and \(T\) (and \(V\) and \(W\)) in the direction we have already proved, showing that if \(TS = I\text{,}\) then \(ST = I\text{.}\)
    🔗
    🔗
    🔗

    Subsection 3.4.2 Isomorphic Vector Spaces

    The next definition captures the idea of two vector spaces that are essentially the same, except for the names of their elements.
    🔗

    Definition 3.69. isomorphism, isomorphic.

    1. An isomorphism is an invertible linear map.
      🔗
      🔗
    2. Two vector spaces are called isomorphic if there is an isomorphism from one vector space onto the other one.
      🔗
      🔗
    🔗
    🔗

    Aside
    The Greek word isos means equal; the Greek word morph means shape. Thus isomorphic literally means equal shape.
    🔗
    Think of an isomorphism \(T\colon V \to W\) as relabeling \(v \in V\) as \(Tv \in W{}\text{.}\) This viewpoint explains why two isomorphic vector spaces have the same vector space properties. The terms “isomorphism” and “invertible linear map” mean the same thing. Use “isomorphism” when you want to emphasize that the two spaces are essentially the same.
    🔗
    It can be difficult to determine whether two mathematical structures (such as groups or topological spaces) are essentially the same, differing only in the names of the elements of underlying sets. However, the next result shows that we need to look at only a single number (the dimension) to determine whether two vector spaces are isomorphic.
    🔗

    Theorem 3.70. dimension shows whether vector spaces are isomorphic.

    Two finite-dimensional vector spaces over \(\F{}\) are isomorphic if and only if they have the same dimension.
    🔗
    🔗

    Proof.
    First suppose \(V\) and \(W\) are isomorphic finite-dimensional vector spaces. Thus there exists an isomorphism \(T\) from \(V\) onto \(W{}\text{.}\) Because \(T\) is invertible, we have \(\ker T = \{0\}\) and \(\ran T = W{}\text{.}\) Thus
    \begin{equation*} \dim \ker T = 0 \andd \dim \ran T = \dim W{}. \end{equation*}
    🔗
    The formula
    \begin{equation*} \dim V = \dim \ker T + \dim \ran T \end{equation*}
    🔗
    (the fundamental theorem of linear maps, which is 3.21) thus becomes the equation \(\dim V = \dim W{}\text{,}\) completing the proof in one direction.
    🔗
    To prove the other direction, suppose \(V\) and \(W\) are finite-dimensional vector spaces of the same dimension. Let \(v_1, \dots, v_n\) be a basis of \(V\) and \(w_1, \dots, w_n\) be a basis of \(W{}\text{.}\) Let \(T \in \Lc(V{}, W)\) be defined by
    \begin{equation*} T(c_1 v_1 + \dots + c_n v_n) = c_1 w_1 + \dots + c_n w_n. \end{equation*}
    🔗
    Then \(T\) is a well-defined linear map because \(v_1, \dots, v_n\) is a basis of \(V{}\text{.}\) Also, \(T\) is surjective because \(w_1, \dots, w_n\) spans \(W{}\text{.}\) Furthermore, \(\ker T = \{0\}\) because \(w_1, \dots, w_n\) is linearly independent. Thus \(T\) is injective. Because \(T\) is injective and surjective, it is an isomorphism (see 3.63). Hence \(V\) and \(W\) are isomorphic.
    🔗
    🔗

    Aside
    Every finite-dimensional vector space is isomorphic to some \(\FF{n}\text{.}\) Thus why not just study \(\F{n}\) instead of more general vector spaces? To answer this question, note that an investigation of \(\F{n}\) would soon lead to other vector spaces. For example, we would encounter the null space and range of linear maps. Although each of these vector spaces is isomorphic to some \(\FF{m}\text{,}\) thinking of them that way often adds complexity but no new insight.
    🔗
    The previous result implies that each finite-dimensional vector space \(V\) is isomorphic to \(\FF{n}\text{,}\) where \(n = \dim V{}\text{.}\) For example, if \(m\) is a nonnegative integer, then \(\P{}_m(\F{})\) is isomorphic to \(\FF{m+1}\text{.}\)
    🔗
    Recall that the notation \(\F{m,n}\) denotes the vector space of \(m\)-by-\(n\) matrices with entries in \(\F{}{}\text{.}\) If \(v_1, \dots, v_n\) is a basis of \(V\) and \(w_1, \dots, w_m\) is a basis of \(W{}\text{,}\) then for each \(T \in \Lc(V{},W)\text{,}\) we have a matrix \(\M(T) \in \FF{m,n}\text{.}\) Thus once bases have been fixed for \(V\) and \(W{}\text{,}\) \(\M\) becomes a function from \(\Lc(V{},W)\) to \(\FF{m,n}\text{.}\) Notice that Theorem 3.35 and Theorem 3.38 show that \(\M\) is a linear map. This linear map is actually an isomorphism, as we now show.
    🔗

    Theorem 3.71. \(\Lc(V,W)\) and \(\F{m,n}\) are isomorphic.

    Suppose \(v_1, \dots, v_n\) is a basis of \(V\) and \(w_1, \dots, w_m\) is a basis of \(W{}\text{.}\) Then \(\M\) is an isomorphism between \(\Lc(V{},W)\) and \(\FF{m,n}\text{.}\)
    🔗
    🔗

    Proof.
    We already noted that \(\M\) is linear. We need to prove that \(\M\) is injective and surjective.
    🔗
    We begin with injectivity. If \(T \in \Lc(V{},W)\) and \(\M(T) = 0\text{,}\) then \(Tv_k = 0\) for each \(k = 1, \dots, n\text{.}\) Because \(v_1, \dots, v_n\) is a basis of \(V{}\text{,}\) this implies \(T = 0\text{.}\) Thus \(\M\) is injective (by Theorem 3.15).
    🔗
    To prove that \(\M\) is surjective, suppose \(A \in \FF{m,n}\text{.}\) By the linear map lemma Theorem 3.4, there exists \(T \in \Lc(V{},W)\) such that
    \begin{equation*} Tv_k = \sum_{j=1}^m A_{j,k}w_j \end{equation*}
    for each \(k = 1, \dots, n\text{.}\) Because \(\M(T)\) equals \(A\text{,}\) the range of \(\M\) equals \(\FF{m,n}\text{,}\) as desired.
    🔗
    🔗
    Now we can determine the dimension of the vector space of linear maps from one finite-dimensional vector space to another.
    🔗

    Theorem 3.72. \(\dim \Lc(V,W) = (\dim V)(\dim W)\).

    Suppose \(V\) and \(W\) are finite-dimensional. Then \(\Lc(V{},W)\) is finite-dimensional and
    \begin{equation*} \dim \Lc(V{},W) = (\dim V)(\dim W). \end{equation*}
    🔗
    🔗

    Proof.
    The desired result follows from Theorem 3.71, Theorem 3.70, and Theorem 3.40.

    Subsection 3.4.3 Linear Maps Thought of as Matrix Multiplication

    Previously we defined the matrix of a linear map. Now we define the matrix of a vector.
    🔗

    Definition 3.73. matrix of a vector, \(\M(v)\).

    Suppose \(v \in V\) and \(v_1, \dots, v_n\) is a basis of \(V{}\text{.}\) The matrix of \(v\) with respect to this basis is the \(n\)-by-\(1\) matrix
    \begin{equation*} \M(v) = \begin{pmatrix}b_1 \\ \vdots \\ b_n \end{pmatrix} , \end{equation*}
    where \(b_1, \dots, b_n\) are the scalars such that
    \begin{equation*} v = b_1 v_1 + \dots + b_n v_n. \end{equation*}
    🔗
    🔗
    The matrix \(\M(v)\) of a vector \(v \in V\) depends on the basis \(v_1, \dots, v_n\) of \(V{}\text{,}\) as well as on \(v\text{.}\) However, the basis should be clear from the context and thus it is not included in the notation.
    🔗

    Example 3.74. matrix of a vector.

    1. The matrix of the polynomial \(2 - 7x + 5x^3 + x^4\) with respect to the standard basis of \(\P{}_4(\R{})\) is
      \begin{equation*} \begin{pmatrix}2 \\ -7 \\ 0 \\ 5 \\ 1 \end{pmatrix} . \end{equation*}
      🔗
      🔗
    2. The matrix of a vector \(x \in \F{n}\) with respect to the standard basis is obtained by writing the coordinates of \(x\) as the entries in an \(n\)-by-\(1\) matrix. In other words, if \(x = (x_1, \dots, x_n) \in \FF{n}\text{,}\) then
      \begin{equation*} \M(x) = \begin{pmatrix}x_1 \\ \vdots \\ x_n \end{pmatrix} . \end{equation*}
      🔗
      🔗
    🔗
    🔗
    Occasionally we want to think of elements of \(V\) as relabeled to be \(n\)-by-\(1\) matrices. Once a basis \(v_1, \dots, v_n\) is chosen, the function \(\M\) that takes \(v \in V\) to \(\M(v)\) is an isomorphism of \(V\) onto \(\F{n,1}\) that implements this relabeling.
    🔗
    Recall that if \(A\) is an \(m\)-by-\(n\) matrix, then \(A_{\cdot, k}\) denotes the \(k^\nth\) column of \(A\text{,}\) thought of as an \(m\)-by-\(1\) matrix. In the next result, \(\M(Tv_k)\) is computed with respect to the basis \(w_1, \dots, w_m\) of \(W{}\text{.}\)
    🔗

    Theorem 3.75. \(\M(T)_{\cdot, k} = \M(Tv_k)\).

    Suppose \(T \in \Lc(V{}, W)\) and \(v_1, \dots, v_n\) is a basis of \(V\) and \(w_1, \dots, w_m\) is a basis of \(W{}\text{.}\) Let \(1 \le k \le n\text{.}\) Then the \(k^\nth\) column of \(\M(T)\text{,}\) which is denoted by \(\M(T)_{\cdot, k}\text{,}\) equals \(\M(Tv_k)\text{.}\)
    🔗
    🔗

    Proof.
    The desired result follows immediately from the definitions of \(\M(T)\) and \(\M(Tv_k)\text{.}\)
    🔗
    🔗
    The next result shows how the notions of the matrix of a linear map, the matrix of a vector, and matrix multiplication fit together.
    🔗

    Theorem 3.76. linear maps act like matrix multiplication.

    Suppose \(T \in \Lc(V{},W)\) and \(v \in V{}\text{.}\) Suppose \(v_1, \dots, v_n\) is a basis of \(V\) and \(w_1, \dots, w_m\) is a basis of \(W{}\text{.}\) Then
    \begin{equation*} \M(Tv) = \M(T) \M(v). \end{equation*}
    🔗
    🔗

    Proof.
    Suppose \(v = b_1 v_1 + \dots + b_n v_n\text{,}\) where \(b_1, \dots, b_n \in \F{}{}\text{.}\) Thus
    \begin{equation} Tv = b_1 Tv_1 + \dots + b_n Tv_n.\tag{3.77} \end{equation}
    🔗
    Hence
    \begin{align*} \M(Tv) \amp = b_1 \M(Tv_1) + \dots + b_n \M(Tv_n)\\ \amp = b_1 \M(T)_{\cdot, 1} + \dots + b_n \M(T)_{\cdot, n}\\ \amp = \M(T) \M(v)\text{,} \end{align*}
    where the first equality follows from (3.77) and the linearity of \(\M\text{,}\) the second equality comes from Theorem 3.75, and the last equality comes from Theorem 3.50.
    🔗
    🔗
    Each \(m\)-by-\(n\) matrix \(A\) induces a linear map from \(\F{n,1}\) to \(\FF{m,1}\text{,}\) namely the matrix multiplication function that takes \(x \in \F{n,1}\) to \(Ax \in \FF{m,1}\text{.}\) The result above can be used to think of every linear map (from a finite-dimensional vector space to another finite-dimensional vector space) as a matrix multiplication map after suitable relabeling via the isomorphisms given by \(\M\!\text{.}\) Specifically, if \(T \in \Lc(V{},W)\) and we identify \(v \in V\) with \(\M(v) \in \FF{n,1}\text{,}\) then the result above says that we can identify \(Tv\) with \(\M(T)\M(v)\text{.}\)
    🔗
    Because the result above allows us to think (via isomorphisms) of each linear map as multiplication on \(\F{n,1}\) by some matrix \(A\text{,}\) keep in mind that the specific matrix \(A\) depends not only on the linear map but also on the choice of bases. One of the themes of many of the most important results in later chapters will be the choice of a basis that makes the matrix \(A\) as simple as possible.
    🔗
    In this book, we concentrate on linear maps rather than on matrices. However, sometimes thinking of linear maps as matrices (or thinking of matrices as linear maps) gives important insights that we will find useful.
    🔗
    Notice that no bases are in sight in the statement of the next result. Although \(\M(T)\) in the next result depends on a choice of bases of \(V\) and \(W{}\text{,}\) the next result shows that the column rank of \(\M(T)\) is the same for all such choices (because \(\ran T\) does not depend on a choice of basis).
    🔗

    Theorem 3.78. dimension of \(\ran T\) equals column rank of \(\M(T)\).

    Suppose \(V\) and \(W\) are finite-dimensional and \(T \in \Lc(V{}, W)\text{.}\) Then \(\dim \ran T\) equals the column rank of \(\M(T)\text{.}\)
    🔗
    🔗

    Proof.
    Suppose \(v_1, \dots, v_n\) is a basis of \(V\) and \(w_1, \dots, w_m\) is a basis of \(W{}\text{.}\) The linear map that takes \(w \in W\) to \(\M(w)\) is an isomorphism from \(W\) onto the space \(\F{m,1}\) of \(m\)-by-\(1\) column vectors. The restriction of this isomorphism to \(\ran T\) [which equals \(\Span(Tv_1, \dots, Tv_n)\) by Exercise 3.2.3.10 in Section 3.2] is an isomorphism from \(\ran T\) onto \(\Span\bigl( \M(Tv_1), \dots, \M(Tv_n) \bigr)\text{.}\) For each \(k \in \{ 1, \ldots, n \}\text{,}\) the \(m\)-by-\(1\) matrix \(\M(Tv_k)\) equals column \(k\) of \(\M(T)\text{.}\) Thus
    \begin{equation*} \dim \ran T = \text{ the column rank of } \M(T), \end{equation*}
    as desired.
    🔗
    🔗
    🔗

    Subsection 3.4.4 Change of Basis

    In Section 3.3 we defined the matrix
    \begin{equation*} \M\bigl(T, (v_1, \dots, v_n), (w_1, \dots, w_m) \bigr) \end{equation*}
    of a linear map \(T\) from \(V\) to a possibly different vector space \(W{}\text{,}\) where \(v_1, \dots, v_n\) is a basis of \(V\) and \(w_1, \dots, w_m\) is a basis of \(W{}\text{.}\) For linear maps from a vector space to itself, we usually use the same basis for both the domain vector space and the target vector space. When using a single basis in both capacities, we often write the basis only once. In other words, if \(T \in \Lc(V)\) and \(v_1, \dots, v_n\) is a basis of \(V{}\text{,}\) then the notation \(\M( T, (v_1, \ldots, v_n) )\) is defined by the equation
    \begin{equation*} \M( T, (v_1, \ldots, v_n) ) = \M( T, (v_1, \ldots, v_n), (v_1, \ldots, v_n) ). \end{equation*}
    🔗
    If the basis \(v_1, \ldots, v_n\) is clear from the context, then we can write just \(\M(T)\text{.}\)
    🔗

    Definition 3.79. identity matrix, I.

    Suppose \(n\) is a positive integer. The \(n\)-by-\(n\) matrix
    \begin{equation*} \begin{pmatrix}1 \amp \amp 0 \\ \amp \ddots \amp \\ 0 \amp \amp 1 \end{pmatrix} \end{equation*}
    with \(1\)’s on the diagonal (the entries where the row number equals the column number) and \(0\)’s elsewhere is called the identity matrix and is denoted by \(I\text{.}\)
    🔗
    🔗
    🔗
    In the definition above, the \(0\) in the lower left corner of the matrix indicates that all entries below the diagonal are \(0\text{,}\) and the \(0\) in the upper right corner indicates that all entries above the diagonal are \(0\text{.}\)
    🔗
    With respect to each basis of \(V{}\text{,}\) the matrix of the identity operator \(I \in \Lc(V)\) is the identity matrix \(I\text{.}\) Note that the symbol \(I\) is used to denote both the identity operator and the identity matrix. The context indicates which meaning of \(I\) is intended. For example, consider the equation \(\M(I) = I;\) on the left side \(I\) denotes the identity operator, and on the right side \(I\) denotes the identity matrix.
    🔗
    If \(A\) is a square matrix (meaning it has the same number of rows as columns) with the same size as \(I\text{,}\) then \(AI = IA = A\text{,}\) as you should verify.
    🔗

    Definition 3.80. invertible, inverse, \(A^{-1}\).

    A square matrix \(A\) is called invertible if there is a square matrix \(B\) of the same size such that \(AB = BA = I\text{;}\) we call \(B\) the inverse of \(A\) and denote it by \(A^{-1}{}\text{.}\)
    🔗
    🔗

    Aside
    Some mathematicians use the terms nonsingular and singular, which mean the same as invertible and noninvertible.
    🔗
    🔗
    The same proof as used in Theorem 3.60 shows that if \(A\) is an invertible square matrix, then there is a unique matrix \(B\) such that \(AB = BA = I\) (and thus the notation \(B = A^{-1}\) is justified).
    🔗
    If \(A\) is an invertible matrix, then \({( A^{-1} )}^{-1} = A\) because
    \begin{equation*} A^{-1} A = A A^{-1} = I. \end{equation*}
    🔗
    Also, if \(A\) and \(C\) are invertible square matrices of the same size, then \(AC\) is invertible and \((AC)^{-1} = C^{-1} A^{-1}\) because
    \begin{align*} (AC) ( C^{-1} A^{-1} ) \amp = A ( C C^{-1} ) A^{-1}\\ \amp = AIA^{-1}\\ \amp = A A^{-1}\\ \amp = I\text{,} \end{align*}
    and similarly \(( C^{-1} A^{-1} )(AC) = I\text{.}\)
    🔗
    The next result holds because we defined matrix multiplication to make it true—see 3.43 and the material preceding it. Now we are just being more explicit about the bases involved.
    🔗

    Theorem 3.81. matrix of product of linear maps.

    Suppose \(T \in \Lc(U, V)\) and \(S \in \Lc(V{}, W)\text{.}\) If \(u_1, \dots, u_m\) is a basis of \(U\text{,}\) \(v_1, \dots, v_n\) is a basis of \(V{}\text{,}\) and \(w_1, \dots, w_p\) is a basis of \(W{}\text{,}\) then
    \begin{align*} \M\bigl(ST\amp , (u_1, \dots, u_m), (w_1, \dots, w_p) \bigr) =\\ \amp \M\bigl(S, (v_1, \dots, v_n), (w_1, \dots, w_p) \bigr) \M\bigl(T, (u_1, \dots, u_m), (v_1, \dots, v_n) \bigr)\text{.} \end{align*}
    🔗
    🔗
    The next result deals with the matrix of the identity operator \(I\) with respect to two different bases. Note that the \(k^{\nth}\) column of \(\M\bigl(I, (u_1, \dots, u_n), (v_1, \dots, v_n)\bigr)\) consists of the scalars needed to write \(u_k\) as a linear combination of the basis \(v_1, \dots, v_n\text{.}\)
    🔗
    In the statement of the next result, \(I\) denotes the identity operator from \(V\) to \(V{}\text{.}\) In the proof, \(I\) also denotes the \(n\)-by-\(n\) identity matrix.
    🔗

    Theorem 3.82. matrix of identity operator with respect to two bases.

    Suppose that \(u_1, \dots, u_n\) and \(v_1, \dots, v_n\) are bases of \(V{}\text{.}\) Then the matrices
    \begin{equation*} \M\bigl(I, (u_1, \dots, u_n), (v_1, \dots, v_n)\bigr) \andd \M\bigl(I, (v_1, \dots, v_n), (u_1, \dots, u_n)\bigr) \end{equation*}
    are invertible, and each is the inverse of the other.
    🔗
    🔗

    Proof.
    In 3.81, replace \(w_k\) with \(u_k\text{,}\) and replace \(S\) and \(T\) with \(I\text{,}\) getting
    \begin{equation*} I = \M\bigl(I, (v_1, \dots, v_n), (u_1, \dots, u_n) \bigr) \M\bigl(I, (u_1, \dots, u_n), (v_1, \dots, v_n) \bigr). \end{equation*}
    🔗
    Now interchange the roles of the \(u\)’s and \(v\)’s, getting
    \begin{equation*} I = \M\bigl(I, (u_1, \dots, u_n), (v_1, \dots, v_n) \bigr) \M\bigl(I, (v_1, \dots, v_n), (u_1, \dots, u_n) \bigr). \end{equation*}
    🔗
    These two equations above give the desired result.
    🔗
    🔗

    Example 3.83. matrix of identity operator on \(\F2\) with respect to two bases.

    Consider the bases \((4, 2), (5, 3)\) and \(\ (1, 0), (0, 1)\) of \(\FF{2}\text{.}\) Because \(I(4,2) = 4(1,0) + 2(0,1)\) and \(I(5, 3) = 5(1,0) + 3(0, 1)\text{,}\) we have
    \begin{equation*} \M\Bigl(I, \bigl((4, 2), (5, 3)\bigr), \bigl((1, 0), (0, 1)\bigr) \Bigr) = \begin{pmatrix}4 \amp 5 \\ 2 \amp 3 \end{pmatrix} . \end{equation*}
    🔗
    The inverse of the matrix above is
    \begin{equation*} \begin{pmatrix}\frac{3}{2} \amp -\frac{5}{2} \\ -1 \amp 2 \end{pmatrix} , \end{equation*}
    as you should verify. Thus 3.82 implies that
    \begin{equation*} \M\Bigl(I, \bigl((1, 0), (0, 1)\bigr), \bigl((4, 2), (5, 3)\bigr) \Bigr) = \begin{pmatrix}\frac{3}{2} \amp -\frac{5}{2} \\ -1 \amp 2 \end{pmatrix} . \end{equation*}
    🔗
    🔗
    Our next result shows how the matrix of \(T\) changes when we change bases. In the next result, we have two different bases of \(V{}\text{,}\) each of which is used as a basis for the domain space and as a basis for the target space. Recall our shorthand notation that allows us to display a basis only once when it is used in both capacities:
    \begin{equation*} \M\bigl(T, (u_1, \dots, u_n)\bigr) = \M\bigl(T, (u_1, \dots, u_n), (u_1, \dots, u_n) \bigr). \end{equation*}
    🔗

    Theorem 3.84. change-of-basis formula.

    Suppose \(T \in \Lc(V)\text{.}\) Suppose \(u_1, \dots, u_n\) and \(v_1, \dots, v_n\) are bases of \(V{}\text{.}\) Let
    \begin{equation*} A= \M\bigl(T, (u_1, \dots, u_n)\bigr) \andd B = \M\bigl(T, (v_1, \dots, v_n)\bigr) \end{equation*}
    and \(C = \M\bigl(I, (u_1, \dots, u_n), (v_1, \dots, v_n)\bigr)\text{.}\) Then
    \begin{equation*} A = C^{-1}B C. \end{equation*}
    🔗
    🔗

    Proof.
    In 3.81, replace \(w_k\) with \(u_k\) and replace \(S\) with \(I\text{,}\) getting
    \begin{equation} A = C^{-1} \M\bigl(T, (u_1, \dots, u_n), (v_1, \dots, v_n) \bigr),\tag{3.85} \end{equation}
    where we have used 3.82.
    🔗
    Again use 3.81, this time replacing \(w_k\) with \(v_k\text{.}\) Also replace \(T\) with \(I\) and replace \(S\) with \(T\text{,}\) getting
    \begin{equation*} \M\bigl(T, (u_1, \dots, u_n), (v_1, \dots, v_n) \bigr) = B C. \end{equation*}
    🔗
    Substituting the equation above into (3.85) gives the equation \(A = C^{-1}B C\text{.}\)
    🔗
    🔗
    The proof of the next result is left as an exercise.
    🔗

    Theorem 3.86. matrix of inverse equals inverse of matrix.

    Suppose that \(v_1, \ldots, v_n\) is a basis of \(V\) and \(T \in \Lc(V)\) is invertible. Then \(\M\bigl(T^{-1}\bigr) = ( \M(T) )^{-1}{}\text{,}\) where both matrices are with respect to the basis \(v_1, \ldots, v_n\text{.}\)

    \begin{equation*} q(x) = ( x^2 + x ) p'' \! (x) +2x p' \! (x) + p(3) \end{equation*}
    for all \(x \in \R{}\text{.}\)

    21.

    Suppose \(n\) is a positive integer and \(A_{j,k} \in \F{}\) for all \(j,k = 1, \dots, n\text{.}\) Prove that the following are equivalent (note that in both parts below, the number of equations equals the number of variables).
    1. The trivial solution \(x_1 = \dots = x_n = 0\) is the only solution to the homogeneous system of equations
      \begin{align*} \sum_{k=1}^n A_{1,k} x_k \amp = 0\\ \amp \vdots\\ \sum_{k=1}^n A_{n,k} x_k \amp = 0\text{.} \end{align*}
      🔗
      🔗
    2. For every \(c_1, \dots, c_n \in \F{}{}\text{,}\) there exists a solution to the system of equations
      \begin{align*} \sum_{k=1}^n A_{1,k} x_k \amp = c_1\\ \amp \vdots\\ \sum_{k=1}^n A_{n,k} x_k \amp = c_n\text{.} \end{align*}

    23.
