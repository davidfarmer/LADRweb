    Section 7.3 Positive Operators

    Definition 7.34. positive operator.

    An operator \(T \in \Lc(V)\) is called positive if \(T\) is self-adjoint and
    \begin{equation*} \langle Tv, v \rangle \ge 0 \end{equation*}
    for all \(v \in V{}\text{.}\)
    🔗
    🔗
    If \(V\) is a complex vector space, then the requirement that \(T\) be self-adjoint can be dropped from the definition above (by Theorem 7.14).
    🔗

    Example 7.35. positive operators.

    1. Let \(T \in \Lc( \F2 )\) be the operator whose matrix (using the standard basis) is \(\left(\begin{matrix}2 \amp -1\\-1 \amp 1 \end{matrix} \right)\text{.}\) Then \(T\) is self-adjoint and \(\langle T(w, z), (w, z) \rangle = 2 \lvert w \rvert ^2 - 2\re( w\overline{z} ) + \lvert z \rvert ^2 = \lvert w-z \rvert ^2 + \lvert w \rvert ^2 \ge 0\) for all \((w, z) \in \F2\text{.}\) Thus \(T\) is a positive operator.
      🔗
      🔗
    2. If \(U\) is a subspace of \(V{}\text{,}\) then the orthogonal projection \(P_{\!U}\) is a positive operator, as you should verify.
      🔗
      🔗
    3. If \(T \in \Lc(V)\) is self-adjoint and \(b, c \in \R{}\) are such that \(b^2 \lt 4 c\text{,}\) then \(T^2 + b T + c I\) is a positive operator, as shown by the proof of Theorem 7.26.
      🔗
      🔗
    🔗
    🔗

    Definition 7.36. square root.

    An operator \(R\) is called a square root of an operator \(T\) if \(R^2 = T{}\text{.}\)
    🔗
    🔗

    Example 7.37. square root of an operator.

    If \(T \in \Lc( \F{3} )\) is defined by \(T(z_1, z_2, z_3) = (z_3, 0, 0)\text{,}\) then the operator \(R \in \Lc( \F{3} )\) defined by \(R(z_1, z_2, z_3) = (z_2, z_3, 0)\) is a square root of \(T\) because \(R^2 = T\text{,}\) as you can verify.
    🔗
    🔗

    Aside
    Because positive operators correspond to nonnegative numbers, better terminology would use the term nonnegative operators. However, operator theorists consistently call these positive operators, so we follow that custom. Some mathematicians use the term positive semidefinite operator, which means the same as positive operator.
    🔗
    The characterizations of the positive operators in the next result correspond to characterizations of the nonnegative numbers among \(\C{}\text{.}\) Specifically, a number \(z \in \C{}\) is nonnegative if and only if it has a nonnegative square root, corresponding to condition (d). Also, \(z\) is nonnegative if and only if it has a real square root, corresponding to condition (e). Finally, \(z\) is nonnegative if and only if there exists \(w \in \C{}\) such that \(z = \bar{w}w\text{,}\) corresponding to condition (f). See Exercise 7.3.20 for another condition that is equivalent to being a positive operator.
    🔗

    Theorem 7.38. characterizations of positive operators.

    Let \(T \in \Lc(V)\text{.}\) Then the following are equivalent.
    1. \(T\) is a positive operator.
      🔗
      🔗
    2. \(T\) is self-adjoint and all eigenvalues of \(T\) are nonnegative.
      🔗
      🔗
    3. With respect to some orthonormal basis of \(V{}\text{,}\) the matrix of \(T\) is a diagonal matrix with only nonnegative numbers on the diagonal.
      🔗
      🔗
    4. \(T\) has a positive square root.
      🔗
      🔗
    5. \(T\) has a self-adjoint square root.
      🔗
      🔗
    6. \(T = R^*R\) for some \(R \in \Lc(V)\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    We will prove that (a) \(\Rightarrow\) (b) \(\Rightarrow\) (c) \(\Rightarrow\) (d) \(\Rightarrow\) (e) \(\Rightarrow\) (f) \(\Rightarrow\) (a).
    🔗
    First suppose (a) holds, so that \(T\) is positive, which implies that \(T\) is self-adjoint (by definition of positive operator). To prove the other condition in (b), suppose \(\lambda\) is an eigenvalue of \(T{}\text{.}\) Let \(v\) be an eigenvector of \(T\) corresponding to \(\lambda\text{.}\) Then
    \begin{equation*} 0 \le \langle Tv, v \rangle = \langle \lambda v, v \rangle = \lambda \langle v, v \rangle . \end{equation*}
    🔗
    Thus \(\lambda\) is a nonnegative number. Hence (b) holds, showing that (a) implies (b).
    🔗
    Now suppose (b) holds, so that \(T\) is self-adjoint and all eigenvalues of \(T\) are nonnegative. By the spectral theorem ( Theorem 7.29 and Theorem 7.31), there is an orthonormal basis \(e_1, \dots, e_n\) of \(V\) consisting of eigenvectors of \(T{}\text{.}\) Let \(\lambda_1, \dots, \lambda_n\) be the eigenvalues of \(T\) corresponding to \(e_1, \dots, e_n\text{;}\) thus each \(\lambda_k\) is a nonnegative number. The matrix of \(T\) with respect to \(e_1, \ldots, e_n\) is the diagonal matrix with \(\lambda_1, \ldots, \lambda_n\) on the diagonal, which shows that (b) implies (c).
    🔗
    Now suppose (c) holds. Suppose \(e_1, \ldots, e_n\) is an orthonormal basis of \(V\) such that the matrix of \(T\) with respect to this basis is a diagonal matrix with nonnegative numbers \(\lambda_1, \ldots, \lambda_n\) on the diagonal. The linear map lemma Theorem 3.4 implies that there exists \(R \in \Lc(V)\) such that
    \begin{equation*} Re_k = \sqrt{\lambda_k} e_k \end{equation*}
    for each \(k = 1, \dots, n\text{.}\) As you should verify, \(R\) is a positive operator. Furthermore, \(R^2 e_k = \lambda_k e_k = Te_k\) for each \(k\text{,}\) which implies that \(R^2 = T{}\text{.}\) Thus \(R\) is a positive square root of \(T{}\text{.}\) Hence (d) holds, which shows that (c) implies (d).
    🔗
    Every positive operator is self-adjoint (by definition of positive operator). Thus (d) implies (e). }
    🔗
    Now suppose (e) holds, meaning that there exists a self-adjoint operator \(R\) on \(V\) such that \(T = R^2{}\text{.}\) Then \(T = R^* R\) \big(because \(R^* = R\)\big). Hence (e) implies (f).
    🔗
    Finally, suppose (f) holds. Let \(R \in \Lc(V)\) be such that \(T = R^*R\text{.}\) Then \(T^* = ( R^*R )^* = R^*( R^* )^* = R^*R = T{}\text{.}\) Hence \(T\) is self-adjoint. To complete the proof that (a) holds, note that
    \begin{equation*} \langle Tv, v \rangle = \langle R^*Rv, v \rangle = \langle Rv, Rv \rangle \ge 0 \end{equation*}
    for every \(v \in V{}\text{.}\) Thus \(T\) is positive, showing that (f) implies (a).
    🔗
    🔗
    Every nonnegative number has a unique nonnegative square root. The next result shows that positive operators enjoy a similar property.
    🔗

    Theorem 7.39. each positive operator has only one positive square root.

    Every positive operator on \(V\) has a unique positive square root.
    🔗
    🔗

    Aside
    A positive operator can have infinitely many square roots (although only one of them can be positive) . For example, the identity operator on \(V\) has infinitely many square roots if \(\dim V > 1\text{.}\)
    🔗

    Proof.
    Suppose \(T \in \Lc(V)\) is positive. Suppose \(v \in V\) is an eigenvector of \(T{}\text{.}\) Hence there exists a real number \(\lambda \ge 0\) such that \(Tv = \lambda v\text{.}\)
    🔗
    Let \(R\) be a positive square root of \(T{}\text{.}\) We will prove that \(Rv = \sqrt{\lambda}v\text{.}\) This will imply that the behavior of \(R\) on the eigenvectors of \(T\) is uniquely determined. Because there is a basis of \(V\) consisting of eigenvectors of \(T\) (by the spectral theorem), this will imply that \(R\) is uniquely determined.
    🔗
    To prove that \(Rv = \sqrt{\lambda}v\text{,}\) note that the spectral theorem asserts that there is an orthonormal basis \(e_1, \dots, e_n\) of \(V\) consisting of eigenvectors of \(R\text{.}\) Because \(R\) is a positive operator, all its eigenvalues are nonnegative. Thus there exist nonnegative numbers \(\lambda_1, \dots, \lambda_n\) such that \(Re_k = \sqrt{\lambda_k} e_k\) for each \(k = 1, \dots, n\text{.}\)
    🔗
    Because \(e_1, \dots, e_n\) is a basis of \(V{}\text{,}\) we can write
    \begin{equation*} v = a_1 e_1 + \dots + a_n e_n \end{equation*}
    for some numbers \(a_1, \dots, a_n \in \F{}{}\text{.}\) Thus
    \begin{equation*} Rv = a_1 \sqrt{\lambda_1} e_1 + \dots + a_n \sqrt{\lambda_n} e_n. \end{equation*}
    🔗
    Hence
    \begin{equation*} \lambda v = Tv = R^2v = a_1 \lambda_1 e_1 + \dots + a_n \lambda_n e_n. \end{equation*}
    🔗
    The equation above implies that
    \begin{equation*} a_1 \lambda e_1 + \dots + a_n \lambda e_n = a_1 \lambda_1 e_1 + \dots + a_n \lambda_n e_n. \end{equation*}
    🔗
    Thus \(a_k(\lambda - \lambda_k) = 0\) for each \(k = 1, \dots, n\text{.}\) Hence
    \begin{equation*} v = \sum_{\{k:\lambda_k = \lambda\}} a_k e_k. \end{equation*}
    🔗
    Thus
    \begin{equation*} Rv = \sum_{\{k:\lambda_k = \lambda\}} a_k \sqrt{\lambda} e_k = \sqrt{\lambda} v, \end{equation*}
    as desired.}
    🔗
    🔗
    The notation defined below makes sense thanks to the result above.
    🔗

    Notation 7.40. \(\sqrt{T}\).

    For \(T\) a positive operator, \(\sqrt{T}\) denotes the unique positive square root of \(T{}\text{.}\)
    🔗
    🔗

    Example 7.41. square root of positive operators.

    Define operators \(S, T\) on \(\R 2\) (with the usual Euclidean inner product) by
    \begin{equation*} S(x, y) = (x, 2y) \andd T(x, y) = (x+y, x+y). \end{equation*}
    🔗
    Then with respect to the standard basis of \(\R 2\) we have
    \begin{equation} \M(S) = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 2\end{pmatrix} \andd \M(T) = \begin{pmatrix} 1 \amp 1 \\ 1 \amp 1\end{pmatrix}.\tag{7.42} \end{equation}
    🔗
    Each of these matrices equals its transpose; thus \(S\) and \(T\) are self-adjoint.
    🔗
    If \((x, y) \in \R2\text{,}\) then
    \begin{equation*} \langle S(x, y), (x, y) \rangle = x^2 + 2y^2 \ge 0 \end{equation*}
    and
    \begin{equation*} \langle T(x, y), (x, y) \rangle = x^2 + 2 xy + y^2 = (x+y)^2 \ge 0. \end{equation*}
    🔗
    Thus \(S\) and \(T\) are positive operators.
    🔗
    The standard basis of \(\R2\) is an orthonormal basis consisting of eigenvectors of \(S\text{.}\) Note that
    \begin{equation*} ( \tfrac{1}{\sqrt{2}}, \tfrac{1}{\sqrt{2}} ), ( \tfrac{1}{\sqrt{2}}, -\tfrac{1}{\sqrt{2}} ) \end{equation*}
    is an orthonormal basis of eigenvectors of \(T\text{,}\) with eigenvalue \(2\) for the first eigenvector and eigenvalue \(0\) for the second eigenvector. Thus \(\sqrt{T}\) has the same eigenvectors, with eigenvalues \(\sqrt{2}\) and \(0\text{.}\)
    🔗
    You can verify that
    \begin{equation*} \M( \! \sqrt{S} ) = \begin{pmatrix}1 \amp 0 \\ 0 \amp \sqrt{2} \end{pmatrix} \andd \M( \! \sqrt{T} ) = \begin{pmatrix}\frac{1}{\sqrt{2}} \amp \frac{1}{\sqrt{2}} \\ \frac{1}{\sqrt{2}} \amp \frac{1}{\sqrt{2}} \end{pmatrix} \end{equation*}
    with respect to the standard basis by showing that the squares of the matrices above are the matrices in (7.42) and that each matrix above is the matrix of a positive operator.
    🔗
    🔗
    The statement of the next result does not involve a square root, but the clean proof makes nice use of the square root of a positive operator.
    🔗

    Theorem 7.43. \(T\) positive and \(\langle Tv, v \rangle = 0 \implies Tv = 0\).

    Suppose \(T\) is a positive operator on \(V\) and \(v \in V\) is such that \(\langle Tv, v \rangle = 0\text{.}\) Then \(Tv = 0\text{.}\)
    🔗
    🔗

    Proof.
    We have
    \begin{equation*} 0 = \langle Tv, v \rangle = \langle \sqrt{T} \sqrt{T} v, v \rangle = \langle \sqrt T v, \sqrt T v \rangle = \lVert \sqrt T v \rVert ^2{}. \end{equation*}
    🔗
    Hence \(\sqrt T v = 0\text{.}\) Thus \(Tv = \sqrt T( \sqrt T v ) = 0\text{,}\) as desired.
    🔗
    🔗
