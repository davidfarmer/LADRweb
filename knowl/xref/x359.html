Example 6.40. linear functional on \(\F{3}\).

The function \(\phi \colon \F{3} \rightarrow \F{}\) defined by
\begin{equation*} \phi(z_1, z_2, z_3) = 2 z_1 - 5 z_2 + z_3 \end{equation*}
is a linear functional on \(\FF{3}\text{.}\) We could write this linear functional in the form
\begin{equation*} \phi(z) = \langle z, w \rangle \end{equation*}
for every \(z \in \FF3\text{,}\) where \(w = (2, -5, 1)\text{.}\)
