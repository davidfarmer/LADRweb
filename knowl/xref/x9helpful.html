Theorem 9.55. helpful results in evaluating determinants.

  1. If either two columns or two rows of a square matrix are equal, then the determinant of the matrix equals \(0\text{.}\)
    🔗
    🔗
  2. Suppose \(A\) is a square matrix and \(B\) is the matrix obtained from \(A\) by swapping either two columns or two rows. Then \(\det A = - \det B\text{.}\)
    🔗
    🔗
  3. If one column or one row of a square matrix is multiplied by a scalar, then the value of the determinant is multiplied by the same scalar.
    🔗
    🔗
  4. If a scalar multiple of one column of a square matrix is added to another column, then the value of the determinant is unchanged.
    🔗
    🔗
  5. If a scalar multiple of one row of a square matrix is added to another row, then the value of the determinant is unchanged.
