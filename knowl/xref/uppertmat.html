Example 5.32. matrix of an operator with respect to standard basis.

Define \(T \in \Lc( \F3 )\) by \(T(x, y, z) = (2x + y, 5y + 3z, 8z)\text{.}\) Then the matrix of \(T\) with respect to the standard basis of \(\F3\) is
\begin{equation*} \M(T) = \begin{pmatrix}2 \amp 1 \amp 0 \\ 0 \amp 5 \amp 3 \\ 0 \amp 0 \amp 8 \end{pmatrix} , \end{equation*}
as you should verify.
