Theorem 3.87. a sum is a direct sum if and only if dimensions add up.

Suppose \(V\) is finite-dimensional and \(V{}_1, \dots, V{}_m\) are subspaces of \(V{}\text{.}\) Then \(V{}_1 + \dots + V{}_m\) is a direct sum if and only if
\begin{equation*} \dim(V{}_1 + \dots + V{}_m) = \dim V{}_1 + \dots + \dim V{}_m. \end{equation*}
