Example 6.17. Cauchy–Schwarz inequality.

  1. If \(x_1, \ldots, x_n, y_1, \ldots, y_n \in \R{}\text{,}\) then
    \begin{equation*} ( x_1 y_1 + \cdots + x_n y_n)^2 \le ( {x_1}^{2} + \cdots + {x_n}^{2} ) ( {y_1}^{2} + \cdots + {y_n}^{2} ), \end{equation*}
    as follows from applying the Cauchy–Schwarz inequality to the vectors \((x_1, \ldots, x_n), (y_1, \ldots, y_n) \in \RR n\text{,}\) using the usual Euclidean inner product.

  2. If \(f, g\) are continuous real-valued functions on \([-1, 1]\text{,}\) then
    \begin{equation*} \lvert \int_{-1}^1 fg \rvert ^{2} \le ( \int_{-1}^1 f^2 ) ( \int_{-1}^1 g^2 ), \end{equation*}
    as follows from applying the Cauchy–Schwarz inequality to Example 6.4(c).
