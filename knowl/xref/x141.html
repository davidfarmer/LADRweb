Example 5.23. minimal polynomial of an operator on \(\F5\).

Suppose \(T \in \Lc( \F{5} )\) and
\begin{equation*} \M(T) = \begin{pmatrix}0 \amp 0 \amp 0 \amp 0 \amp -3 \\ 1 \amp 0 \amp 0 \amp 0 \amp 6 \\ 0 \amp 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \amp 0 \end{pmatrix} \end{equation*}
with respect to the standard basis \(e_1, e_2, e_3, e_4, e_5\text{.}\) Taking \(v = e_1\) for (5.3), we have
\begin{align*} Te_1 \amp = e_2, \amp T^4e_1 \amp = T( T^3e_1 ) = Te_4 = e_5,\\ T^2e_1 \amp = T(Te_1) = Te_2 = e_3, \amp T^5 e_1 \amp = T( T^4e_1 ) = Te_5 = -3e_1 + 6e_2.\\ T^3e_1 \amp = T( T^2e_1 ) = Te_3 = e_4\text{,} \end{align*}
🔗
Thus \(3e_1 - 6 Te_1 = -T^5 e_1\text{.}\) The list \(e_1, Te_1, T^2 e_1, T^3 e_1, T^4 e_1\text{,}\) which equals the list \(e_1, e_2, e_3, e_4, e_5\text{,}\) is linearly independent, so no other linear combination of this list equals \(-T^5e_1\text{.}\) Hence the minimal polynomial of \(T\) is \(3 - 6z + z^5{}\text{.}\)
