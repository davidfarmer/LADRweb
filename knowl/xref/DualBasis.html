Definition 3.106. dual basis.

If \(v_1, \dots, v_n\) is a basis of \(V{}\text{,}\) then the dual basis of \(v_1, \dots, v_n\) is the list \(\phi_1, \dots, \phi_n\) of elements of \(V'\!\text{,}\) where each \(\phi_j\) is the linear functional on \(V\) such that
\begin{equation*} \phi_j(v_k) = \begin{cases}1 \amp \text{ if } k = j,\\ 0 \amp \text{ if } k \ne j. \end{cases} \end{equation*}
