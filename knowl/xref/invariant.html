Example 5.4. four invariant subspaces, not necessarily all different.

If \(T \in \Lc(V)\text{,}\) then the following subspaces of \(V\) are all invariant under \(T{}\text{.}\)
  1. \(\{ 0 \}\).
    The subspace \(\{0\}\) is invariant under \(T\) because if \(u \in \{0\}\text{,}\) then \(u = 0\) and hence \(Tu = 0 \in \{0\}\text{.}\)
    🔗
    🔗
  2. \(V\).
    The subspace \(V\) is invariant under \(T\) because if \(u \in V{}\text{,}\) then \(Tu \in V{}\text{.}\)
    🔗
    🔗
  3. \(\ker T\).
    The subspace \(\ker T\) is invariant under \(T\) because if \(u \in \ker T\text{,}\) then \(Tu = 0\text{,}\) and hence \(Tu \in \ker T{}\text{.}\)
    🔗
    🔗
  4. \(\ran T\).
    The subspace \(\ran T\) is invariant under \(T\) because if \(u \in \ran T\text{,}\) then \(Tu \in \ran T{}\text{.}\)
