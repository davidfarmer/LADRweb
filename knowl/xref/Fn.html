Example 2.8. a list that spans \(\F{n}\).

Suppose \(n\) is a positive integer. We want to show that
\begin{equation*} (1, 0, \dots, 0), (0, 1, 0, \dots, 0), \dots, (0, \dots, 0, 1) \end{equation*}
spans \(\FF{n}\text{.}\) Here the \(k^\nth\) vector in the list above has \(1\) in the \(k^\nth\) slot and \(0\) in all other slots.
🔗
Suppose \((x_1, \dots, x_n) \in \FF{n}\text{.}\) Then
\begin{equation*} (x_1, \dots, x_n) = x_1 (1, 0, \dots, 0) + x_2 (0, 1, 0, \dots, 0) + \dots + x_n (0, \dots, 0, 1). \end{equation*}
🔗
Thus \((x_1, \dots, x_n) \in \Span \bigl((1, 0, \dots, 0), (0, 1, 0, \dots, 0), \dots, (0, \dots, 0, 1)\bigr)\text{,}\) as desired.
