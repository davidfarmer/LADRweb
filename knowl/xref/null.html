Example 3.12. null space.

  1. If \(T\) is the zero map from \(V\) to \(W{}\text{,}\) meaning that \(Tv = 0\) for every \(v \in V{}\text{,}\) then \(\ker T = V{}\text{.}\)

Suppose \(\phi \in \Lc( \CC3, \C{} )\) is defined by \(\phi(z_1, z_2, z_3) = z_1 + 2z_2 + 3z_3\text{.}\) Then \(\ker \phi\) equals \(\{ (z_1, z_2, z_3) \in \C3: z_1 + 2z_2 + 3z_3 = 0 \}\text{,}\) which is a subspace of the domain of \(\phi\text{.}\) We will soon see that the null space of each linear map is a subspace of its domain.

  4. Suppose that \(T\in \Lc\bigl(\P(\R{})\bigr)\) is the multiplication by \(x^2\) map defined by \((Tp)(x) = x^2 p(x)\text{.}\) The only polynomial \(p\) such that \(x^2 p(x) = 0\) for all \(x \in \R{}\) is the \(0\) polynomial. Thus \(\ker T = \{ 0 \}\text{.}\)

  5. Suppose \(T\in \Lc( \F{\infty} )\) is the backward shift defined by
    \begin{equation*} T(x_1, x_2, x_3, \dots) = (x_2, x_3, \dots). \end{equation*}
    Then \(T(x_1, x_2, x_3, \dots)\) equals \(0\) if and only if the numbers \(x_2, x_3, \dots\) are all \(0\text{.}\) Thus \(\ker T = \{ (a, 0, 0, \dots): a \in \F{} \}\text{.}\)
