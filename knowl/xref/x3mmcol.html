Theorem 3.51. matrix multiplication as linear combinations of columns or rows.

Suppose \(C\) is an \(m\)-by-\(c\) matrix and \(R\) is a \(c\)-by-\(n\) matrix.
  1. If \(k \in \{ 1, \ldots, n \}\text{,}\) then column \(k\) of \(CR\) is a linear combination of the columns of \(C\text{,}\) with the coefficients of this linear combination coming from column \(k\) of \(R\text{.}\)
    🔗
    🔗
  2. If \(j \in \{ 1, \ldots, m \}\text{,}\) then row \(j\) of \(CR\) is a linear combination of the rows of \(R\text{,}\) with the coefficients of this linear combination coming from row \(j\) of \(C\text{.}\)
