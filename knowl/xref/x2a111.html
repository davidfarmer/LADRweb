Example 3.3. linear maps.

  1. zero.
    In addition to its other uses, we let the symbol \(0\) denote the linear map that takes every element of some vector space to the additive identity of another (or possibly the same) vector space. To be specific, \(0 \in \Lc(V{},W)\) is defined by
    \begin{equation*} 0v = 0. \end{equation*}
    The \(0\) on the left side of the equation above is a function from \(V\) to \(W{}\text{,}\) whereas the \(0\) on the right side is the additive identity in \(W{}\text{.}\) As usual, the context should allow you to distinguish between the many uses of the symbol \(0\text{.}\)
    🔗
    🔗
  2. identity operator.
    The identity operator, denoted by \(I\text{,}\) is the linear map on some vector space that takes each element to itself. To be specific, \(I \in \Lc(V)\) is defined by
    \begin{equation*} Iv = v. \end{equation*}
    🔗
    🔗
  3. differentiation.
    Define \(D\in \Lc\bigl(\P(\R{})\bigr)\) by
    \begin{equation*} Dp = p'\!. \end{equation*}
    The assertion that this function is a linear map is another way of stating a basic result about differentiation: \((f + g)' = f' + g'\) and \((\lambda f)' = \lambda f'\) whenever \(f, g\) are differentiable and \(\lambda\) is a constant.
    🔗
    🔗
  4. integration.
    Define \(T\in \Lc\bigl(\P(\R{}),\R{}\bigr)\) by
    \begin{equation*} Tp = \int_0^1 p. \end{equation*}
    The assertion that this function is linear is another way of stating a basic result about integration: the integral of the sum of two functions equals the sum of the integrals, and the integral of a constant times a function equals the constant times the integral of the function.
    🔗
    🔗
  5. multiplication by \(x^2\).
    Define a linear map \(T\in \Lc\bigl(\P(\R{})\bigr)\) by
    \begin{equation*} (Tp)(x) = x^2 p(x) \end{equation*}
    for each \(x \in \R{}\text{.}\)
    🔗
    🔗
  6. backward shift.
    Recall that \(\F{\infty}\) denotes the vector space of all sequences of elements of \(\F{}{}\text{.}\) Define a linear map \(T\in \Lc( \F{\infty} )\) by
    \begin{equation*} T(x_1, x_2, x_3, \dots) = (x_2, x_3, \dots). \end{equation*}
    🔗
    🔗
  7. from \(\R3\) to \(\R2\).
    Define a linear map \(T\in \Lc( \RR{3},\R{2} )\) by
    \begin{equation*} T(x,y,z) = (2x - y + 3z, 7x + 5y -6z). \end{equation*}
    🔗
    🔗
  8. from \(\F{n}\) to \(\F{m}\).
    To generalize the previous example, let \(m\) and \(n\) be positive integers, let \(A_{j,k} \in \F{}\) for each \(j = 1, \dots, m\) and each \(k = 1, \dots , n\text{,}\) and define a linear map \(T\in \Lc( \FF{n},\F{m} )\) by
    \begin{equation*} T(x_1, \dots, x_n) = (A_{1,1}x_1 + \dots + A_{1,n} x_n, \dots, A_{m,1}x_1 + \dots + A_{m,n} x_n). \end{equation*}
    Actually every linear map from \(\F{n}\) to \(\F{m}\) is of this form.
    🔗
    🔗
  9. composition.
    Fix a polynomial \(q \in \P(\R{})\text{.}\) Define a linear map \(T \in \Lc( \P(\R{}) )\) by
    \begin{equation*} (Tp)(x) = p( q(x) ). \end{equation*}
    🔗
    🔗
