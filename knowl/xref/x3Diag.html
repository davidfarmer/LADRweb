Exercise 2.

Suppose \(\E\) is a subset of \(\Lc(V)\) and every element of \(\E\) is diagonalizable. Prove that there exists a basis of \(V\) with respect to which every element of \(\E\) has a diagonal matrix if and only if every pair of elements of \(\E\) commutes. Note: This exercise extends 5.63, which considers the case in which \(\E\) contains only two elements. For this exercise, \(\E\) may contain any number of elements, and \(\E\) may even be an infinite set.
