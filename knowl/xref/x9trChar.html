Exercise 10.

Prove that the trace is the only linear functional \(\fun \tau {\Lc(V)} {\F{}}\) such that
\begin{equation*} \tau(ST) = \tau(TS) \end{equation*}
for all \(S, T \in \Lc(V)\) and \(\tau(I) = \dim V{}\text{.}\)
🔗
Hint.
Suppose that \(v_1, \ldots, v_n\) is a basis of \(V{}\text{.}\) For \(j, k \in \{ 1, \ldots, n \}\text{,}\) define \(P_{j,k} \in \Lc(V)\) by \(P_{j,k}(a_1 v_1 + \cdots + a_n v_n) = a_k v_j\text{.}\) Prove that
\begin{equation*} \tau(P_{j,k}) = \begin{cases}1 \amp \text{ if } j = k, \\ 0 \amp \text{ if } j \ne k. \end{cases} \end{equation*}
🔗
Then for \(T \in \Lc(V)\text{,}\) use the equation \(T = \sum_{k=1}^n \sum_{j=1}^n \M(T)_{j,k} P_{j,k}\) to show that \(\tau(T) = \tr T\text{.}\)
