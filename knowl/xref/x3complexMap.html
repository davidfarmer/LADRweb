Exercise 33.

Suppose that \(V\) and \(W\) are real vector spaces and \(T \in \Lc(V{}, W)\text{.}\) Define \(\fun {T{}_{\C{}}} {V{}_{\C{}}} {W{}_{\C{}}}\) by
\begin{equation*} T{}_{\C{}}(u + iv) = Tu + iTv \end{equation*}
for all \(u, v \in V{}\text{.}\)
  1. Show that \(T{}_{\C{}}\) is a (complex) linear map from \(V{}_{\C{}}\) to \(W{}_{\C{}}\text{.}\)
    🔗
    🔗
  2. Show that \(T{}_{\C{}}\) is injective if and only if \(T\) is injective.
    🔗
    🔗
  3. Show that \(\ran T{}_{\C{}} = W{}_{\C{}}\) if and only if \(\ran T = W{}\text{.}\)
    🔗
    🔗
🔗
Note: See Exercise 1.2.8.b in Section 1.2 for the definition of the complexification \(V{}_{\C{}}\text{.}\) The linear map \(T{}_{\C{}}\) is called the complexification of the linear map \(T{}\text{.}\)
