Example 3.64. neither injectivity nor surjectivity implies invertibility.

  1. The multiplication by \(x^2\) linear map from \(\P(\R{})\) to \(\P(\R{})\) (see 3.3) is injective but it is not invertible because it is not surjective (the polynomial \(1\) is not in the range).
    🔗
    🔗
  2. The backward shift linear map from \(\F{\infty}\) to \(\F{\infty}\) (see 3.3) is surjective but it is not invertible because it is not injective [the vector \((1, 0, 0, 0, \dotsc)\) is in the null space] .
