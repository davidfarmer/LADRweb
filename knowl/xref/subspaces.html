Example 1.40. subspaces.

  1. If \(b \in \F{}{}\text{,}\) then
    \begin{equation*} \{ (x_1, x_2, x_3, x_4) \in \F{4} : x_3 = 5 x_4 + b \} \end{equation*}
    is a subspace of \(\F{4}\) if and only if \(b = 0\text{.}\)
    🔗
    🔗
  2. The set of continuous real-valued functions on the interval \([0, 1]\) is a subspace of \(\RR{[0, 1]}\text{.}\)
    🔗
    🔗
  3. The set of differentiable real-valued functions on \(\R{}\) is a subspace of \(\RR{\R{}}\text{.}\)
    🔗
    🔗
  4. The set of differentiable real-valued functions \(f\) on the interval \((0, 3)\) such that \(f'\!(2) = b\) is a subspace of \(\R{(0,3)}\) if and only if \(b = 0\text{.}\)
    🔗
    🔗
  5. The set of all sequences of complex numbers with limit \(0\) is a subspace of \(\CC{\infty}\text{.}\)
