Exercise 13.

Prove that the union of three subspaces of \(V\) is a subspace of \(V\) if and only if one of the subspaces contains the other two. Note: This exercise is surprisingly harder than Exercise 1.3.2.12, possibly because this exercise is not true if we replace \(\F{}\) with a field containing only two elements.
