Theorem 6.32. Gram–Schmidt procedure.

Suppose \(v_1, \dots, v_m\) is a linearly independent list of vectors in  \(V{}\text{.}\) Let \(f_1 = v_1\text{.}\) For \(k = 2, \dots, m\text{,}\) define \(f_k\) inductively by
\begin{equation*} f_k = v_k - \frac{\langle v_k, f_1 \rangle }{\lVert f_1 \rVert ^2} f_1 - \dots - \frac{\langle v_k, f_{k-1} \rangle }{\lVert f_{k-1} \rVert ^2} f_{k-1}. \end{equation*}
🔗
For each \(k = 1, \ldots, m\text{,}\) let \(e_k = \dfrac{f_k}{\lVert f_k \rVert }\text{.}\) Then \(e_1, \dots, e_m\) is an orthonormal list of vectors in  \(V\) such that
\begin{equation*} \Span (v_1, \dots, v_k) = \Span (e_1, \dots, e_k) \end{equation*}
for each \(k = 1, \dots, m\text{.}\)
