Definition 2.4. span.

The set of all linear combinations of a list of vectors \(v_1, \dots, v_m\) in \(V\) is called the span of \(v_1, \dots, v_m\text{,}\) denoted by \(\Span(v_1, \dots, v_m)\text{.}\) In other words,
\begin{equation*} \Span(v_1, \dots, v_m) = \{ a_1 v_1 + \dots + a_m v_m: a_1, \dots, a_m \in \F{} \}. \end{equation*}
🔗
The span of the empty list \((\ )\) is defined to be \(\{0\}\text{.}\)
