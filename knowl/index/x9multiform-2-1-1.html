Item 1.

For \(m\) a positive integer, an \(m\)-linear form on \(V\) is a function \(\fun \beta {V^m{}} {\F{}}\) that is linear in each slot when the other slots are held fixed. This means that for each \(k \in \{ 1, \ldots, m \}\) and all \(u_1, \ldots, u_m \in V{}\text{,}\) the function
\begin{equation*} v \mapsto \beta(u_1, \ldots, u_{k-1}, v, u_{k+1}, \ldots, u_m) \end{equation*}
is a linear map from \(V\) to \(\F{}{}\text{.}\)
