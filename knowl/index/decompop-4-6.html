Note that in the example above, each of \(A_1\text{,}\) \(A_2\text{,}\) \(A_3\) is an upper-triangular matrix whose diagonal entries are all equal. The next result shows that with respect to an appropriate basis, every operator on a finite-dimensional complex vector space has a matrix of this form.
