Example 1.23. \(\F{\infty}\).

\(\F{\infty}\) is defined to be the set of all sequences of elements of \(\F{}\text{:}\)
\begin{equation*} \F{\infty} = \{ (x_1, x_2, \dotsc) : x_k \in \F{} \ for\ k = 1, 2, \dotsc \}. \end{equation*}
🔗
Addition and scalar multiplication on \(\F{\infty}\) are defined as expected:
\begin{gather*} (x_1, x_2, \dotsc) + (y_1, y_2, \dotsc) = (x_1 + y_1, x_2 + y_2, \dotsc),\\ \lambda(x_1, x_2, \dotsc) = (\lambda x_1, \lambda x_2, \dotsc)\text{.} \end{gather*}
🔗
With these definitions, \(\F{\infty}\) becomes a vector space over \(\F{}{}\text{,}\) as you should verify. The additive identity in this vector space is the sequence of all \(0\)’s.
