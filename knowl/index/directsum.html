Definition 1.41. direct sum, \(\oplus\).

Suppose \(V{}_1, \dots, V{}_m\) are subspaces of \(V{}\text{.}\)
  1. The sum \(V{}_1 + \dots + V{}_m\) is called a direct sum if each element of \(V{}_1 + \dots + V{}_m\) can be written in only one way as a sum \(v_1 + \dots + v_m\text{,}\) where each \(v_k \in V{}_k\text{.}\)
    🔗
    🔗
  2. If \(V{}_1 + \dots + V{}_m\) is a direct sum, then \(V{}_1 \oplus \dots \oplus V{}_m\) denotes \(V{}_1 + \dots + V{}_m\text{,}\) with the \(\oplus\) notation serving as an indication that this is a direct sum.
