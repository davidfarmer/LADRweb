Exercise 35.

Fix a positive integer \(n\text{.}\) The Laplacian \(\Delta p\) of a twice differentiable real-valued function \(p\) on \(\R{n}\) is the function on \(\R{n}\) defined by
\begin{equation*} \Delta p = \frac{ \partial^2 p }{\partial {x_1}^{2}} + \dots + \frac{ \partial^2 p }{\partial {x_n}^{2}}. \end{equation*}
🔗
The function \(p\) is called harmonic if \(\Delta p = 0\text{.}\)
🔗
A polynomial on \(\R{n}\) is a linear combination (with coefficients in \(\R{}\)) of functions of the form \({x_1}^{m_1} \dotsm {x_n}^{m_n}\text{,}\) where \(m_1, \dots, m_n\) are nonnegative integers.
🔗
Suppose \(q\) is a polynomial on \(\RR{n}\text{.}\) Prove that there exists a harmonic polynomial \(p\) on \(\R{n}\) such that \(p(x) = q(x)\) for every \(x \in \R{n}\) with \(\|x\| = 1\text{.}\) Note: The only fact about harmonic functions that you need for this exercise is that if \(p\) is a harmonic function on \(\R{n}\) and \(p(x) = 0\) for all \(x \in \R{n}\) with \(\|x\|=1\text{,}\) then \(p = 0\text{.}\)
🔗
Hint.
A reasonable guess is that the desired harmonic polynomial \(p\) is of the form \(q + ( 1 - \|x\|^2 ) r\) for some polynomial \(r\text{.}\) Prove that there is a polynomial \(r\) on \(\R{n}\) such that \(q + ( 1 - \|x\|^2 ) r\) is harmonic by defining an operator \(T\) on a suitable vector space by
\begin{equation*} Tr = \Delta \bigl( (1 - \|x\|^2) r \bigr) \end{equation*}
and then showing that \(T\) is injective and hence surjective.
